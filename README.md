# RC Section NDM

Excel VBA-программа для расчета железобетонных сечений по НДМ: `N + Mx + My`, несущая способность, трещины по СП 35 и СП 63, устойчивость. Поддерживаются круг, составные прямоугольные и скругленные сечения, импорт и экспорт AutoCAD.

Готовая книга: [RC_Section_NDM.xlsm](workbook/output/RC_Section_NDM.xlsm). Краткая инструкция находится на листе `Справка`, подробное [руководство пользователя](docs/NDM_User_Guide.md) — в `docs`.

Сначала нажмите «Сформировать сечение»: программа построит геометрию по
параметрам листа «Сечения» или импортирует её из AutoCAD. При выбранном Excel
сечение сохраняется на Results, при File — в файл с текущим именем снимка.
«Выполнить расчёт», обновление схемы и экспорт используют этот выбранный источник
без повторного формирования геометрии. Уже сохранённый файл можно сразу использовать
для расчёта. После изменения размеров, армирования или сетки сечение нужно сформировать заново.

## Сборка

Нужны Windows и установленный Microsoft Excel. Для сборки должен быть разрешен доступ к объектной модели проекта VBA; для работы книги разрешены макросы. AutoCAD нужен только для импорта и экспорта.

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Build-Workbook.ps1
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Validate-Workbook.ps1
```

Сборка создает книгу с настройками шаблона. Не запускайте ее поверх открытой рабочей книги.

## Разработка

Основная ветка — `main`: согласованная рабочая версия, включая принятое адаптивное разбиение сетки. Дальнейшие изменения выполняются в отдельных ветках `codex/...` от актуальной `main` и после проверок и согласования сливаются в `main`. Историческая `master` сохраняется отдельно.

- `src/` - VBA; `tests/` - тесты; `tools/` - сборка и проверки.
- Новый параметрический тип: один `ISectionRecipe`, декларативное описание через `CSectionDefinitionBuilder` и одна регистрация в `CSectionTypeRegistry`. Общий сборщик готовит геометрию, арматуру, сетку и необязательные аннотации; общие алгоритмы не зависят от имени типа.
- [AGENTS.md](AGENTS.md) - правила изменений.
- [Расчетная модель](docs/MathematicalModel.md), [единицы и знаки](docs/CoordinateSystem.md), [проверки](docs/ValidationPlan.md).
- [Нормативная трассировка](docs/NormativeTraceability.md), [открытые вопросы](docs/OpenNormativeQuestions.md), [отчеты](docs/reports/README.md).
- `norms/`, `reference/`, `control_examples/` - источники и контрольные материалы.

Поддерживается ненапрягаемая арматура. Автоматические тесты не заменяют независимую нормативную проверку расчета.
