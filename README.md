# RC Section NDM

Excel VBA-программа для расчёта железобетонных поперечных
сечений по нелинейной деформационной модели.

## Основные документы

- `AGENTS.md` — постоянные правила работы над проектом.
- `docs/NDM_PROJECT_SPEC.md` — полное техническое задание.
- `tasks/00_ANALYZE_REPOSITORY.md` — первое задание для Codex.

## Справочные программы

- `reference/round_section/` — существующий расчёт круглого сечения.
- `reference/arbitrary_section_ndm/` — расчёт произвольного сечения.

Обе программы предоставлены как инженерные примеры и источники
контрольных результатов. Они не являются эталоном архитектуры кода.

# Нормативные документы

В этом каталоге находятся нормативные документы, используемые
для разработки программы.

Перед применением любого параметра необходимо проверить:

1. редакцию основного документа;
2. наличие действующих изменений;
3. номер пункта, таблицы или приложения;
4. применимость положения к мостовым конструкциям;
5. приоритет СП 35 или СП 63.

Нельзя принимать нормативные значения только по памяти.
