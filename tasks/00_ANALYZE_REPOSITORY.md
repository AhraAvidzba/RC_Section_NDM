# Этап 0. Анализ репозитория

Прочитай:

- `AGENTS.md`;
- `docs/NDM_PROJECT_SPEC.md`;
- все README-файлы в `reference`;
- нормативные документы из `norms`;
- существующие книги и экспортированный VBA-код.

Особое внимание удели:

- `reference/round_section/`;
- `reference/arbitrary_section_ndm/`.

Обе справочные программы предоставлены с инженерной точки зрения.
Они не являются эталоном архитектуры кода.

Расчёт круглого сечения может содержать ошибки, хотя его результаты
сверялись с классическим расчётом по СП 35 и другими программами.

Результаты программы произвольного сечения можно использовать как
доверенный контрольный ориентир, но её архитектуру также не следует
копировать автоматически.

Выполни только анализ. Не меняй существующий код и не начинай
реализацию новой программы.
