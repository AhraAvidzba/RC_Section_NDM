# Открытые вопросы

Статус: этап 0.

## Нормативные вопросы

- Какая редакция СП 35 должна считаться основной для расчетов мостовых конструкций: найден PDF СП 35.13330.2011 с изменениями 1-5, но требуется подтвердить актуальность.
- Почему копия СП 63 лежит одновременно в `norms/SP_35/` и `norms/SP_63/`; нужно оставить один источник истины или описать причину дублирования.
- Какие пункты СП 35 имеют приоритет над СП 63 для прочности нормальных сечений мостовых железобетонных элементов.
- Какие конкретные пункты СП 35 и СП 63 задают диаграммы бетона и арматуры для выбранных режимов.
- Какие пункты задают предельные деформации бетона и обычной ненапрягаемой арматуры.
- Какие пункты задают расчет ширины раскрытия уже образовавшихся нормальных трещин.
- Какие коэффициенты длительности, профиля арматуры и допустимой ширины трещин применимы к мостовым конструкциям.
- Какие подтвержденные значения по умолчанию должны быть внесены на лист `System` для классов бетона, обычной арматуры, диаграмм материалов, предельных деформаций и коэффициентов трещиностойкости.

## Вопросы по исходным данным

- Решено: напрягаемая арматура не поддерживается ни в первом релизе, ни как будущая архитектурная возможность.
- Какие классы бетона и арматуры должны быть доступны в начальной версии.
- Какие пользовательские единицы будут вводиться на листе: кН/м/МПа или сразу Н/мм/МПа.
- Нужно ли импортировать геометрию из AutoCAD в новой программе или это отдельная будущая задача.
- Какой минимальный набор контрольных примеров считать обязательным для приемки этапов 2-4.

## Вопросы по справочным расчетам

- Для круглого расчета нет отдельного файла контрольных результатов; нужно определить, какие значения из книги использовать для сверки.
- Для произвольного расчета найден DWG-пример, но нет описанного сценария запуска и ожидаемых численных результатов.
- Необходимо вручную подтвердить систему знаков обеих справочных программ.
- Необходимо проверить, не отличаются ли единицы в листах от комментариев в коде.
- Решено: справочные программы не являются обязательным источником тестовых нагрузок; произвольные нагрузки допустимы для модульных тестов при наличии независимого критерия проверки.

- Какой механизм тестирования VBA использовать в проекте.
