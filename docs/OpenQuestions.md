# OpenQuestions

Дата актуализации: 2026-08-05.

## Нормативные

- Закрыть вопросы из `docs/OpenNormativeQuestions.md`.
- Подтвердить актуальные редакции СП 35 и СП 63.
- Зафиксировать приоритет СП 35 над СП 63 для мостовых конструкций по каждому расчетному параметру.
- Подтвердить нормативную методику расчета ширины раскрытия трещин и площади взаимодействия арматуры.

## Расчетные

- Проверить `UltimateStrain` на будущих несимметричных геометриях.
- Уточнить рекомендуемые настройки `Capacity.MaxLambda`, `Capacity.ToleranceLambda`, `Capacity.ToleranceStrain` для пользовательских расчетов.
- Подготовить независимые ручные контрольные примеры для `N + Mx + My`.
- Сравнить результаты с контрольными программами при одинаковой сетке, арматуре, диаграммах и знаках.

## Производительность

- Оценить кэширование сетки, арматуры и материалов между повторными пользовательскими запусками.
- Проверить влияние `Mesh.BoundarySubdivisions` на точность и время.
- Оптимизировать `FullCapacity` для малых базовых моментов и больших `lambda`.

## Интерфейс и данные

- Решить, нужен ли отдельный лист/класс `ResultData`.
- Решить, нужен ли импорт геометрии из AutoCAD.
- Подготовить оформление листа `Расчет` после стабилизации расчетной модели.
