# OpenQuestions

Дата актуализации: 2026-09-21.

## Нормативные

- Закрыть вопросы из `docs/OpenNormativeQuestions.md`.
- Подтвердить актуальные редакции СП 35 и СП 63, которые используются как расчетная база проекта.
- Зафиксировать приоритет СП 35 над СП 63 для мостовых конструкций по каждому расчетному параметру, где нормы пересекаются.
- Подготовить независимые ручные контрольные примеры для трещин, устойчивости и несущей способности.

## Расчетные

- Проверить с внешними расчетными программами набор согласованных задач `N + Mx + My`.
- Продолжить анализ крайних случаев `UltimateStrain` и `LoadMultiplier` на сильно несимметричных сечениях.
- Уточнить рекомендуемые пользовательские значения `Capacity.MaxLambda`, `Capacity.ToleranceLambda`, `Capacity.ToleranceStrain` для разных классов задач.
- Отдельно оценить чувствительность `Calculation.ZeroMomentPerDepth` на малых эксцентриситетах и больших габаритах.

## Производительность

- Оценить повторное использование подготовленных материалов, свойств сечения и нагрузочных состояний между соседними расчетными ветками.
- Проверить влияние `Mesh.StepX`, `Mesh.StepY` и `Mesh.BoundarySubdivisions` на точность и время для крупных сечений.
- Продолжить оптимизацию расчета трещин без изменения последовательности нормативных проверок.

## Интерфейс И Данные

- Проверить AutoCAD import/export на реальных чертежах с разными UCS и пользовательскими слоями.
- Решить, нужен ли отдельный просмотр расчетной модели помимо `Results`.
- Уточнить, какие диагностические сообщения из отчета стоит дополнительно выводить пользователю в интерфейсе Excel.
