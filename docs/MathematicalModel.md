# Математическая модель

Статус: обновлено по результатам этапа 3.

## Скругленный прямоугольник

`CGeometryRoundedRectangle` задается шириной `b`, высотой `h`, четырьмя радиусами `rtl`, `rtr`, `rbr`, `rbl` и центром `(cx, cy)`.

Площадь для контроля:

```text
A = b * h - (1 - pi / 4) * (rtl^2 + rtr^2 + rbr^2 + rbl^2)
```

Для центра тяжести используется схема вычитания из полного прямоугольника четырех угловых областей: квадрат `r x r` минус четверть круга радиуса `r`.

## Принадлежность точки

Точка сначала проверяется по ограничивающему прямоугольнику. Затем для каждого скругленного угла проверяется, не попала ли точка в удаленную угловую область за пределами четверти окружности.

Граница включается в контур.

## Волоконная сетка

`CFiberMeshBuilder` строит регулярную сетку по ограничивающему прямоугольнику геометрии.

Для каждой ячейки:

- координата волокна принимается в центре ячейки;
- площадь волокна равна `stepX * stepY`;
- ячейка включается, если центр принадлежит сечению;
- `FillFactor = 1`;
- `MaterialID` передается параметром.

Частичное заполнение граничных ячеек на этапе 2 не реализовано.

## Геометрические характеристики

`CGeometryPropertiesCalculator` суммирует характеристики по волокнам:

```text
A    = sum(Ai)
Sx   = sum(Ai * yi)
Sy   = sum(Ai * xi)
xc   = Sy / A
yc   = Sx / A
Ix   = sum(Ai * yi^2)
Iy   = sum(Ai * xi^2)
Ixy  = sum(Ai * xi * yi)
Ixc  = Ix - A * yc^2
Iyc  = Iy - A * xc^2
Ixyc = Ixy - A * xc * yc
```

Главные центральные моменты:

```text
I1,2 = (Ixc + Iyc) / 2 +/- sqrt(((Ixc - Iyc) / 2)^2 + Ixyc^2)
```

Угол главных осей:

```text
alpha = 0.5 * atan2(-2 * Ixyc, Iyc - Ixc)
```

## Линейное ядро этапа 3

Поле деформаций:

```text
epsilon(x, y) = epsilon0 + kappaX * y + kappaY * x
```

Порядок неизвестных:

```text
q = [epsilon0, kappaX, kappaY]^T
```

Порядок правой части:

```text
F = [N, Mx, My]^T
```

Для бетонного волокна используется строка:

```text
B = [1, y, x]
```

Вклад бетонного волокна в матрицу:

```text
Kfiber = Eb * Area * transpose(B) * B
```

Матрица связывает параметры плоскости деформаций с усилиями:

```text
[N, Mx, My]^T = K * [epsilon0, kappaX, kappaY]^T
```

Структура матрицы:

```text
K11 = sum(E * A)
K12 = sum(E * A * y)
K13 = sum(E * A * x)
K21 = sum(E * A * y)
K22 = sum(E * A * y^2)
K23 = sum(E * A * y * x)
K31 = sum(E * A * x)
K32 = sum(E * A * x * y)
K33 = sum(E * A * x^2)
```

Для обычной ненапрягаемой арматуры применяется эффективный вклад, исключающий двойной учет бетона:

```text
Eeffective = Es - Eb
Kbar = Eeffective * As * transpose(Bs) * Bs
```

где:

```text
Bs = [1, ys, xs]
```

Дополнительная сила стержня при обратном расчете внутренних усилий:

```text
FbarAdditional = (Es - Eb) * epsilonS * As
```

Полное напряжение арматуры для диагностического вывода:

```text
sigmaS = Es * epsilonS
```

Этап 3 не содержит нормативных нелинейных диаграмм, предельных деформаций, трещиноватого сечения, поиска несущей способности, удерживающих моментов, коэффициентов запаса или коэффициентов использования.
