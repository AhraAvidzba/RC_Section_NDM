# Расчетная модель

## НДС

Единственная постановка - `N + Mx + My`. Одноосный изгиб получается при нулевом втором моменте. Единицы и перенос нагрузки описаны в [CoordinateSystem.md](CoordinateSystem.md).

Гипотеза плоских сечений:

```text
epsilon(x, y) = epsilon0 + kappaX * y + kappaY * x
```

Сила бетонного элемента равна `sigma_c(epsilon) * A_c`. Арматура замещает бетон на своей площади, поэтому ее добавка:

```text
F_s = (sigma_s(epsilon_s) - sigma_c(epsilon_s)) * A_s
```

Усилия суммируются по всем элементам:

```text
N  = sum(F)
Mx = sum(F * y)
My = sum(F * x)
```

Решатель находит epsilon0, kappaX и kappaY из равновесия. Newton использует касательную матрицу, ограничения приращений, демпфирование и line search; Secant - секущую схему с рестартами. Диаграммы материалов задаются расчетным профилем, а не типом геометрии.

Практически нулевые моменты определяются по `Mtol = Calculation.ZeroMomentPerDepth * h`: для Mx используется бетонный габарит по Y, для My - по X. Этот инженерный фильтр не заменяет численные допуски решателя.

## Универсальный путь нагрузки

Колонка LoadPath сочетания используется и для несущей способности, и для образования трещины:

```text
N(lambda)  = N0  + lambda * Nbase
Mx(lambda) = Mx0 + lambda * Mxbase
My(lambda) = My0 + lambda * Mybase
```

Постоянная часть не изменяется, масштабируемая задает направление поиска. При lambda = 1 получается исходное сочетание.

- λ*Mx или λ*My масштабирует соответствующий пользовательский момент.
- λ*Mxy масштабирует оба пользовательских момента, сохраняя N.
- λ*N масштабирует N вместе с моментами от ее эксцентриситета.
- λ*NMxy масштабирует все сочетание.
- Auto и пустое значение: при одной составляющей выбирается ее путь; при N + M сначала моментный, затем осевой, затем общий путь.

Два момента без N считаются одной моментной составляющей. Явный путь не меняется скрытно. Допустимая найденная граница, даже при lambda < 1, завершает поиск. Ошибки ввода не подменяются другой траекторией.

## Несущая способность

UltimateStrain ищет равновесную предельную плоскость деформаций; LoadMultiplier подбирает множитель пробными решениями НДС и уточняет границу методом Bisection, Brent или Secant.

Стратегия Auto сначала использует UltimateStrain, при численной неудаче - LoadMultiplier для того же пути. Для осевой силовой траектории сразу используется LoadMultiplier: на плато диаграммы сила может не задавать единственную плоскость деформаций.

Проверяются сжатие и растяжение бетона и стали; растяжение бетона активно только при включенной растянутой ветви. Физическая граница, отказ постоянной части, недостижимый критерий, численная несходимость и ограничение поиска имеют разные статусы.

## Трещины

Образование нормальной трещины проверяется с работающим растянутым бетоном; ширина и продольные трещины используют фактическое НДС сочетания без его работы. СП 35 и СП 63 используют общую геометрию, но разные формулы.

NotCracked исключает расчет ширины нормальной трещины, но не проверку продольных трещин. Неудача поиска точки образования сама по себе не блокирует раскрытие при пригодном текущем НДС. В СП 63 при недоступном уточнении используется psi_s = 1 с предупреждением только при вызове формулы; при NotCracked коэффициент не меняется. В СП 35 psi_s отсутствует.

В СП 35 каждая растянутая группа рассматривается отдельно. Другие группы включаются в ее конечную область по своим центрам, целиком; ряды нумеруются от бетонной границы к НЛ. Напряжения берутся из фактического НДС, а не из состояния образования трещины. Обозначения, параметры зон и формулы приведены в справке книги.

[Методический отчет СП 63](reports/methodology/CrackWidthMethodology_SP63.md) сохранен как исторический материал. Он не заменяет актуальную справку и [нормативную проверку](OpenNormativeQuestions.md).
