# Audit03: Ревизия ResultComment

Статус на 2026-10-02: содержательная ревизия продолжается. Это не финальная приемка.

## Проверяемые Контракты

- Читается каждый фактический leaf/meta, в том числе комментарий успешного результата.
- Отказы, блокировки и предупреждения требуют русской причины с указанием расчетной стадии.
- Strength, Crack и Stability получают только комментарии своего subtree; Batch получает их согласованную совокупность.
- Writers и txt-report выводят готовые комментарии, не назначают статусы по тексту и не придумывают инженерные причины.
- Полная причина сохраняется в зависимом leaf. В сводном Crack/Batch одна общая причина текущего НДС не должна повторяться для каждой blocked-проверки.
- Auto сохраняет причины предыдущих путей и фактически принятый путь; fixed path не подменяется другим.
- Проверяются реальные четыре output-блока, execution report и сохраненный/повторно открытый Results.
