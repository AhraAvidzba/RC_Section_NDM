# WorkbookLayout

Дата актуализации: 2026-08-14.

## Книга

Итоговая книга:

```text
workbook/output/RC_Section_NDM.xlsm
```

Сборка:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Build-Workbook.ps1
```

## Лист `Расчет`

| Область | Диапазон | Назначение |
|---|---|---|
| Сочетания нагрузок | `rngLoadCombinations = Config!O3:U23` | до 20 сочетаний `N + Mx + My`; `CalculationType = Group1` запускает расчет по первой группе, `Group2` - расчет трещин по второй группе; `CapacityLoadPath` задает λ-траекторию поиска несущей способности |
| Единый результат | `rngResultSection = Расчет!S17:AH35` | результат определяющего сочетания |
| Кнопки | вне печатной области | запуск расчета, очистка результатов, экспорт в AutoCAD, обновление схемы |
| Схема сечения | ChartObject `chtNDMSectionPlot` на листе `Расчет`, первично создается около столбца `AP` | пользователь может перемещать и менять размер схемы; при обновлении перерисовывается содержимое внутри существующего ChartObject |

Отдельных пользовательских блоков `Mx`, `My`, `Mxy` нет. Одноосные случаи задаются в той же таблице сочетаний при `Mx = 0` или `My = 0`.

## Лист `Config`

| Область | Диапазон | Назначение |
|---|---|---|
| Единицы измерения | `rngUnitSettings` | отдельный блок `Quantity / INPUT / INTERNAL / OUTPUT`; `INPUT` и `OUTPUT` выбираются из списков |
| Правила знаков | `rngSignConventionSettings` | отдельный блок пользовательских знаков `+N`, `+Mx`, `+My` для ввода и вывода |
| Общие настройки | `rngSystemSettings` | источник геометрии, сетка, материалы, решатели, несущая способность, трещины, AutoCAD |
| Круг | `rngCircleGeometry` | диаметр и автоматическая арматура круглого сечения |
| Скругленный прямоугольник | `rngRoundedRectangleGeometry` | размеры и радиусы углов |
| Г-сечение | `rngLShapeGeometry` | размеры и автоматическая арматура по граням |
| Параметры бетона | `rngConcreteMaterialParameters` | расчетные сопротивления и модули бетона для I/II ГПС; по ним строятся диаграммы |
| Параметры арматуры | `rngSteelMaterialParameters` | расчетные сопротивления, модули и профиль арматуры для I/II ГПС |
| Настройки диаграмм | `rngCalculationDiagramSettings` | выбор TwoLine/ThreeLine и режима растянутого бетона для Strength, Mcrc и CrackedNDS |

В колонке `Ед.` у входных настроек используются формулы Excel, которые подтягивают выбранную пользователем единицу `INPUT` из `rngUnitSettings`. Например, для нагрузок в `rngLoadCombinations` по умолчанию выводятся `N, tf`, `Mx, tf*m`, `My, tf*m`.

Контрольные таблицы точек диаграмм на `Config` являются проверочным выводом формул Excel. Расчетное ядро их не читает: рабочие диаграммы строит `CMaterialModelProvider` по параметрам материалов и `rngCalculationDiagramSettings`.

Контрольная таблица арматуры и формульный блок трещин на `Config` больше не являются частью интерфейса. Расчетная геометрия живет в `CSectionModel`; при необходимости ее можно позже вывести на отдельный просмотр, но лист Excel не является источником геометрии для ядра.

## Лист `Results`

| Область | Диапазон | Назначение |
|---|---|---|
| Сводка batch-расчета | `rngBatchSummary = Results!A1:AY31` | определяющее сочетание, прямое НДС, единый блок предельной несущей способности по `CapacityLoadPath` и блок трещин до 20 сочетаний |
| Результаты НДМ по элементам | `rngNDMElementResults = Results!A34` | LC-зависимые данные: `RunID`, `LoadCase`, `ElementID`, `Strain`, `Stress`, `PhysicalState` |
| Расчетная геометрия | `rngNDMSectionGeometry = Results!I34` | постоянные данные snapshot: `ElementID`, тип материала, координаты, площадь, размеры/диаметр и локальные моменты инерции |
| Свойства всего сечения | `rngNDMSectionProperties = Results!Z34` | Bounds, центр тяжести, главные оси, output-единицы snapshot, `Epsilon0/KappaX/KappaY`, точка приложения нагрузки и другие свойства уровня LC |
| Аннотации сечения | `rngNDMSectionAnnotations = Results!AH34` | сохраненные размерные линии и групповые подписи арматуры для восстановления схемы без повторного расчета |

Все переменные по высоте таблицы на `Results` расположены горизонтально в одной строке под `rngBatchSummary`. Между нижней границей `rngBatchSummary` и заголовками нижних диапазонов оставлены две пустые строки. Между концом каждой нижней таблицы и следующим якорем оставлены два пустых столбца, поэтому увеличение количества строк в одной таблице не может перекрыть соседний блок.

Все таблицы `Results` перезаписываются после успешного расчета блочной записью массивов и образуют единый snapshot. AutoCAD export и Excel-схема читают именно эти таблицы, а не пересобирают расчетную модель заново.

## Источник Геометрии

`Geometry.Source` задается в `rngSystemSettings`:

- `Generated` - использовать встроенные генераторы по `Geometry.Type`;
- `AutoCAD` - импортировать расчетную сетку из активного AutoCAD-чертежа.

Для AutoCAD-импорта используются только объекты `Region` на слоях:

- `AutoCAD.Import.ConcreteLayer`;
- `AutoCAD.Import.RebarLayer`.

Единицы AutoCAD считаются миллиметрами.

## `rngLShapeGeometry`

Таблица Г-сечения:

```text
Параметр | H1 | B1 | H2 | B2 | Ед. | Комментарий
```

`H1/B1` задают верхний прямоугольник, `H2/B2` задают нижний прямоугольник. Полная высота сечения равна `H1 + H2`.

Суффикс `_1` означает левую грань для `H*` или верхнюю грань для `B*`. Суффикс `_2` означает правую грань для `H*` или нижнюю грань для `B*`. Нумерация граней идет слева направо и сверху вниз.

## Устаревшие Диапазоны

Не должны создаваться:

```text
rngSystemDiagnostics
rngMainInput
rngRebarInput
rngResultMx
rngResultMy
rngResultMxy
```

Обязательные актуальные диапазоны единиц и знаков:

```text
rngUnitSettings
rngSignConventionSettings
```
