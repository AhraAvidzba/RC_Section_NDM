# WorkbookLayout

## Книга

workbook/output/RC_Section_NDM.xlsm

## Лист `Расчет`

| Область | Диапазон | Назначение |
|---|---|---|
| Сочетания нагрузок | `rngLoadCombinations = Config!O3:U23` | таблица `N + Mx + My`; число сочетаний равно числу строк внутри именованного диапазона, в шаблоне подготовлено 20 строк, минимально допустима 1 строка сочетания; `CapacityLoadPath` задает λ-траекторию поиска несущей способности |
| Кнопки | вне печатной области | запуск расчета, очистка результатов, экспорт в AutoCAD, обновление схемы |
| Схема сечения | ChartObject `chtNDMSectionPlot` на листе `Расчет`, первично создается около столбца `AP` | пользователь может перемещать и менять размер схемы; при обновлении перерисовывается содержимое внутри существующего ChartObject |

Отдельного численного результата на лист `Расчет` больше не пишем: все расчетные
данные сохраняются в snapshot на `Results`, а лист `Расчет` остается поверхностью
для кнопок и Excel-схемы. Отдельных пользовательских блоков `Mx`, `My`, `Mxy`
нет. Одноосные случаи задаются в той же таблице сочетаний при `Mx = 0` или `My = 0`.

## Лист `Config`

| Область | Диапазон | Назначение |
|---|---|---|
| Единицы измерения | `rngUnitSettings` | отдельный блок `Quantity / INPUT / INTERNAL / OUTPUT`; `INPUT` и `OUTPUT` выбираются из списков |
| Правила знаков | `rngSignConventionSettings` | отдельный блок пользовательских знаков `+N`, `+Mx`, `+My` для ввода и вывода |
| Общие настройки | `rngSystemSettings` | источник геометрии, сетка, материалы, решатели, несущая способность, трещины, AutoCAD |
| Круг | `rngCircleGeometry` | диаметр и автоматическая арматура круглого сечения |
| Скругленный прямоугольник | `rngRoundedRectangleGeometry` | размеры и радиусы углов |
| Г-сечение | `rngLShapeGeometry` | размеры и автоматическая арматура по граням |
| Параметры бетона | `rngConcreteMaterialParameters` | расчетные сопротивления и модули бетона для I/II ГПС, `Rb,mc2` для продольных трещин; по ним строятся диаграммы |
| Параметры арматуры | `rngSteelMaterialParameters` | расчетные сопротивления, модули и профиль арматуры для I/II ГПС |
| Настройки диаграмм | `rngCalculationDiagramSettings` | выбор TwoLine/ThreeLine и режима растянутого бетона для Strength, CrackInitiation и CrackedNDS |

В колонке `Ед.` у входных настроек используются формулы Excel, которые подтягивают выбранную пользователем единицу `INPUT` из `rngUnitSettings`. Например, для нагрузок в `rngLoadCombinations` по умолчанию выводятся `N, tf`, `Mx, tf*m`, `My, tf*m`.

Количество сочетаний меняется обычным изменением высоты таблицы на `Config`. Чтобы добавить строку, расширьте именно область `rngLoadCombinations`: например выделите нижнюю строку диапазона и сдвиньте ее вниз с сохранением пунктирной границы, либо измените адрес диапазона через `Формулы -> Диспетчер имен`. Не вставляйте целую строку листа, если рядом расположены другие таблицы. Чтобы уменьшить число доступных строк, удаляйте строки внутри диапазона, но оставьте минимум одну строку под заголовком. Если после расширения таблицы на `Results` не хватает места, расчет остановится до очистки старого snapshot. Для верхних блоков нужно сдвинуть вниз `rngStrengthSummaryAnchor`, `rngCrackSummaryAnchor`, `rngStabilitySummaryAnchor` и/или `rngNDMElementResults`; для правых snapshot-блоков - `rngNDMSectionGeometry`, `rngNDMSectionProperties`, `rngNDMMaterialDiagrams`, `rngNDMSectionAnnotations`.

Контрольные таблицы точек диаграмм на `Config` являются проверочным выводом формул Excel. Расчетное ядро их не читает: рабочие диаграммы строит `CMaterialModelProvider` по параметрам материалов и `rngCalculationDiagramSettings`.

Контрольная таблица арматуры и формульный блок трещин на `Config` больше не являются частью интерфейса. Расчетная геометрия живет в `CSectionModel`; при необходимости ее можно позже вывести на отдельный просмотр, но лист Excel не является источником геометрии для ядра.

## Лист `Results`

| Область | Диапазон | Назначение |
|---|---|---|
| Сводка batch-расчета | `rngBatchSummary = Results!A1` | компактный итог по сочетаниям: прямое НДС, несущая способность, нормальные и продольные трещины; высота расширяется под фактическое число LC, если на Results достаточно места |
| Подробная прочность | `rngStrengthSummaryAnchor = Results!A38` | якорь первой строки данных отдельной таблицы НДС и несущей способности по модели прочности; шапка формируется над якорем |
| Подробные трещины | `rngCrackSummaryAnchor = Results!A64` | якорь первой строки данных отдельной таблицы нормальных и продольных трещин; шапка формируется над якорем |
| Подробная устойчивость | `rngStabilitySummaryAnchor = Results!A91` | якорь первой строки данных отдельной таблицы продольного изгиба и устойчивости с блоками СП 35 и СП 63 |
| Результаты НДМ по элементам | `rngNDMElementResults = Results!A115` | LC-зависимые данные: `RunID`, `LoadCase`, `ProfileId`, `StateType`, `ElementID`, `Strain`, `Stress`, `PhysicalState` |
| Расчетная геометрия | `rngNDMSectionGeometry = Results!L115` | постоянные данные snapshot: `ElementID`, тип материала, координаты, площадь, размеры/диаметр и локальные моменты инерции |
| Свойства всего сечения | `rngNDMSectionProperties = Results!AC115` | Bounds, центр тяжести, главные оси, output-единицы snapshot, `Epsilon0/KappaX/KappaY`, `ConcreteDiagramId`/`RebarDiagramId`, точка приложения нагрузки и другие свойства уровня LC |
| Фактические диаграммы материалов | `rngNDMMaterialDiagrams = Results!AK115` | уникальный каталог контрольных точек диаграмм, реально переданных solver-ам для сохраненных `ProfileId`/`StateType`/`MaterialModelSpec` |
| Аннотации сечения | `rngNDMSectionAnnotations = Results!AX115` | сохраненные размерные линии и групповые подписи арматуры для восстановления схемы без повторного расчета |

Верхняя сводка остается короткой. Под ней отдельными широкими блоками выводятся подробная прочность, подробные трещины и подробная устойчивость, а ниже, начиная со 115 строки, горизонтально расположены таблицы расчетного snapshot. Перед нижними snapshot-таблицами есть общая синяя строка-раздел с описанием содержимого. Между `rngBatchSummary`, шапкой `rngStrengthSummaryAnchor`, шапкой `rngCrackSummaryAnchor`, шапкой `rngStabilitySummaryAnchor` и нижним snapshot должны оставаться две чистые строки; эти строки не считаются строками сочетаний. Между концом каждой нижней таблицы и следующим якорем оставлены два пустых столбца, поэтому увеличение количества строк в одной таблице не может перекрыть соседний блок. Последним правым блоком остается `rngNDMSectionAnnotations`.

Все таблицы `Results` перезаписываются после успешного расчета блочной записью массивов и образуют единый snapshot. AutoCAD export и Excel-схема читают именно эти таблицы, а не пересобирают расчетную модель заново.

## Источник Геометрии

`Geometry.Source` задается в `rngSystemSettings`:

- `Generated` - использовать встроенные генераторы по `Geometry.Type`;
- `AutoCAD` - импортировать расчетную сетку из активного AutoCAD-чертежа.

Для AutoCAD-импорта используются только объекты `Region` на слоях:

- `AutoCAD.Import.ConcreteLayer`;
- `AutoCAD.Import.RebarLayer`.

Единицы AutoCAD считаются миллиметрами.

## `rngLShapeGeometry`

Таблица Г-сечения:

```text
Параметр | H1 | B1 | H2 | B2 | Ед. | Комментарий
```

`H1/B1` задают верхний прямоугольник, `H2/B2` задают нижний прямоугольник. Полная высота сечения равна `H1 + H2`.

Суффикс `_1` означает левую грань для `H*` или верхнюю грань для `B*`. Суффикс `_2` означает правую грань для `H*` или нижнюю грань для `B*`. Нумерация граней идет слева направо и сверху вниз.

## Устаревшие Диапазоны

Не должны создаваться:

```text
rngSystemDiagnostics
rngMainInput
rngRebarInput
rngResultMx
rngResultMy
rngResultMxy
```

Обязательные актуальные диапазоны единиц и знаков:

```text
rngUnitSettings
rngSignConventionSettings
```
