# PROJECT_STATUS

Дата актуализации: 2026-09-21.

## Текущий Статус

Проект находится в состоянии рабочей инженерной Excel VBA-программы. Расчетное ядро, книга, импорт/экспорт AutoCAD, подробные результаты, отчет и регрессионные тесты поддерживают текущую постановку `N + Mx + My`. Окончательная нормативная верификация остается инженерной задачей: все спорные места должны сверяться с локальными документами `norms/` и фиксироваться в `docs/OpenNormativeQuestions.md`.

## Реализовано

| Область | Состояние |
|---|---|
| Книга Excel | `workbook/output/RC_Section_NDM.xlsm`, листы `Config`, `Справка`, `Расчет`, `Results` |
| Ввод | все настройки и контрольные таблицы на `Config`; сочетания нагрузок задаются в `rngLoadCombinations` |
| Геометрия | `Circle`, `RectSet`, `RoundedRectangle`, `HollowRectangle`, AutoCAD `Region` |
| Арматура | автоматическая расстановка для параметрических сечений, дополнительные ряды, трассировка имен стержней |
| Волокна | бетонная сетка с `Mesh.StepX`, `Mesh.StepY`, `Mesh.BoundarySubdivisions` |
| Материалы | TwoLine/ThreeLine-диаграммы по параметрам бетона, арматуры и расчетному режиму |
| Прямой расчет | `CSectionSolver`, режимы `Newton` и `Secant`, единый счетчик вызовов решения равновесия |
| Несущая способность | универсальная λ-траектория `CapacityLoadPath`: `λ*Mx`, `λ*My`, `λ*Mxy`, `λ*N`, `λ*NMxy`; стратегии `Auto`, `UltimateStrain`, `LoadMultiplier` |
| Трещины | проверка образования нормальной трещины, расчет ширины нормальных трещин, проверка продольных трещин, пути `Auto`, `λ*Mxy`, `λ*N`, `λ*NMxy` |
| Устойчивость | расчет по СП 63 и СП 35, случайный эксцентриситет, `phi_l`, табличная ветвь СП 35 и ветвь `eta` |
| Batch | число сочетаний берется из высоты `rngLoadCombinations`; шаблон по умолчанию содержит 30 строк |
| Results | сводка, подробные блоки прочности, трещин и устойчивости, геометрия, элементы, свойства и аннотации |
| AutoCAD | импорт `Region`, экспорт геометрии, контура, арматуры, осей, нейтральной линии и результатов |
| Схема Excel | построение по последнему снимку `Results` без повторного запуска решателя |
| Тесты | PowerShell-обертки `Validate-Workbook.ps1`, `Run-AllTests.ps1` и специализированные VBA-тесты |

## Не Поддерживается

- напрягаемая арматура;
- ручной ввод координат арматуры на листе `Расчет`;
- отдельные пользовательские режимы `SolveMx`, `SolveMy`, `SolveMxy`;
- самостоятельный пользовательский расчет `Mcrc`/`Ncrc` вне `Calculation.Crack.Width`;
- восстановление точного контура произвольной импортированной AutoCAD-геометрии, если контур не задан параметрически.

## Важные Решения

- Расчет ведется только в общей постановке `N + Mx + My`.
- Все входные значения переводятся в расчетные единицы через `CUnitSystem`.
- Математика переноса нагрузок и фильтр практически нулевого момента сосредоточены в общем слое работы с нагрузками.
- Реальные `Area/Ix/Iy/Ixy` импортированных элементов используются в механических расчетах; `Width/Height/Rotation` являются только геометрической оболочкой для границ, схемы и AutoCAD.
- `Capacity.MaxLambda` ограничивает расширение скобки `LoadMultiplier`; `UltimateStrain` не обрезает уже найденный множитель этой настройкой.
- Сводка `rngBatchSummary` выбирает худшее сочетание по настройке `General.WorstCombinationCriterion`; схема и AutoCAD берут то же сочетание.
