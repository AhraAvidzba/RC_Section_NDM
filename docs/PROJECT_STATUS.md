# PROJECT_STATUS

Дата актуализации: 2026-08-05.

## Текущий статус

Проект находится в состоянии рабочего инженерного прототипа. Реализованы расчетное ядро, сборка книги, пользовательский запуск из Excel и регрессионные тесты. Окончательная нормативная верификация по СП 35 и СП 63 не завершена.

## Реализовано

| Область | Состояние |
|---|---|
| Книга Excel | `workbook/output/RC_Section_NDM.xlsm`, листы `Config`, `Справка`, `Расчет`, `Results` |
| Ввод | настройки только на `Config`; сочетания нагрузок на `Расчет` |
| Геометрия | `Circle`, `RoundedRectangle`, `LShape` |
| Арматура | автоматическая расстановка для круга и Г-сечения, включая дополнительные ряды |
| Волокна | сетка бетона с `Mesh.BoundarySubdivisions` |
| Материалы | TwoLine/ThreeLine-диаграммы по параметрам бетона, арматуры и расчетного режима |
| Прямой расчет | `CSectionSolver`, режимы `Newton` и `Secant` |
| Несущая способность | универсальная λ-траектория `CapacityLoadPath`: `λ*Mx`, `λ*My`, `λ*Mxy`, `λ*N`, `λ*NMxy`; доступны `Auto`, `UltimateStrain`, `LoadMultiplier` |
| Одномерный поиск | `Bisection`, `Brent`, `Secant` для `LoadMultiplier` и fallback-ветки `Auto` по выбранной λ-траектории |
| Трещины | расчет ширины уже образовавшихся нормальных трещин |
| Batch | до 20 сочетаний в одном запуске |
| AutoCAD | экспорт волокон, арматуры и напряжений; импорт расчетной сетки из Region |
| Тесты | PowerShell-обертки `Run-*.ps1`, общий запуск `Run-AllTests.ps1` |

## Не реализовано

- новые геометрии кроме круга, скругленного прямоугольника и Г-сечения;
- ручная расстановка арматуры через лист `Расчет`;
- напрягаемая арматура;
- расчет образования трещин и `Mcrc`;
- окончательно подтвержденные нормативные формулы для всех диаграмм и коэффициентов трещин;
- единый объект `ResultData` как отдельный лист или класс-DTO.

## Важные архитектурные решения

- Расчет ведется только в общей постановке `N + Mx + My`.
- `Mx` и `My` являются компонентами вектора моментов, а не отдельными режимами.
- Все настройки берутся с `Config`; расчетное ядро не читает Excel-листы.
- Материалы задаются параметрами I/II ГПС; готовые TwoLine/ThreeLine-диаграммы создает `CMaterialModelProvider`.
- `Capacity.MaxLambda` является защитным верхним пределом; при слишком малом заданном базовом моменте для `UltimateStrain` может потребоваться увеличить этот предел.
- `rngBatchSummary` расположен на `Results!A1:CU29`.
