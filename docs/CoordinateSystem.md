# Система координат

Статус: обновлено по результатам этапа 3.

## Локальная система

- ось `X` направлена вправо;
- ось `Y` направлена вверх;
- координаты задаются в мм;
- геометрия `CGeometryRoundedRectangle` по умолчанию центрируется в точке `(0, 0)`;
- необязательные параметры `centerX`, `centerY` смещают локальный центр сечения.

## Знаки геометрических характеристик

На этапе 2 определены только геометрические величины:

```text
Area = sum(Ai)
Sx   = sum(Ai * yi)
Sy   = sum(Ai * xi)
Ix   = sum(Ai * yi^2)
Iy   = sum(Ai * xi^2)
Ixy  = sum(Ai * xi * yi)
```

Центральные моменты:

```text
Ixc  = Ix  - Area * yc^2
Iyc  = Iy  - Area * xc^2
Ixyc = Ixy - Area * xc * yc
```

## Знаки линейного ядра

На этапе 3 принята плоскость деформаций:

```text
epsilon(x, y) = epsilon0 + kappaX * y + kappaY * x
```

Положительное `epsilon0` соответствует растяжению. Положительная `kappaX` увеличивает деформацию при положительном `Y`. Положительная `kappaY` увеличивает деформацию при положительном `X`.

Внутренние усилия суммируются так:

```text
Nint  = sum(Fi)
Mxint = sum(Fi * yi)
Myint = sum(Fi * xi)
```

В линейных тестах положительные `Mx` и `My` соответствуют положительным кривизнам `kappaX` и `kappaY` для симметричного сечения с нулевым `Ixy`.

## Граница сечения

`ContainsPoint(x, y)` считает точки на границе принадлежащими сечению с учетом допуска `GEOM_TOLERANCE`.

## Единицы

Внутренние единицы соответствуют требованиям проекта:

- длина - мм;
- площадь - мм2;
- геометрические моменты инерции - мм4;
- сила - Н;
- момент - Н*мм;
- напряжение - МПа, то есть Н/мм2;
- деформация - безразмерная;
- кривизна - 1/мм.

Линейное ядро этапа 3 использует только эти внутренние единицы.
