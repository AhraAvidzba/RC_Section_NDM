# Проверки

## Объем

Документация требует проверки ссылок и Git diff. Оформление и локальное поведение - направленных проверок. Расчетные изменения проверяются с учетом влияния на НДС, поиск предела, материалы, геометрию, единицы, знаки и результаты.

Не запускать тяжелый полный набор после каждой мелкой правки. Самые долгие полные on/off и Excel UI прогоны требуют отдельного явного согласия пользователя в чате с указанием состава и длительности.

## Команды

Скрипты находятся в `tools/build_workbook/` и запускаются из корня проекта.

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Validate-Workbook.ps1
```

Направленные наборы: `Run-GeometryTests.ps1`, `Run-MaterialTests.ps1`, `Run-SectionSolverTests.ps1`, `Run-CapacityTests.ps1`, `Run-CrackTests.ps1`, `Run-SP35FocusedTests.ps1`, `Run-BatchTests.ps1`, `Run-WorkbookInterfaceTests.ps1`, `Run-RegressionBaselineTests.ps1`.

Полный набор, только после согласования:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Run-AllTests.ps1
```

`Build-Workbook.ps1` создает книгу с настройками шаблона; пользовательскую книгу проверять на отдельной копии. Завершать только собственные проверенные процессы Excel/AutoCAD, не все окна общей командой.

## Контроль

- VBA компилируется; модули совпадают с книгой и `VBA_All_Code.txt`.
- Диапазоны, списки и правая рамка Справки сохраняются после сборки.
- Все затронутые LoadPath проверены отдельно; физический отказ отличен от численной ошибки.
- ResultComment правильно заполнен и объединен, сообщения указывают актуальные адреса настроек.
- Результаты сохраняются при смене единиц и знаков; экспорт геометрии всегда в мм.
- Контуры и несколько отверстий одинаково обрабатываются при генерации и импорте; все четыре правила выбора области соблюдаются.
- AutoCAD проверяется в AutoCAD, не SofiPLUS: WCS, Region/Polyline, отверстия, повороты, временные объекты и безопасная очистка.
- Runtime не меняет ширину столбцов Results; перенос в данных отключен, шапки сохранены.
- Скорость сравнивается на одинаковых входах; ускорение принимается при неизменных результатах и диагностике.

## Доказательства

Итоговые отчеты: [reports/](reports/README.md). Логи и машинные данные: `docs/regression/` и `docs/NDM_Audit03_*Evidence.json`.

Промежуточные результаты и тестовые копии исключены через .gitignore. Новые приемочные доказательства в `docs/regression/` добавлять осознанно по конкретным путям через `git add -f`; ранее сохраненные материалы остаются отслеживаемыми.

Baseline менять только с инженерным объяснением. Независимая нормативная сверка, ручные примеры и сравнение с внешними программами остаются отдельными проверками: [OpenNormativeQuestions.md](OpenNormativeQuestions.md).
