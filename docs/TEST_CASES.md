# TEST_CASES

Дата актуализации: 2026-09-21.

## Общая Постановка

Все расчетные тесты используют единую задачу:

```text
N + Mx + My
```

Одноосные случаи проверяются как частные случаи при нулевой второй компоненте момента. Отдельных методов `SolveMx`, `SolveMy`, `SolveMxy` нет.

## Геометрия И CSectionModel

Проверяются:

- `Circle`;
- `RectSet` в режимах `Rectangle`, `LSection`, `TwoRectangles`;
- `RoundedRectangle` с прямыми и криволинейными участками;
- `HollowRectangle` с внешним контуром и Opening;
- дробление граничных ячеек через `Mesh.BoundarySubdivisions`;
- прямоугольные и квадратные элементы сетки через `Mesh.StepX`/`Mesh.StepY`;
- автоматическая арматура и дополнительные ряды для параметрических сечений;
- пропуск неактивных граней и рядов;
- единая сборка `CSectionModel` из встроенной сетки и арматуры;
- импорт AutoCAD Region в `CSectionModel` на мок-данных без запущенного AutoCAD;
- приоритет реальных `Area/LocalIx/LocalIy/LocalIxy` над геометрической оболочкой элемента.

Для `CSectionModel` зафиксировано:

- расчетные ID `C1`, `C2`, `R1`, `R2`;
- сохранение исходных имен и handles как трассировочных полей;
- fallback локальных инерций только при полном отсутствии реальных данных;
- согласованная оболочка `Width/Height/Rotation` для границ, схемы и AutoCAD.

## Настройки И UI

Проверяются:

- обязательные именованные диапазоны;
- отсутствие устаревших имен;
- чтение `rngSystemSettings`, `rngUnitSettings`, `rngSignConventionSettings`;
- загрузка активного геометрического диапазона по `Geometry.Type`;
- выбор источника геометрии по `Geometry.Source`;
- динамическое число сочетаний по высоте `rngLoadCombinations`;
- минимум одна строка сочетания;
- проверка места на `Results` с учетом шапок и двух пустых строк между блоками;
- выпадающие списки для поддерживаемых вариантов;
- пользовательские названия профилей в списке профилей сочетаний;
- запись batch summary и подробных блоков на `Results`;
- Excel-схема по последнему snapshot без повторного запуска решателя.

## Единицы, Знаки И Нагрузки

Проверяются:

- преобразование `INPUT -> INTERNAL -> OUTPUT`;
- дефолтный ввод нагрузок в `tf` и `tf*m`;
- пользовательский знак `+N = Compression` при внутреннем `+N = Tension`;
- перенос нагрузок между точкой приложения, центром бетонного сечения и центром приведенного сечения;
- фильтр практически нулевого момента `Calculation.ZeroMomentPerDepth`;
- нулевые моменты после поворота и переноса, включая остатки порядка `1E-16`;
- чистое сжатие, чистое растяжение, чистый изгиб, внецентренное сжатие и внецентренное растяжение.

## Решатели И Несущая Способность

Регрессия покрывает:

- `CSectionSolver` с `Newton`;
- `CSectionSolver` с `Secant`;
- централизованный счетчик вызовов `CSectionSolver`;
- `CCapacitySolver.SolveByLoadPathMultiplier`;
- `CCapacitySolver.SolveByUltimateLoadPath`;
- `Capacity.SolutionStrategy = Auto`;
- пути `λ*Mx`, `λ*My`, `λ*Mxy`, `λ*N`, `λ*NMxy`;
- одномерные методы `Bisection`, `Brent`, `Secant`;
- опасные осевые и почти осевые случаи, где требуется правильный выбор стартовой плоскости или fallback.

Численная несходимость проверяется как отдельный статус, а не как физическое разрушение.

## Трещины

Проверяются:

- обязательный расчет `CrackedState` для сочетаний с включенными трещинами;
- проверка образования нормальной трещины;
- пути `SLS.Crack.InitiationLoadPath`: `Auto`, `λ*Mxy`, `λ*N`, `λ*NMxy`;
- автоматическое переключение путей в режиме `Auto`;
- `BeforeMcrcState` и `AfterMcrcState`, когда точка образования трещины найдена;
- отсутствие этих состояний с понятным статусом, когда нет действия, способного вызвать нормальную трещину;
- режимы `SLS.Crack.PsiMode = User`, `Auto` и `AlwaysCalc`;
- расчет `a_s` по ближайшему контуру и по глобальной крайней точке;
- продольные трещины независимо от факта образования нормальной трещины.

## Устойчивость

Проверяются:

- расчет по СП 63 и СП 35;
- случайный эксцентриситет с `AutoWithL`, `AutoWithMuL`, `User`;
- режимы `Stability.AccidentalEccentricityPlanes = OnlyMomentPlane` и `BothPlanes`;
- обязательные положительные `Mu1/Mu2`;
- условие применения `eta` по СП 63 при `l0/i > 14`;
- табличная ветвь СП 35 при `ec/r <= 1`;
- ветвь СП 35 через `Ncr/eta` при `ec/r > 1`;
- запас по ограничению `Stability.SP35.NOverNcrLimit * Ncr / N`;
- остановка дальнейшей расчетной цепочки при FAIL устойчивости.

## AutoCAD И Схема

Проверяются:

- импорт бетонных и арматурных `Region`;
- независимость локальных инерций от положения Region в чертеже;
- получение угла изотропного элемента по прямой грани;
- экспорт геометрии, арматуры, осей, нейтральной линии, точки нагрузки и параметрического контура;
- совпадение координат схемы Excel и AutoCAD export по сохраненному snapshot;
- подписи осей X/Y и переключатели вывода контура.

## Отчеты

Численные baseline-результаты и отчеты тестов хранятся в `docs/regression/`. При изменении расчетной математики обновление baseline должно выполняться осознанно, с указанием причины изменения.
