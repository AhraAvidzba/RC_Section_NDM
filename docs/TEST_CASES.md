# TEST_CASES

Дата актуализации: 2026-08-14.

## Общая Постановка

Все расчетные тесты используют единую задачу:

```text
N + Mx + My
```

Одноосные случаи проверяются как частные случаи:

```text
N + Mx, My = 0
N + My, Mx = 0
```

Отдельных методов `SolveMx`, `SolveMy`, `SolveMxy` в целевой архитектуре нет.

## Геометрия И CSectionModel

Проверяются:

- прямоугольник через `CGeometryRoundedRectangle` без радиусов;
- скругленный прямоугольник;
- круг;
- Г-сечение `CGeometryLShape`;
- дробление граничных ячеек через `Mesh.BoundarySubdivisions`;
- автоматическая арматура круга и Г-сечения;
- дополнительные ряды арматуры;
- пропуск граней или рядов без первого ряда;
- единая сборка `CSectionModel` из встроенной сетки и арматуры;
- импорт AutoCAD Region в `CSectionModel` на мок-данных без запущенного AutoCAD.

Для `CSectionModel` зафиксировано:

- количество бетонных и арматурных элементов;
- расчетные ID `C1`, `R1`;
- сохранение исходного имени стержня в `RebarSourceName`;
- расчет площади стержня по диаметру.

## Настройки И UI

Проверяются:

- наличие обязательных именованных диапазонов;
- наличие отдельных диапазонов `rngUnitSettings` и `rngSignConventionSettings`;
- отсутствие устаревших имен;
- загрузка `rngSystemSettings`;
- загрузка единиц и знаков до чтения сочетаний, геометрии, материалов и настроек решателей;
- загрузка активного геометрического диапазона по `Geometry.Type` для `Geometry.Source = Generated`;
- выбор источника геометрии по `Geometry.Source`;
- выпадающие списки только для поддерживаемых вариантов;
- пропуск полностью пустых сочетаний;
- ошибка для частично заполненного сочетания;
- пользовательский запуск расчета для круга и Г-сечения;
- запись результатов в `rngResultSection`;
- запись batch summary в `rngBatchSummary`;
- отсутствие старого контрольного вывода арматуры и формульного блока трещин на `Config`.

## Единицы И Знаки

Проверяются:

- выпадающие списки единиц для `Force`, `Moment`, `Stress` и других величин;
- выпадающий список пользовательского знака `+N`;
- дефолтный ввод нагрузок в `tf` и `tf*m`;
- преобразование `INPUT -> INTERNAL -> OUTPUT` для силы, момента, длины, площади, напряжения и кривизны;
- знак `+N = Compression` на пользовательском вводе и внутреннее `+N = Tension`;
- динамические подписи единиц в `rngLoadCombinations` и таблицах точек диаграмм;
- неизменность физического результата при смене пользовательских единиц и знаков.

## Решатели

Регрессия покрывает:

- `CSectionSolver` с `Newton`;
- `CSectionSolver` с `Secant`;
- `CCapacitySolver.SolveByLoadMultiplier`;
- `CCapacitySolver.SolveByUltimateStrain`;
- одномерные методы поиска `Bisection`, `Brent`, `Secant`;
- `CCrackWidthCalculator`;
- `CBatchSectionCalculator`.

Ключевой архитектурный тест: решатели и batch-слой получают `CSectionModel`, а не `CFiberMeshBuilder` и `CRebarLayout`.

## Координаты И Перенос Начала

Проверяются:

- чистое сжатие;
- `N + Mx` при `My = 0`;
- `N + My` при `Mx = 0`;
- полный `N + Mx + My`;
- симметрия круглого сечения;
- повторный запуск;
- изменение геометрии;
- инвариантность кривизн при переносе начала координат;
- корректное преобразование `N`, `Mx`, `My` при переносе.
