# IMPLEMENTATION_PLAN

Дата актуализации: 2026-08-14.

## Правила Развития

1. Не возвращать отдельные расчетные ветви `Mx`, `My`, `Mxy`.
2. Все расчеты вести в единой постановке `N + Mx + My`.
3. Расчетное ядро не читает Excel-листы и не знает источник геометрии.
4. Единственный контракт геометрии для ядра - `CSectionModel`.
5. Не добавлять временные совместимые обертки, возвращающие решатели к старому контракту `mesh + rebars`.
6. После изменений кода запускать релевантные тесты; для крупных задач - `Run-AllTests.ps1`.

## Реализовано

- Геометрии `Circle`, `RoundedRectangle`, `LShape`.
- Автоматическая арматура для круга и Г-сечения, включая дополнительные ряды.
- Параметрические TwoLine/ThreeLine-диаграммы бетона и арматуры по параметрам материала и расчетному режиму.
- `CSectionModel` как единая расчетная модель.
- Прямой расчет НДС.
- Поиск несущей способности методами `LoadMultiplier` и `UltimateStrain`.
- Одномерные методы `Bisection`, `Brent`, `Secant` для `LoadMultiplier`.
- Расчет ширины уже образовавшихся нормальных трещин в текущем предварительном виде.
- Batch-расчет до 20 сочетаний.
- Экспорт геометрии, напряжений, главных осей, точки приложения нагрузки и нейтральной линии в AutoCAD.
- Импорт расчетной сетки из AutoCAD `Region` на заданных слоях в `CSectionModel`.

## Текущий Поток Данных

```text
Generated geometry/rebar -> CSectionModel -> расчетное ядро
AutoCAD Region importer  -> CSectionModel -> расчетное ядро
```

Настройка `Geometry.Source` выбирает источник:

- `Generated` - встроенные генераторы по `Geometry.Type`;
- `AutoCAD` - активный AutoCAD-чертеж, только Region на слоях импорта.

Excel-таблицы с расчетной геометрией не являются источником данных для ядра. При необходимости они могут быть добавлены позже только как просмотр/диагностика.

## Ближайшие Задачи

1. Вернуться к методике трещин:
   - уточнить `Abt`, `As`, `ds`, `ls`, `psi_s`, `a_crc` для произвольного сечения;
   - отделить требования СП от инженерных интерпретаций;
   - решить, какие промежуточные данные выводить пользователю.

2. Улучшить AutoCAD import/export:
   - проверить импорт на реальном AutoCAD-чертежe;
   - уточнить чтение центральных моментов инерции Region в разных версиях AutoCAD;
   - при необходимости добавить диагностический просмотр импортированной модели.

3. Производительность:
   - замерить время по фазам: сборка модели, прямой решатель, capacity, трещины, вывод;
   - рассмотреть кэширование `CSectionModel` внутри одного пользовательского запуска;
   - не менять математическую модель ради ускорения без отдельной проверки.

4. Контрольные примеры:
   - круг;
   - Г-сечение;
   - импортированная произвольная сетка AutoCAD;
   - разные положения нейтральной линии;
   - разные диаметры и ряды арматуры.

## Не Делать Без Отдельного Решения

- Не возвращать `rngMainInput` и `rngRebarInput`.
- Не добавлять ручной ввод координат арматуры как основной путь.
- Не восстанавливать `CLinearSectionSolver`.
- Не менять единицы измерения.
- Не менять критерии разрушения и Newton/line-search без отдельного задания.
- Не делать Excel-лист источником импортированной геометрии для расчетного ядра.
