## Математическая постановка

Линейное ядро использует гипотезу плоских сечений:

```text
epsilon(x, y) = epsilon0 + kappaX * y + kappaY * x
```

Порядок неизвестных:

```text
[epsilon0, kappaX, kappaY]
```

Порядок уравнений равновесия:

```text
[N, Mx, My]
```

Матрица жесткости собирается по бетонным волокнам и обычным ненапрягаемым стержням. Для каждого элемента используется:

```text
B = [1, y, x]
K += E * A * transpose(B) * B
```

## Арматура

Поддерживается только обычная ненапрягаемая арматура.

Данные стержня:

```text
ID | X | Y | Diameter | Area | SteelClass | Comment
```

Если `Area <= 0`, площадь вычисляется по диаметру:

```text
Area = pi * Diameter^2 / 4
```

Преднапряжение, `InitialStrain` и `IsPrestressed` не поддерживаются и не закладываются как будущая возможность.

## Исключение двойного учета

Бетонная сетка занимает все сечение. Поэтому стержень добавляет только эффективный вклад:

```text
Eeffective = Es - Eb
Fadditional = Eeffective * epsilonS * As
```

Полное диагностическое напряжение стали:

```text
sigmaS = Es * epsilonS
```

## Решение системы

`CLinearSystem3x3` решает систему `3 x 3` методом Гаусса с выбором главного элемента. `WorksheetFunction.MInverse` не используется.

Возвращаются:

- признак решения;
- компоненты вектора;
- определитель;
- абсолютная и относительная невязка;
- причина остановки.
