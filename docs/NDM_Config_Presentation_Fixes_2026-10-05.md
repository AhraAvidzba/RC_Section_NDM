# Исправление списков и оформления книги

Дата: 2026-10-05. Исходный commit: `4a72a52224e1aaeb13bee8dee68948a097d7c2ec`.

## Изменения

1. В обновлении сохраненной книги убраны inline-списки вида
   `Stacked,SideBySide`. Источники validation остаются вертикальными скрытыми
   диапазонами и не зависят от разделителя локализованного Excel. Адреса
   служебных списков разных версий шаблона не считаются взаимозаменяемыми:
   подходящий источник переиспользуется, иначе выделяется свободный скрытый
   столбец без перезаписи существующих данных. Динамические списки ID/профилей
   сохраняют пользовательские источники.
2. Финальная рамка таблиц Config применяется после создания гиперссылок
   «Подробнее», поскольку hyperlink-стиль Excel сбрасывал границы ячеек.
   При обновлении сохраненной книги рамки также восстанавливаются.
3. Колонка `state` в блоке «Момент образования трещин» использует общую
   статусную палитру для `BaseFail`, `FAIL`, `NumFail`, `InputErr`, `CalcErr`,
   `OK`, `N/A`. Признаки `Cracked`/`NotCracked` не передаются в нормализатор
   статусов и сохраняют нейтральное оформление. Численные результаты,
   машинные коды и правила определения статусов не менялись.
4. Объединения дополнительных рядов RectSet сохранены намеренно:
   `loc_2row`, `loc_3row`, `bind_2row`, `bind_3row` являются общими для пары
   противоположных граней каждого прямоугольника; диаметры для граней
   задаются отдельно. Изменение этого контракта не входит в исправление UI.

при совпадении исходного SHA256 и отсутствии блокировки файла. Пользовательский
`RC_Section_NDM_execution_report.txt`, измененный до начала этой задачи,
сохранен отдельно и не заменяется новым тестовым отчетом.
