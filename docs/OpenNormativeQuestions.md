## ONQ-001. Формулы диаграммы бетона по СП 63

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- Тема: участки диаграммы сжатого бетона.
- Проблема: в PDF/RTF часть формул хранится как графические объекты, текст извлекается неоднозначно.
- Текущее решение: программа строит TwoLine/ThreeLine-диаграммы бетона по параметрам `rngConcreteMaterialParameters` и расчетному профилю `rngCalculationProfiles`; контрольные точки на `Config` служат только для проверки.
- Для самостоятельной сверки: подтвердить формулы, координаты характерных точек и область применимости по читаемому нормативному источнику.

## ONQ-004. Расчет ширины раскрытия трещин

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- Тема: проверка образования нормальной трещины и расчет ширины ее раскрытия.
- Проблема: расчет трещин для произвольного сечения `N + Mx + My` использует инженерное обобщение зон `Abt`, эквивалентного диаметра при разных `d` и поиска `lambda_crc`; эти решения нужно дополнительно сверить на контрольных примерах.
- Для самостоятельной сверки: подтвердить нормативную формулу, расчетную площадь взаимодействия арматуры и коэффициенты для мостовых конструкций.

## ONQ-005. Устойчивость По СП 35 И СП 63

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- Тема: продольный изгиб, случайный эксцентриситет, `phi_l`, `Ncr`, `eta`, табличная ветвь СП 35.
- Проблема: программная реализация приведена к проверяемой структуре, но требуется финальная независимая сверка пунктов, формул и граничных условий по нормативным документам.
- Для самостоятельной сверки: оформить ручные контрольные примеры для СП 63 и СП 35, включая `μ != 1`, разные знаки моментов, ветви `ec/r <= 1` и `ec/r > 1`, а также ограничение `N/Ncr`.

## ONQ-007. Малый Наклон Плато

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- `General.PlateauSlopeFactor` задаёт наклон ненулевых физических плато `Et = α·E` соответствующей ветви. Согласованный пользователем default — `α = 0.001`, то есть наклон `0.001·E` (0,1% от E). Это согласованное изменение `σ(ε)`, а не нормативное требование и не поправка только к касательной жёсткости.
- Пределы деформаций сохраняются, но напряжения и найденные предельные усилия могут немного измениться. Проверенная выборка не доказывает малость изменения для любых пользовательских материалов и деформаций.
- `α = 0` возвращает исходные горизонтальные плато. Для нормативной контрольной сверки без численного изменения плато использовать `0`. Контрольные точки и графики Config учитывают текущее значение коэффициента; Results хранит фактически использованные диаграммы последнего расчёта.
- Доказательства и границы проверки: `docs/reports/performance/PlateauSlope_2026-10-11.md`.
