## ONQ-001. Формулы диаграммы бетона по СП 63

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- Тема: участки диаграммы сжатого бетона.
- Проблема: в PDF/RTF часть формул хранится как графические объекты, текст извлекается неоднозначно.
- Текущее решение: программа строит TwoLine/ThreeLine-диаграммы бетона по параметрам `rngConcreteMaterialParameters` и расчетному профилю `rngCalculationProfiles`; контрольные точки на `Config` служат только для проверки.
- Для самостоятельной сверки: подтвердить формулы, координаты характерных точек и область применимости по читаемому нормативному источнику.

## ONQ-004. Расчет ширины раскрытия трещин

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- Тема: проверка образования нормальной трещины и расчет ширины ее раскрытия.
- Проблема: расчет трещин для произвольного сечения `N + Mx + My` использует инженерное обобщение зон `Abt`, эквивалентного диаметра при разных `d` и поиска `lambda_crc`; эти решения нужно дополнительно сверить на контрольных примерах.
- Для самостоятельной сверки: подтвердить нормативную формулу, расчетную площадь взаимодействия арматуры и коэффициенты для мостовых конструкций.

## ONQ-005. Устойчивость По СП 35 И СП 63

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- Тема: продольный изгиб, случайный эксцентриситет, `phi_l`, `Ncr`, `eta`, табличная ветвь СП 35.
- Проблема: программная реализация приведена к проверяемой структуре, но требуется финальная независимая сверка пунктов, формул и граничных условий по нормативным документам.
- Для самостоятельной сверки: оформить ручные контрольные примеры для СП 63 и СП 35, включая `μ != 1`, разные знаки моментов, ветви `ec/r <= 1` и `ec/r > 1`, а также ограничение `N/Ncr`.

## ONQ-007. Малый Наклон Плато

Статус: закрыт по решению пользователя; последующая сверка — самостоятельно.

- `General.PlateauSlopeFactor` задаёт наклон ненулевых физических плато `Et = α·E` соответствующей ветви. Согласованный пользователем default — `α = 0.001`, то есть наклон `0.001·E` (0,1% от E). Это согласованное изменение `σ(ε)`, а не нормативное требование и не поправка только к касательной жёсткости.
- Пределы деформаций сохраняются, но напряжения и найденные предельные усилия могут немного измениться. Проверенная выборка не доказывает малость изменения для любых пользовательских материалов и деформаций.
- `α = 0` возвращает исходные горизонтальные плато. Для нормативной контрольной сверки без численного изменения плато использовать `0`. Контрольные точки и графики Config учитывают текущее значение коэффициента; Results хранит фактически использованные диаграммы последнего расчёта.
- Доказательства и границы проверки: `docs/reports/performance/PlateauSlope_2026-10-11.md`.

## ONQ-008. Разделение усилий устойчивости и трещиностойкости СП 35

Статус: открыто; ограничение описано в справке.

- СП 35, п. 7.52: случайный эксцентриситет не учитывают при расчёте по трещиностойкости и деформациям. Локальный источник: `norms/SP_35/`, страница 90 PDF.
- Фактический контракт: `CBatchSectionCalculator.CalculateCombination` выполняет `RunStabilityFilter` до остальных проверок; при успешной устойчивости `mWorkingLoads` передаются также в `RunCrackWidth`. Раздельного исключения случайного эксцентриситета внутри одного профиля сейчас нет.
- Применение: для трещин назначать отдельный профиль с `Calculation.Stability.Enabled = No`; заданные силы и моменты сохраняются. Проверка устойчивости выполняется отдельным сочетанием/профилем. Сочетаниям нужны разные ID.
- В этой ревизии исправлены объяснения, а не математическая постановка. Возможное разделение усилий внутри смешанного профиля требует самостоятельной расчётной задачи и проверки.

## ONQ-009. Изолированная постпроверка T (кручение) и суммы NMT

Уравнения пространственной фермы сопоставлены с [ACI 445.1R-12, глава 9, §9.1–9.2.2](../norms/Torsion/ACI-445.1R-12-Torsion.pdf), стр.9–11 издания, стр.10–12 сохранённой выдержки ACI University. [Книга В. В. Горского](../norms/Torsion/Gorsky-1961-Torsion.pdf) используется для зависимости сплошного прямоугольника и сопоставления арматуры при θ=45°. Локальные копии и сведения об источниках находятся в `norms/Torsion/`.

Статус: инженерная модель с явно заданными ограничениями; не совместная нормативная верификация N+Mx+My+T.

- Готовое НДС N+Mx+My не изменяется. Для выбранных наружных продольных стержней проверяется алгебраическая сумма сохранённого напряжения НДМ и положительной добавки от T (кручение). Она не является самостоятельно уравновешенным НДС и не определяет совместный предельный момент.
- Пространственная однокамерная ферма: `q = |T|/(2Ao)`, `FT = q·uo·cot θ`, `σsw = q·s/(Asw·cot θ)`. `Ao` и `uo` относятся к оси единственного наружного хомута. Для θ=45° продольная тяга и требуемая площадь соответствуют Горскому, §4, формулам (17)–(19), стр.27 книги, стр.25 PDF «Проектирование железобетонных конструкций, подверженных кручению».
- По решению пользователя учитываются только наружный ряд продольной арматуры и один наружный хомут. Вся продольная тяга распределяется на выбранные наружные стержни по прилегающим участкам периметра. Доля внутреннего контура не задаётся. Этот выбор не следует выдавать за универсальное нормативное правило для любых пустотелых сечений.
- Равноудалённые проекции стержня обрабатываются автоматически. Физическая площадь делится поровну между отдельными точками и связными дуговыми компонентами множества ближайших проекций; на каждой дуге доля площади распределяется равномерно. Для точечных групп площадь относится к прилегающей длине периметра. На общих участках тяга делится пропорционально плотностям этой площади, а вклады складываются под одним ID. Это инженерное правило распределения принятой модели, не требование источника. Интегрирование по границам точечных ячеек и дуг сохраняет полную тягу и не зависит от разбиения контура.
- `Strut` проверяет диагональные сжимающие напряжения бетона отдельно от нормальных напряжений НДМ. Предел `νRb` с default ν=0,5 и автоматическая эффективная толщина `2·a` (a — минимальное расстояние от оси хомута до бетонной границы) являются доступными пользователю инженерными параметрами. Они не объявляются требованием СП 35 или СП 63. Явная толщина ограничена располагаемой бетонной полосой вокруг хомута.
- `GorskyRectangle` задаёт только предел бетона `Tlim = c·Rи·b²·h`, c=0,07 по умолчанию: Горский, §3, формула (13), стр.23 книги, стр.21 PDF. Применим к одному сплошному прямоугольнику с прямыми углами. Принятое `Rи` задаётся пользователем в `Torsion.Rb`; соответствие этого сопротивления материалу проверяется отдельно. Этот режим не объявляет весь алгоритм реализацией методики Горского для пустотелых сечений.
- Нормальные напряжения бетона от T (кручение) в НДМ не добавляются. Результаты НДМ за физическими пределами, если сохранено сошедшееся состояние, доступны для арифметической суммы; их собственные отказы остаются в НДМ. Проверки хомута, бетонных раскосов и растягивающей суммы арматуры выводятся самостоятельно.
