# Пример расчета устойчивости Г-сечения со смещенной точкой нагрузки

Документ показывает, как текущая реализация NDM учитывает продольный изгиб для
несимметричного Г-сечения с повернутыми главными осями. Это расчетный пример по
фактическому коду программы, а не самостоятельная нормативная верификация.

Главная особенность примера: пользователь задает усилия относительно центра
тяжести бетонного сечения и дополнительно задает смещение точки приложения
нагрузки:

```text
Load.ReferenceOffsetX = 50 мм
Load.ReferenceOffsetY = 50 мм
```

## 1. Исходные данные

Принято Г-сечение:

| Параметр | Значение |
|---|---:|
| B1 | 250 мм |
| H1 | 550 мм |
| B2 | 600 мм |
| H2 | 250 мм |

Сечение состоит из двух прямоугольников:

- верхний прямоугольник: `250 x 550 мм`;
- нижний прямоугольник: `600 x 250 мм`;
- общая высота: `800 мм`.

Арматура принята условно, чтобы показать влияние несимметричного сечения:

| Стержень | x, мм | y, мм | Диаметр |
|---|---:|---:|---:|
| R1 | 50 | 750 | 25 |
| R2 | 125 | 750 | 25 |
| R3 | 200 | 750 | 25 |
| R4 | 50 | 500 | 25 |
| R5 | 50 | 300 | 25 |
| R6 | 125 | 50 | 25 |
| R7 | 300 | 50 | 25 |
| R8 | 550 | 50 | 25 |

Материалы:

| Параметр | Значение |
|---|---:|
| Eb | 32500 МПа |
| Es | 200000 МПа |
| Rb | 15.5 МПа |
| Rsc | 350 МПа |

Нагрузки в пользовательской системе знаков:

| Параметр | Значение |
|---|---:|
| N | 100 тс, сжатие |
| Mx | 50 тс*м |
| My | 20 тс*м |
| Load.ReferenceOffsetX | 50 мм |
| Load.ReferenceOffsetY | 50 мм |

Расчетная длина:

| Параметр | Значение |
|---|---:|
| геометрическая длина | 3.0 м |
| коэффициент расчетной длины μ | 2.0 |
| расчетная длина l0 | 6.0 м |

## 2. Как код учитывает смещение точки приложения нагрузки

В текущем коде пользовательские усилия сначала переводятся во внутреннюю систему
знаков. По умолчанию в книге:

```text
+N user = Compression
```

Но внутри расчетного ядра сжатие имеет отрицательный знак. Поэтому:

```text
Ninternal = -100 тс
```

Далее `CBatchSectionCalculator.ApplyLoadReference` переносит усилия к центру
тяжести бетонного сечения:

```math
M_{x,c} = M_{x,user} + N_{internal} \cdot e_y
```

```math
M_{y,c} = M_{y,user} + N_{internal} \cdot e_x
```

где:

- `e_x = Load.ReferenceOffsetX = 50 мм = 0.05 м`;
- `e_y = Load.ReferenceOffsetY = 50 мм = 0.05 м`.

Подстановка:

```math
M_{x,c} = 50 + (-100) \cdot 0.05 = 45 \; тс \cdot м
```

```math
M_{y,c} = 20 + (-100) \cdot 0.05 = 15 \; тс \cdot м
```

Именно эти моменты используются дальше в расчете устойчивости. Если пользователь
выберет другую систему знаков, пересчет сначала пройдет через `CUnitSystem`, а
сама формула переноса в коде останется такой же.

## 3. Геометрические характеристики бетонного сечения

Текущий расчет устойчивости использует геометрические характеристики бетонного
сечения. Для принятого Г-сечения получаются:

| Параметр | Значение |
|---|---:|
| Ab | 287500 мм2 |
| xc | 216.304 мм |
| yc | 316.304 мм |
| Ix | 15 725 656 703 мм4 |
| Iy | 7 413 156 703 мм4 |
| Ixy | -5 021 739 130 мм4 |

Из-за несимметрии сечения главные центральные оси повернуты относительно
глобальных осей X/Y:

```math
\alpha = 64.806^\circ
```

Главные моменты инерции бетонного сечения:

```math
I_1 = 18\,088\,016\,828 \; мм^4
```

```math
I_2 = 5\,050\,796\,578 \; мм^4
```

Радиусы инерции:

```math
i_1 = \sqrt{\frac{I_1}{A_b}} = 250.83 \; мм
```

```math
i_2 = \sqrt{\frac{I_2}{A_b}} = 132.54 \; мм
```

Ширины сечения в направлениях главных осей по текущей дискретной геометрии:

```math
h_1 = 883.47 \; мм
```

```math
h_2 = 830.32 \; мм
```

## 4. Проекция моментов в главные оси

Код раскладывает вектор момента по главным направлениям. Для угла
`α = 64.806°`:

```math
\cos\alpha = 0.42568
```

```math
\sin\alpha = 0.90488
```

Моменты в главных плоскостях:

```math
M_1 = M_{x,c}\cos\alpha + M_{y,c}\sin\alpha
```

```math
M_2 = -M_{x,c}\sin\alpha + M_{y,c}\cos\alpha
```

Подстановка:

```math
M_1 = 45 \cdot 0.42568 + 15 \cdot 0.90488 = 32.73 \; тс \cdot м
```

```math
M_2 = -45 \cdot 0.90488 + 15 \cdot 0.42568 = -34.33 \; тс \cdot м
```

Дальше расчет выполняется отдельно в двух главных плоскостях.

## 5. Расчет по СП 63

Ниже показана последовательность в том виде, как ее использует текущий класс
устойчивости: для каждой главной плоскости определяется случайный эксцентриситет,
условная жесткость, критическая сила и коэффициент продольного изгиба.

### Плоскость 1

Случайный эксцентриситет:

```math
e_{a,1} = \max\left(\frac{l_0}{600}, \frac{h_1}{30}, 10\right)
```

```math
e_{a,1} = \max\left(\frac{6000}{600}, \frac{883.47}{30}, 10\right)
        = 29.45 \; мм
```

Эксцентриситет от заданного момента:

```math
e_{0,1} = \frac{M_1}{N}
        = \frac{32.73}{100} \cdot 1000
        = 327.29 \; мм
```

Расчетный эксцентриситет:

```math
e_1 = e_{0,1} + e_{a,1}
    = 327.29 + 29.45
    = 356.73 \; мм
```

По текущей реализации для условной жесткости получено:

```math
\delta_1 = 0.4038
```

```math
k_{b,1} = 0.2131
```

```math
D_1 = 16321.07 \; тс \cdot м^2
```

Критическая сила:

```math
N_{cr,1} = \frac{\pi^2 D_1}{l_0^2}
```

```math
N_{cr,1} =
\frac{\pi^2 \cdot 16321.07}{6.0^2}
= 4474.51 \; тс
```

Коэффициент продольного изгиба:

```math
\eta_1 = \frac{1}{1 - \frac{N}{N_{cr,1}}}
```

```math
\eta_1 =
\frac{1}{1 - \frac{100}{4474.51}}
= 1.0229
```

Момент с учетом продольного изгиба:

```math
M_{1,design} = \eta_1 \cdot N \cdot e_1
```

```math
M_{1,design} =
1.0229 \cdot 100 \cdot 0.35673
= 36.49 \; тс \cdot м
```

Запас по устойчивости:

```math
\gamma_{st,1} = \frac{N_{cr,1}}{N}
              = \frac{4474.51}{100}
              = 44.75
```

### Плоскость 2

Случайный эксцентриситет:

```math
e_{a,2} = \max\left(\frac{l_0}{600}, \frac{h_2}{30}, 10\right)
```

```math
e_{a,2} = \max\left(\frac{6000}{600}, \frac{830.32}{30}, 10\right)
        = 27.68 \; мм
```

Эксцентриситет от заданного момента:

```math
e_{0,2} = \frac{M_2}{N}
        = \frac{-34.33}{100} \cdot 1000
        = -343.34 \; мм
```

Расчетный эксцентриситет:

```math
e_2 = e_{0,2} - e_{a,2}
    = -343.34 - 27.68
    = -371.02 \; мм
```

По текущей реализации:

```math
\delta_2 = 0.4468
```

```math
k_{b,2} = 0.2008
```

```math
D_2 = 7034.54 \; тс \cdot м^2
```

Критическая сила:

```math
N_{cr,2} = \frac{\pi^2 D_2}{l_0^2}
```

```math
N_{cr,2} =
\frac{\pi^2 \cdot 7034.54}{6.0^2}
= 1928.56 \; тс
```

Коэффициент продольного изгиба:

```math
\eta_2 =
\frac{1}{1 - \frac{100}{1928.56}}
= 1.0547
```

Момент с учетом продольного изгиба:

```math
M_{2,design} =
1.0547 \cdot 100 \cdot (-0.37102)
= -39.13 \; тс \cdot м
```

Запас:

```math
\gamma_{st,2} =
\frac{1928.56}{100}
= 19.29
```

### Возврат из главных осей в глобальные X/Y

После расчета по двум главным плоскостям программа возвращает моменты в
глобальную систему:

```math
M_{x,design} = M_{1,design}\cos\alpha - M_{2,design}\sin\alpha
```

```math
M_{y,design} = M_{1,design}\sin\alpha + M_{2,design}\cos\alpha
```

Подстановка:

```math
M_{x,design} =
36.49 \cdot 0.42568 - (-39.13) \cdot 0.90488
= 50.94 \; тс \cdot м
```

```math
M_{y,design} =
36.49 \cdot 0.90488 + (-39.13) \cdot 0.42568
= 16.36 \; тс \cdot м
```

Итог по СП 63 для дальнейшего расчета НДМ:

| Усилие | Значение |
|---|---:|
| N | 100 тс, сжатие |
| Mx | 50.94 тс*м |
| My | 16.36 тс*м |

## 6. Расчет по СП 35

В текущем коде расчет по СП 35 выполняется в той же геометрической постановке:
сначала усилия переносятся к центру тяжести бетонного сечения, затем моменты
раскладываются по главным осям, после чего каждая плоскость считается отдельно.

### Плоскость 1

Случайный эксцентриситет:

```math

```

```math

```


```math
\frac{e_1}{i_1} =
\frac{342.29}{250.83}
= 1.365
```

В текущей реализации для этой плоскости выбирается ветвь с коэффициентом
продольного изгиба:

```text
SP35-eta
```

Полученные промежуточные величины:

```math
\delta_{min,1} = 0.2771
```

```math
\delta_1 = 0.3874
```

```math

```

```math

```

Критическая сила:

## 7. Что важно для несимметричных сечений

Для Г-сечения глобальные оси X/Y обычно не совпадают с главными осями бетонного
сечения. Поэтому программа не применяет коэффициент продольного изгиба напрямую
к `Mx` и `My`.

Текущая последовательность такая:

1. Пользовательские усилия переводятся во внутренние единицы и знаки.
2. Моменты переносятся к центру тяжести бетонного сечения с учетом
   `Load.ReferenceOffsetX/Y`.
3. Бетонное сечение дает главные оси, главные моменты инерции и расчетные высоты.
4. Моменты `Mx/My` раскладываются на две главные плоскости.
5. Для каждой плоскости отдельно определяется `e_a`, `Ncr`, `eta` и расчетный
   момент.
6. Скорректированные моменты возвращаются в глобальные оси X/Y.
7. Дальше в существующий расчет НДМ передаются уже скорректированные `N`, `Mx`,
   `My`.

Смещение `Load.ReferenceOffsetX/Y` в этом процессе всегда считается относительно
центра тяжести бетонного сечения, а не относительно центра тяжести приведенного
сечения бетон + арматура.
