# Исправление Config И Чтения Аннотаций Results

Дата: 2026-10-06. Базовый коммит: `fabaeac`.

## Причины И Исправления

1. `CSectionPlotDataReader` ошибочно читал строки `CRACK_REGION_LINE`,
   `CRACK_REGION_ARC` и `CRACK_PROBE` как размерные подписи, требуя
   `OutsideNormalX/Y`. Эти поля не обязательны для расчетной области и
   неуспешной пробы. Reader теперь принимает в этой ветке только `DIMENSION`
   и `REBAR_ANNOTATION`. Исходные контуры читаются отдельно из геометрии;
   строгая проверка настоящих размерных подписей и динамических адресов сохранена.
2. Сборщик Config размещал разные validation-источники в пересекающихся
   фиксированных колонках. После добавления настроек СП 35 список `mm/pt`
   перезаписал источник `Stacked/SideBySide`. Все таблицы теперь используют
   единый реестр скрытых служебных колонок; одинаковые наборы переиспользуются,
   разные наборы и динамические списки получают отдельные источники.
3. Повторное создание гиперссылок справки применяло стиль Excel, снимающий
   правую рамку. `Add-SettingsInstructions` теперь завершает работу восстановлением
   рамок; правая внешняя грань именованных Config-таблиц назначается явно.

## Проверки

  и `Build2.xlsm`; адресные проверки выполнялись в собственных копиях.
- Config: 1424 утверждения, 0 ошибок. Проверены 283 list-ячейки, 49 отдельных
  источников, смысл вариантов 249 статических selectors и правая грань таблицы.
- Повторное обновление справки штатным сборщиком: те же 1424 утверждения,
  0 ошибок; рамки и validation сохранены.
- Аннотации трещин: 123 утверждения, 0 ошибок. Пустые нормали расчетной области
  и координаты неуспешной пробы допустимы; поврежденная нормаль настоящей подписи
  по-прежнему отклоняется с фактическим адресом, включая перенос named anchor.
- Полная адресная suite Excel-схемы: 3347 утверждений, 0 ошибок, включая эти
  123 проверки. НДС в presentation-тестах не решается.
- Структурный валидатор: 27 проверок, 0 ошибок.
- Сохраненный VBA: 119 из 119 исходных модулей совпадают с экспортом VBE;
  архитектурные source-contracts пройдены.
- Визуально проверены Config с правой рамкой и настоящий сохраненный Chart
  с 289 объектами. Положение пользовательского Chart не менялось.
- Сохраненный пример пользователя рассчитан в подготовленной копии и затем
  в опубликованной рабочей книге: 1 сочетание, успешное завершение без ошибки
  `OutsideNormalX`. Все 2372 ячейки именованных Config-таблиц, включая формулы
  и параметры СП 35, сохранены. Значение по умолчанию `SLS.Crack.Code = SP35`
  осталось неизменным.

Полные тяжелые расчетные suite on/off повторно не запускались: численная
методика и расчетные алгоритмы этим исправлением не затронуты.
