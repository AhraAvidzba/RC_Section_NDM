# Audit03: Структура Таблиц Config И Адресная Диагностика

## Scope

Срез после `37f655c`: F07/K01/K04, реальные именованные таблицы единиц,
знаков, материалов, системных настроек и аннотаций. Меняется только
`CSystemSettingsReader` и тесты. Расчетная методика, физические критерии,
solver options, expected values и tolerances не меняются; новых классов нет.

## Подтвержденные Отклонения

- Поврежденная шапка Units/Signs/Materials переставала распознаваться.
  Reader выдавал сообщение об отсутствующем ключе или обязательном значении,
  но терял конкретную ошибочную ячейку шапки.
- Excel-ошибка в названии строки Units/Signs выглядела как отсутствующая
  настройка, без адреса и точной причины ошибки формулы.
- Excel-ошибка служебного комментария материалов/аннотаций сохранялась как
  `Error 2015`. Scalar Config уже игнорировал такие нерасчетные ошибки.
- Диагностика диапазона с недостаточным числом колонок не называла адрес
  текущей таблицы и действие для ее восстановления.

Это не подтверждение общего VBA Type mismatch: выполненный negative показывает
именно потерю адреса/машинной причины и текст ошибки в нерасчетном источнике.

## Изменения

Известные имена Units/Signs/Materials определяют тип таблицы до fallback
распознавания. Reader проверяет те же смысловые подписи, которые уже требовал
прежний распознаватель; неправильная шапка не интерпретируется как чужая scalar
таблица. Ошибка содержит русское название блока, текущий адрес, ожидаемую
подпись и действие. Регистр и окружающие пробелы по-прежнему допустимы.

Ключи строк Units/Signs/Materials проходят через существующий `ConfigCellText`.
Нерасчетные комментарии материалов/аннотаций используют его явно допустимый
контракт игнорирования Excel-ошибки. Ошибки значений не скрываются. Общий
структурный guard также называет начальную ячейку диапазона и способ исправления.

Optional-таблицы материалов остаются optional для reader-а: обязательность
конкретного материала проверяет активный потребитель. `LoadFromRange` сохраняет
распознавание фактических форматов без обязательного имени. Отложенная проверка
неактивной геометрии/оформления не заменяется глобальной валидацией всех значений.

## Ограничения

Новый структурный gate не является per-key приемкой дополнительных численных
настроек, полным диапазоном или pairwise. Структурные captions не являются
новыми пользовательскими настройками; справка и форматирование не менялись.

выполнены затронутые направленные наборы, а финальный полный release остается
