## Подтверждённые исправления

- F01: воспроизведено на принятой книге. Два пути по 3 давали 2+1 дополнительных стержня, по 15 — 8+7. Исполнитель теперь сохраняет локальный SourceOrdinal каждого пути, сквозные ID и порядок публикации. Preflight суммирует округления по каждому независимому пути; для фильтрованных зависимостей сохраняет безопасную верхнюю оценку. Отключённый источник не создаёт оценку дополнительных позиций.
- F02: после исправления порядка сторон в fixture воспроизведён MISSING_SEGMENT для Offset.H.Left, Config!I140. При исчезнувших прямых боковой путь привязывается к соответствующим концам существующих дуг. Радиусы не уменьшены, фиктивные прямые не добавлены. Случаи B=600, H=1000/600, R1=300, as=50 дают 10 боковых стержней и точную аналитическую длину/площадь.
- F03: рабочие вызовы остаточного RebarRequestedPositionCount отсутствовали; метод удалён. Четыре полезные проверки перенесены на настоящий CRebarRuleExecutor, включая отказ до выделения массива для max Long и отключённый источник.
- F04: baseline HollowRectangle принимал «-» как отключение диаметра. Запрошено решение пользователя о сохранении только этой совместимости; ответа пока нет. Произвольный текст и отрицательные числа не преобразуются в ноль.

Адресный native прогон: **388 PASS, 0 FAIL**. Отчёт: `docs/regression/GeometryReview_2026-10-12/DirectedFixes.txt`. Red-воспроизведения сохранены в `Reproduction/`; первоначальные ошибки fixture не выданы за дефект production.
