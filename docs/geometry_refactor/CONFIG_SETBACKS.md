# Концевые отступы и список типов сечений

Готовая книга содержит актуальные таблицы Config. Рабочая программа не
переносит поля, не вставляет строки и не перестраивает их структуру.
StartSetback и EndSetback уже находятся в своих колонках; числовые значения,
единицы и формулы пользователь редактирует в этих таблицах.

StartSetback/EndSetback измеряются вдоль линии центров стержней в единицах
INPUT Length. В независимом ряду они сокращают рабочую длину, сохраняя
EndMode. У проецируемого ряда ограничивают целевой участок и исключают
проекции за его пределами, без перераспределения остальных стержней.
Зависимый ряд следует фактически созданным позициям исходного ряда.
Пустой или ошибочный активный отступ вызывает ошибку с адресом ячейки.

Для полной окружности концевые отступы неприменимы; при необходимости
создаётся открытый участок дуги. У круга оба выбора EachBar/EverySecondBar
уже присутствуют в Config и имеют независимые именованные списки.

После регистрации нового рецепта в CSectionTypeRegistry запустите
`modSectionRecipeSetup.UpdateSectionRecipeTypes` через Alt+F8. Макрос
меняет только значения служебного списка rngSectionRecipeTypes, длину
этого имени и выпадающий список Geometry.Type. Выбранный тип и другие
таблицы, настройки, формулы, единицы, нагрузки и Results сохраняются.
Отсутствующий именованный список не создаётся автоматически; занятое
продолжение его столбца вызывает ошибку до записи.

При использовании отдельной копии доступна команда:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/build_workbook/Update-SectionRecipeTypes.ps1 -WorkbookPath <отдельная-книга.xlsm>
```

Проверяются чтение действующих полей, единицы мм/см/м, обработка проекций,
независимые списки рядов и минимальное обновление реестра. Исторические
материалы этапа преобразования старых таблиц остаются в истории Git и
отчётах; они не являются инструкцией для пользователя готовой книги.
