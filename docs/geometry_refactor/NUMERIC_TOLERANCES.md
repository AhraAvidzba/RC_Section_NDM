# Допуски сравнения

Зафиксированы до изменения production-геометрии. Они не являются допусками
решателя и не разрешают менять настройки сетки/нагрузки ради совпадения.

Сравнение: `abs(a-b) <= absTol + relTol * max(abs(a), abs(b))`.
NaN/Infinity всегда ошибка. Повтор одного baseline должен совпасть побитно.

| Поля | Единицы | absTol | relTol |
|---|---|---:|---:|
| Координаты сетки/арматуры/контуров/аннотаций, размеры, радиусы | мм | 1e-7 | 1e-12 |
| Площади | мм2 | 1e-6 | 1e-12 |
| Статические моменты | мм3 | 1e-4 | 1e-12 |
| Моменты инерции | мм4 | 1e-3 | 1e-12 |
| Направления, fill factor | безразмерные | 1e-12 | 1e-12 |
| Углы | рад | 1e-12 | 1e-12 |
| Деформация | безразмерная | 1e-10 | 1e-6 |
| Кривизна | 1/мм | 1e-13 | 1e-6 |
| Усилие N | Н | 0.01 | 1e-6 |
| Момент | Н*мм | 1 | 1e-6 |
| Напряжения | МПа | 1e-6 | 1e-6 |
| lambda | безразмерная | 1e-8 | 1e-6 |
| Ширина трещины | мм | 1e-7 | 1e-6 |

Геометрические пределы допускают только ошибки порядка вычислений Double;
1e-7 мм заведомо меньше графической/инженерной точности. Для сумм площадей,
статических моментов и инерций абсолютные пределы учитывают их размерность,
а относительный предел остается 1e-12. Расчетные пределы существенно строже
пользовательского инженерного критерия 2%; статусы и критерии не сравниваются
по численному допуску.

Количество, порядок, ID, материал, источник, роль Outer/Opening, тексты,
единицы, статусы и признак calculated сравниваются точно. Расхождения от
обязательного перехода арматуры на аналитические дуги не поглощаются допуском:
нужны отдельный oracle и запись BEHAVIOR_CHANGES.

Режим побитного сравнения проверяет также сериализацию и воспроизводимость.
Отличия таблиц ввода после добавления новых нулевых отступов проверяются
отдельно; пропуск INPUT в геометрическом diff должен быть явно указан.
