### Реализованный результат

- Четыре семьи используют по одному ISectionRecipe: Circle, RectSet с тремя
  формами, RoundedRectangle и HollowRectangle. Один CSectionDefinition,
  общий builder, точные линии/дуги/окружности/скругления, общий graph правил.

  ISectionShape или переходного fallback. Retirement-map и manifests сохранены.

- В конце Справки — полный гайд и актуальный каталог 276 членов API,

### Доказанные отличия и производительность

Прямое сравнение со старой полилинейной моделью закономерно не проходит
для Hollow: 7 118/7 115 численных полей СП35/СП63. Причина и независимый
oracle уже зафиксированы в `BEHAVIOR_CHANGES.md`/`HOLLOW_RECIPE_EVIDENCE.json`.
Старые статусы сохранены; изменения capacity/crack/width ранее оценены отдельно.
Финальные 48 114 records на норму побитно совпадают с принятой миграцией.
Baseline и допуски не переписаны. Остальные семь fixtures проходят прежнее
сравнение. У preview 96 ожидаемых различий только экранных координат/размеров
Hollow-стержней; структура, подписи и остальные семьи сохранены.

Девять штатных одно-LC workflow с report/Results/схемой: 1,16–4,11 с.
Один полный смешанный профиль HollowOffset: 5,31 с. Это направленные замеры,
не полный performance benchmark. У тёплого staged HollowOffset медиана двух
последующих проб 2,40 с против 2,00 с baseline. Основная разница — summary
и snapshot (дополнительные diagnostics/provenance и данные); solver остаётся
около 0,017/0,015 с, solve count=1. Подготовка около 0,242/0,222 с.
Более общий вывод о всех профилях и размерах из этих проб не делается.

Неуспешные probes сохранены. AutoPlot test ошибочно наследовал AutoCAD;
добавлен явный Generated для проверки активного Geometry.Type. Production
не стал потреблять неактивный тип. Ошибочные keys/accessors и предположение
«все механические свойства — один кэш» исправлены в отдельном harness.
Новый XML verifier кэширует неизменяемые стили и индекс заполненных строк,
сохраняя прежние строгие критерии; native Print_Area alias нормализован к
исходному служебному имени. Исходные probe отчёты не удалены.

### Воспроизведение

Команды — `docs/ValidationPlan.md`; актуальные runners в `tools/build_workbook`.
`Build-Workbook.ps1` восстанавливает книгу из src/tests, штатно устанавливает
новую Справку последней. `Run-Audit03Watchdog.ps1` создаёт изолированную копию,
проверяет source hash и владеет только своим Excel PID. Небольшой итоговый
harness в `examples/modFinalGeometryChecks.bas` импортируется отдельно через
`Update-PrivateWorkbookCode.ps1 -ExampleFiles ...`; в production его нет.

`Summarize-GeometryFinal.py` проверяет фактические PASS/records/hashes и
обновляет матрицу. `Publish-GeometryRelease.ps1` публикует только проверенную
пару книга/dump, сохраняет резервные копии и контролирует чужие output files.
Архив этапа содержит исходники, runners, docs, логи, PNG и native DWG.
