## Последующие уточнения пользователя

1. Добавка профиля: единственная константа 2,5 мм в общем CRebarContactBuilder.
   Каждая соседняя пара контактной цепочки получает эту добавку к сумме
   радиусов. Самостоятельные отступы, расчётные диаметры и площади не меняются.
   Для 32/20/16 по нормали: 28,5 и 49 мм; для a2=a3=100 и 20/16 — 120,5 мм
   либо касательное смещение 20,5 мм. Это пользовательское условие.
2. Круг: русское «Диаметр», основной ряд одной строкой с as/d/n и двумя
   концевыми отступами. Все длины читаются через CUnitSystem.
3. При StartSetback=EndSetback=0 сохраняется полный круг. Иначе общая Slice
   отсекает концевые длины, оставляя открытую дугу с обоими концами ряда.
   После следующего уточнения начало — сверху, обход по часовой стрелке. В примере
   Circle_Arc_ThreeRows_100_200 специально заданы 150/250 мм.
4. Центрирование подписи отверстия исправлено в общем RuleExtremeEnds.
   На прямой грани SideBySide сохраняет одинаковый Y центров Ø20 и Ø16;
   на скруглении касательный перенос меняет обе глобальные координаты.
5. Единое оформление комментариев Config закреплено общим helper-ом,
   проверено 292 ячейки. Перенос и автоматическое увеличение строк убраны.
