# Доказанные Изменения Поведения

Поведение прежнего production-маршрута не менялось. Новые общие пути и
RoundedPolygon еще не подключен к production; вынесенный query helper
проверен побитным geometry/SP35/SP63 regression. Допуски и baseline не подгоняются.

Два прежних roundoff-литерала приведены к научной записи, сохраняемой VBE.
Их Double одинаков: 3ceffffffffffffe. Это не изменение расчетного коэффициента.

## На Проверке: Аналитическая Раскладка RoundedRectangle

По исходному коду боковой путь представлен точками дуг и измеряется как
ломаная. Требование ТЗ 1.4: только аналитические Arc. До исправления нужны
baseline-координаты, независимые длины/позиции/касательные, минимальный
воспроизводимый fixture и численные/расчетные/визуальные различия после.
Это пока наблюдение по коду, не завершенная запись об исправлении.

## Circle В Новом Development-Маршруте

Доказанных изменений инженерного результата нет. Поэлементные 28 fixtures,
SP35/SP63-расчеты и Excel preview проходят исходные допуски. Сохраняются
направления SideBySide, межосевые расстояния неравных диаметров, порядок
публикации B1/B1_R2/B1_R3, исходные комментарии/ID, проверка полного диска
дополнительных стержней и подпись фактически созданной арматуры.

Источник Circle перемещен в короткий рецепт общего интерфейса. Числа теперь
читаются из immutable generic table snapshot, а концевые правила и связанные
ряды исполняются общим алгоритмом. Возможные разности последних битов от
аналитических станций проверены прежним comparator-ом, не новым допуском.
Из 58 308 записей разные биты имеются только у координат BAR/LAYOUT;
максимум 4.2633e-13 мм по X и 2.2737e-13 мм по Y. Сетка, геометрические
свойства, диаметры, площади, строки/ID/роли/комментарии и аннотации побитно
совпадают. Реальные расчеты SP35/SP63 сравнивались отдельно, без округления.
Основная пользовательская книга и прежний production-путь пока не менялись.
