# Audit02 — итоговая приёмка единого API рецептов

## Закрывающая доработка 14.10.2026

Основа — актуальный c6fed5bf. Исполняемый код всех 110 рабочих компонентов
сохранён; новых классов, API, Config, геометрии, армирования и аннотаций нет.

- В гайде у ConfigureDependentContact оба диаметра теперь строго >0: ноль
  вызывает ошибку; отключённый ряд рецепт пропускает до вызова. Алгоритм не менялся.
- У публичных RoundedPolygon/OffsetRoundedPolygon указан CPolygonSpec.
  Описание массивов оставлено только у закрытого численного ядра. Возле
  AxisPath/AddGeometry перечислены фактические аргументы. Генератор разбирает
  полную команду, включая переносы; `_` описан как продолжение строки VBA.
- **Обоснованное исключение RectSet:** четыре Length + Require сохранены.
  Здесь сначала читаются оба числа пары H/B, затем проверяются H>0 и B>0.
  При H1=0 и текстовом B1 baseline сообщает B1; прямой PositiveLength(H1)
  сообщает H1. Аналогично для H2/B2. Кроме адреса меняются номер, source и
  прежний текст ошибки высоты/ширины. Существующий PositiveLength проверяет
  немедленно; сохранить весь контракт через него потребовало бы повторного
  чтения/перевода либо расширения API. Это не сделано по ограничениям цели.
  В коде оставлено пояснение. Один перевод единиц, неактивные поля, знаковое
  смещение, B1<B2 и смежность прямоугольников сохранены.

Реализован общий `CPolygonSpec`: одна запись содержит имя исходной вершины,
X/Y, радиус и источник. Рецепт задаёт вершины через `AddVertex`, завершает
ввод через `Seal` и использует один описатель для контура и его смещений.
Новый контейнер не строит геометрию. Математика остаётся в прежнем query;
один внутренний `Friend CopyKernelData` передаёт данные его закрытому ядру.

`RoundedPolygon` и `OffsetRoundedPolygon` у фасада и query принимают только
`CPolygonSpec`. Все применимые рецепты, тесты и примеры перенесены. Публичные
массивные варианты, `AddCorner` и технические циклы имён из рецептов удалены.
Circle и RectSet сохраняют аналитическую окружность и смежные прямоугольники.
Общие помощники options и чтения длин заменяют повторную подготовку данных.
Сложность формы и направления рядов по-прежнему видны в рецептах.

Фасад создаёт **и регистрирует** линию. Возвращённый `path` позволяет узнать
её ID и геометрические свойства. Последующий `Outer` назначает этой уже
существующей линии роль границы бетона; он не создаёт её повторно. `Opening`
назначает роль отверстия. `AddPath` предназначен для действительно внешней
подготовленной линии. Замкнутого круга построения здесь нет.

## Проверенный результат и ограничения

Восемь полных геометрических/НДС снимков и два расчётных снимка СП35/СП63
побайтно совпадают с baseline. Это шесть матриц форм, десять физических
моделей, 120 сошедшихся прямых решений НДМ и 16 адресных сочетаний четырёх
семейств. Сравниваются координаты, площади, свойства, ID, контуры, стержни,
аннотации, числа, статусы и пояснения; строк или полей, исключённых из
сравнения, нет. В расчётных сочетаниях включены несущая способность,
устойчивость, образование, ширина и продольные трещины. СП35/СП63 обозначают
режим трещин; сохранённая постановка устойчивости в обоих прогонах — СП63.
Это регрессия поведения, не полная нормативная верификация.

Девять настоящих схем Excel совпадают по пикселям. Отдельная схема Audit02Demo
показывает Aligned на фактической наклонной грани; повторный Draw даёт те же
ряды, подписи и Shapes. Измеряемая линия наклонная, поворот текста остался
прежним — 0/90 градусов. Полные длительные ON/OFF и UI-suite не запускались.

**V02 — BLOCKED:** установлен обычный AutoCAD 2023. Уже работающий PID 9344
(запуск 10:24:46) перехватывает ROT даже после запуска отдельного PID 18440.
Защитная проверка остановила подключение до доступа к документам. Закрыт
только собственный новый экземпляр; существующий AutoCAD и документы
пользователя не затронуты. Реальный CAD-макрос не выполнен и не объявляется
успешным. Причина и обе попытки сохранены в evidence; для повторения нужно
освободить COM-подключение. Код CAD-импорта/экспорта этим этапом не менялся.

## Сокращение рецептов и общий код

Считаются исполняемые инструкции в телах процедур. Комментарии, объявления,
закрывающие конструкции и переносы строк не учитываются; операторы через
двоеточие считаются отдельно. Inline Then учитывается отдельно от условия.
Одна инструкция Array могла задавать четыре вершины, поэтому сравнение
не скрывает увеличение числа AddVertex. Полный метод подсчёта и hashes —
`SourceMetricsBefore.json`, `SourceMetrics.json`, `Measure-Audit02Source.py`.

| Circle | 53 → 54 | 8 → 8 | 3 → 3 |

RoundedRectangle уменьшился на 18 инструкций: исчезло обслуживание массивов,
копирование и техническая нумерация. Circle почти прежний: явный выбор оси
общего helper добавил одну инструкцию. Hollow и учебная трапеция выросли на

контуры повторно используют spec, общие формулы и нумерация удалены. Это

## Книга, справка и воспроизводимость

Сверены 107461 ячейка и 27 имён. Ввод Config/LC, Results, формулы и cached
values прежние; оформление и рисунки прежние. Меняются пять строк в уже
существующем блоке Справки, увеличена высота четырёх строк. Новых именованных
диапазонов и дублирующего блока нет. В Справке перечислены четыре действующих
класса как примеры: CSectionRecipeCircle, CSectionRecipeRectSet,

Alt+F11 → Ctrl+R → Class Modules. Внешних файлов реализации книга не требует.

После неё весь VBA основной книги читается ещё раз без сохранения и сравнивается
с source и принятым кандидатом. ALL CODE — именно этот фактический экспорт.
Файл пользовательского execution_report (SHA BE95A1F0…) не меняется и не входит
в коммиты этапа. Hash и время выпуска — Publication.json.

Исправления тестовой миграции не затронули математику: три проверки структуры
теперь ожидают владельца ошибки CPolygonSpec вместо query; топологические
ожидания сохранены. Слишком длинные строки мигратора исправлены до успешной
компиляции. Пробелы автопечати VBE приведены в соответствие с исходниками.
Эталоны и инженерные допуски не менялись, norms/reference/control_examples
не изменены. Прежние защиты ownership/freeze/отдельных аннотаций проходят.

Локальные этапы: e912d4b (описатель), d1fef5f (единый API и рецепты), далее
отдельные коммиты документации/приёмки и выпуска книги. Push разрешён
прямой целью пользователя, которая заменяет старый запрет внутри §14 документа.
