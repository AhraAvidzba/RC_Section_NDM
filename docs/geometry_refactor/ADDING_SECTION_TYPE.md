# Добавление нового типа сечения

Для нового параметрического сечения создайте один класс-рецепт VBA. Он описывает границы бетона, отверстия и армирование; сетку и стержни строит общая программа.
Ниже приведён порядок подключения. Полный API со всеми аргументами и готовыми примерами находится в модуле книги modSectionRecipeApiGuide.

## Возможности
Контур можно составить из прямых, дуг и окружностей; для многоугольника можно задать скругления.
Для арматуры доступны заданное число стержней, шаг, связанные дополнительные ряды и проекция на другую линию. Размеры и подписи задаются отдельно.









## Порядок действий

1. В редакторе VBA (Alt+F11) создайте Class Module и подключите Implements ISectionRecipe.
2. В методе ISectionRecipe_CreateDefinition прочитайте таблицу через context.Reader. Длины переведите в мм через ридер или context.Units.
3. Создайте CSectionDefinitionBuilder, вызовите Initialize и опишите наружную границу. Если есть отверстия, укажите их вместе с соответствующей наружной границей.
4. Задайте линии центров арматуры, диаметры и число стержней или шаг. При необходимости добавьте связанные ряды и правила проекции.
5. Добавьте нужные размеры и подписи, затем верните результат Finish. Общий сборщик проверит описание и построит сечение.
6. Зарегистрируйте класс и имя его входной таблицы в CSectionTypeRegistry.Class_Initialize. Через Alt+F8 выполните UpdateSectionRecipeTypes для обновления выбора Geometry.Type.
7. Выберите новый тип, сформируйте сечение и проверьте контуры, сетку, арматуру и схему. Затем проверьте расчёт, единицы и сообщения при неверном вводе.





























## Чтение размеров и армирования

На листе «Сечения» подготовьте именованную таблицу: в блоке General — размеры, в Main — основное армирование, в Extra — дополнительные ряды. Ридер ищет поля по коротким ключам.

Можно использовать свою структуру таблицы: context.Table даёт снимок диапазона, а reader.ValueAt читает значение по номеру строки и столбца. В этом случае рецепт сам проверяет ввод и переводит единицы.



## Справочник методов создания сечения

Нажмите Alt+F11, затем Ctrl+R и откройте Modules → modSectionRecipeApiGuide. В модуле приведены точные сигнатуры, все параметры, единицы и готовые примеры. Поиск по имени метода — Ctrl+F.

Начните с блока «МИНИМАЛЬНЫЙ ПРИМЕР»: это полный класс простого сечения. Штатные рецепты для сравнения находятся в Class Modules, например CSectionRecipeCircle и CSectionRecipeHollowRectangle.
