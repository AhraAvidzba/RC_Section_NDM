# Добавление нового типа сечения
Новый параметрический тип позволяет один раз описать форму сечения, а затем менять его размеры на листе «Сечения». При нажатии «Сформировать сечение» программа строит по этому описанию бетонную сетку, арматуру и схему. После этого доступны те же расчёты, что и для штатных типов.
Для подключения нужен один класс VBA, который называют рецептом сечения. Рецепт задаёт границы бетона, отверстия и правила армирования. Расставлять каждый стержень и самостоятельно разбивать бетон на элементы не требуется: это делает общий сборщик. Ниже — последовательность работы для человека, который уже знаком с основами VBA.
## 1. Начните с готового примера
Откройте редактор VBA сочетанием Alt+F11, затем окно проекта сочетанием Ctrl+R. В папке Modules найдите modSectionRecipeApiGuide и блок «МИНИМАЛЬНЫЙ ПРИМЕР». Там приведён целый класс простого сечения, который удобно взять за основу. Штатные классы CSectionRecipeCircle и CSectionRecipeHollowRectangle показывают более сложные варианты.
Создайте Class Module и дайте ему своё имя, например CSectionRecipeCustom. Строка Implements ISectionRecipe подключает единый интерфейс рецепта. Основная работа выполняется в ISectionRecipe_CreateDefinition: этот метод получает входные данные, собирает описание сечения и возвращает его программе. Точные сигнатуры берите из примера, чтобы не пропустить обязательные части интерфейса.
## 2. Подготовьте размеры на листе «Сечения»
Сначала решите, какие параметры пользователь будет менять: например ширину, высоту, размер отверстия, диаметр и число стержней. Для нового типа подготовьте одну именованную таблицу с блоками General для размеров, Main для основного армирования и Extra для дополнительных рядов. Ориентируйтесь на таблицу похожего штатного сечения.
Ридер context.Reader находит значения по коротким ключам. Имя, показанное пользователю в пояснении, может быть подробным, а ключ должен совпадать с тем, который читает рецепт. Размеры переводите в миллиметры через ридер или context.Units. Это позволяет сечению правильно работать при разных единицах ввода.
Если стандартная таблица не подходит, context.Table даёт её снимок, а reader.ValueAt читает ячейку по номеру строки и столбца. При таком способе рецепт сам проверяет допустимость значений и переводит размерные величины во внутренние единицы.
## 3. Опишите бетонную границу и отверстия
Создайте CSectionDefinitionBuilder и вызовите Initialize, как в минимальном примере. Затем задайте наружную границу бетона. Её можно составить из прямых, дуг и окружностей; для многоугольника доступны скругления. Для полого сечения добавьте каждое отверстие и укажите, к какой наружной границе оно относится.
На этом этапе вы описываете настоящую геометрию, а не отдельные элементы сетки. Например, прямоугольник с круглым отверстием задаётся наружным прямоугольным контуром и внутренней окружностью. Общая программа сама исключит отверстие при построении сетки с выбранными настройками Mesh. В Contour базовые ячейки обрезаются по фактической границе, а Adaptive уточняет пограничные прямоугольники. Порог минимальной площади применяется к каждой конечной части бетона и физическому стержню; равная порогу площадь сохраняется, а ноль отключает фильтр.
## 4. Задайте правила армирования
Опишите линии, на которых должны располагаться центры стержней, и передайте диаметр с числом стержней или с шагом. Например, для нижней грани прямоугольника задаётся одна линия ряда; общий сборщик размещает стержни вдоль неё по выбранному правилу.
Для более сложного армирования доступны связанные дополнительные ряды и проекция на другую линию. Используйте их, когда положение одного ряда должно зависеть от другого. Собственную процедуру расстановки стержней в рецепте создавать не нужно: единые правила помогают одинаково обрабатывать совпадения и проверять результат у всех типов.
## 5. Добавьте размеры и подписи
При необходимости задайте размерные линии и подписи арматуры, чтобы пользователь мог проверить введённое сечение по схеме. Аннотации описываются отдельно от бетона и стержней: их отсутствие не должно мешать формированию расчётной геометрии.
Завершите описание вызовом Finish и верните полученный результат. После этого общий сборщик проверит геометрию и подготовит бетон, сетку, арматуру и необязательные аннотации. Расчётные имена элементов также создаёт общая программа.
## 6. Подключите тип к списку выбора
В CSectionTypeRegistry.Class_Initialize добавьте одну запись с именем нового типа, его классом и именем входной таблицы. Возьмите соседнюю запись за образец. Затем вернитесь в Excel и через Alt+F8 выполните UpdateSectionRecipeTypes: новый вариант появится в списке Geometry.Type.
Для подключения типа не требуется добавлять отдельные ветви в расчёт НДС, трещин или устойчивости. Эти расчёты получают одно и то же представление готового сечения независимо от того, какой рецепт его сформировал.
## 7. Проверьте работу на простом наборе размеров
Выберите новый Geometry.Type, заполните его таблицу и нажмите «Сформировать сечение». Сначала проверьте наружную границу и отверстия, затем сетку, число и положение стержней, размеры и подписи. Для простой формы полезно сравнить площадь с ручным расчётом.
После проверки геометрии выполните обычный расчёт с заданными N, Mx и My. Отдельно проверьте смену единиц и ошибочный ввод: например нулевую высоту или отверстие вне наружной границы. Сообщение должно помогать исправить данные, а неверное сечение не должно незаметно заменяться другим.
## Где посмотреть параметры методов
В modSectionRecipeApiGuide приведены точные сигнатуры методов, все аргументы, единицы и готовые примеры. Найти метод по имени можно сочетанием Ctrl+F. Используйте этот модуль как справочник во время работы, а приведённые выше шаги — как общий порядок подключения нового типа.
