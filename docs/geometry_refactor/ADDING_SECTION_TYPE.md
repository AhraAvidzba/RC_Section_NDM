# Добавление нового типа сечения

Геометрию нового сечения можно задать декларативно: описать, что нужно получить — границы бетона, отверстия и расположение стержней.
Построение сетки, создание стержней и проверки программа выполняет по этому описанию автоматически. Оно задаётся готовыми методами API в классе VBA.

## Возможности
Готовые контуры: facade.RectanglePath — прямоугольник; facade.CirclePath — окружность; facade.AdjacentRectangles — общий контур смежных прямоугольников без перекрытий.
Многоугольник: задайте вершины и радиусы через CPolygonSpec.AddVertex (0 — без скругления), затем Seal и facade.RoundedPolygon. Замкнутую последовательность отрезков и дуг создают через CGeometryPath.AddLine / AddArc, затем Seal True и facade.AddPath.
Для выбора участка методом Chain имя сегмента можно получить по координатам точки через path.ResolveAnchor. Выбирайте точку внутри нужного отрезка или дуги: общий стык нескольких сегментов неоднозначен. Подробный пример — в modSectionRecipeApiGuide. Готовую замкнутую линию назначьте наружной границей через Outer или отверстием через Opening, указав имя наружной границы. Для отдельных бетонных областей задают свои наружные контуры. Точные вызовы и примеры всех способов — в modSectionRecipeApiGuide.
В классе нового типа опишите, как программа должна получить линию центров арматурных стержней. В штатных типах она строится автоматически из контура с учётом расстояния as до осей стержней. Для нового типа можно также использовать смещение контура или задать отдельный отрезок, дугу, окружность либо непрерывную последовательность таких участков. В API геометрическая линия называется Path («путь»); замкнутая линия может задавать и границу бетона или отверстия.

Затем укажите диаметр стержней и способ их размещения: заданное число стержней, наибольшее допустимое расстояние между соседними стержнями, точное расстояние между ними или отдельные места, заданные расстояниями от начала линии. Для нескольких независимых линий число стержней задаётся отдельно на каждой.

Можно сместить линию размещения арматуры, повернуть или отразить её; создать дополнительный ряд относительно стержней уже заданного ряда. Можно также спроецировать центры стержней исходного ряда на другую линию: по нормали к исходной линии либо по отдельно заданному направлению. Центры новых стержней будут находиться в точках пересечения лучей проекции с целевой линией.

Размеры сечения, поясняющий текст и подписи числа и диаметра стержней задаются отдельно. RebarLabel поддерживает любую нормаль normalX/normalY, например (1,1) для диагонали; у отверстия её направляют в пустоту. Текст подписи и размера, в том числе Dimension с Aligned, следует своей линии и разворачивается для удобного чтения. На стороне без арматуры подпись не выводится.

## Порядок действий

1. В редакторе VBA (Alt+F11) создайте класс с Implements ISectionRecipe.
2. В CreateDefinition получите копии входных таблиц через context.Table и закрытую копию единиц через context.Units. Переведите введённые размеры в мм методами CUnitSystem; перенастраивать этот объект нельзя. Сам класс описания сечения не должен читать ячейки Excel.
3. Создайте CSectionDefinitionBuilder и один раз вызовите Initialize. Задайте геометрические линии с уникальными именами (ID). Создающие команды сразу регистрируют линии; их результат повторно передавать в AddPath не нужно. Замкнутую наружную границу назначьте методом Outer, а отверстие — Opening с именем соответствующей наружной границы.
4. Опишите получение линий центров арматуры, например смещением контура с учётом as. Задайте диаметры и число стержней либо расстояния между ними. Дополнительный ряд можно связать с уже заданным рядом. В CRebarRuleOptions поле AnnotationGroup объединяет стержни в одну подпись, Publication задаёт порядок их вывода, Coincidence — обработку совпавших позиций. ConfigureDependentContact задаёт контактное расстояние дополнительного ряда при строго положительных диаметрах. Отключённый ряд рецепт пропускает до вызова этого помощника; ноль в нём вызывает ошибку. Произвольное смещение задаётся полями NormalOffset/TangentOffset.
5. При необходимости добавьте размеры и подписи. Anchor задаёт исходную точку, PathAnchor — точку готовой линии; Dimension с Aligned показывает истинное расстояние между ними, с Horizontal/Vertical — проекцию. Вызовите Finish, чтобы проверить контуры и ссылки и завершить описание. После него новые команды и повторный Finish запрещены. Арматурные условия и фактическое размещение проверяются общим Build до создания сетки.
6. В CSectionTypeRegistry.Class_Initialize добавьте вызов RegisterRecipe с именем типа, экземпляром нового класса и именами его входных таблиц. Запустите макрос UpdateSectionRecipeConfig через Alt+F8: он обновит список Geometry.Type по реестру.
7. Проверьте форму, сетку, арматуру, схему, единицы, равновесие и сообщения при неверном вводе. Проверьте каждую сторону с отключённой арматурой. Примеры реализации есть в VBE этой книги: CSectionRecipeCircle и CSectionRecipeRoundedRectangle.

## Короткий пример контура

В примерах уже создан объект facade типа CSectionDefinitionBuilder; path имеет тип CGeometryPath, options — CRebarRuleOptions. Все размеры здесь в мм. Следующие две строки задают наружную границу прямоугольника 600 × 1000 мм:

```vb
Set path = facade.RectanglePath("Boundary", 0#, 0#, 600#, 1000#) ' Boundary: имя; (0,0): нижний угол; 600,1000: B,H в мм.
facade.Outer "OUTER", path.ID ' OUTER: имя границы бетона; path.ID: замкнутый контур.
```

Для отверстия создайте другую замкнутую линию и передайте в Opening её имя и имя наружной границы, внутри которой находится отверстие.

## Короткий пример арматуры

На горизонтальном отрезке от (50; 950) до (550; 950) размещаются пять стержней диаметром 20 мм. В этом примере линия задана координатами; для её получения из наружного контура есть методы Offset и OffsetRoundedPolygon. Имя Top объединяет стержни для общей подписи:

```vb
Set path = facade.LinePath("TopAxis", 50#, 950#, 550#, 950#) ' TopAxis: имя; (50,950) и (550,950): концы линии, мм.
Set options = New CRebarRuleOptions: options.AnnotationGroup = "Top" ' Top: общая подпись верхних рядов.
facade.RebarByCount "Top.Main", path.ID, 5, 20#, options ' Top.Main: ряд; path.ID: линия; 5: число; 20: диаметр, мм.
```

Нулевое число стержней или нулевой диаметр отключают ряд. Условие EverySecond создаёт дополнительный ряд только у первого, третьего и следующих нечётных стержней исходного ряда; на каждой независимой линии отсчёт начинается заново.

## Короткий пример аннотаций

Первая строка добавляет подпись числа и диаметра стержней верхнего ряда. Вторая — горизонтальный размер B между x = 0 и x = 600 на уровне y = 1000:

```vb
facade.RebarRowLabel "Top", "Top.Main", 0#, 1# ' Top: группа; Top.Main: ряд; (0,1): направление подписи вверх.
facade.HorizontalDistance "DIM_B", "B", 0#, 600#, 1000# ' DIM_B: имя; B: подпись; 0,600: X точек; 1000: Y, мм.
```

Подпись арматуры учитывает фактически созданные стержни и исчезает, если их нет. Размеры сечения сохраняются и на сторонах без арматуры.

## Справочник методов создания сечения

Откройте редактор VBA (Alt+F11), окно проекта (Ctrl+R), затем Modules → modSectionRecipeApiGuide. Здесь описаны методы создания геометрии, арматуры и аннотаций, чтение размеров и подключение нового типа. Справочник разбит на девять разделов; для каждого метода указаны назначение, точная запись вызова, параметры, единицы и значения по умолчанию. Найти метод можно через Ctrl+F по имени.

Как примеры нового сечения используйте штатные классы-рецепты CSectionRecipeCircle (круг), CSectionRecipeRectSet (прямоугольные сечения), CSectionRecipeRoundedRectangle (скруглённые стороны) и CSectionRecipeHollowRectangle (сечение с отверстием). Они находятся в редакторе VBA этой книги: Alt+F11 → Ctrl+R → Class Modules. Код общих методов смотрите в соответствующих классах этого же проекта.
