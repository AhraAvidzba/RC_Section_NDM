## Сквозной Рецепт Circle: Локальный Этап

Реализованы ISectionRecipe, CSectionRecipeContext, generic Excel snapshot
adapter, CSectionDefinition, CSectionDefinitionBuilder, options/UDT и общий
CSectionBuilder. Definition не хранит context, Range, reader или solver.
Подготовленные пути опубликованы; выдаваемые контуры и бетонная область -
независимые копии. Outer/Opening проверяются по заявленным ролям и родителю,
включая несколько отверстий. Расчетная сетка собирается прежним mesh/query.

CRebarRuleExecutor готовит ByCount/ByMaxStep/ByFixedStep/Explicit/ProjectFrom/
DependentOffset, затем отдельно публикует позиции. Общий interleaved порядок
сохраняет прежние Circle B1/B1_R2/B1_R3. Отбор EverySecond и проекции не
привязаны к имени типа. Геометрические экстремумы и фактические подписи
используются общим annotation builder. BoundaryDistance добавлен в query
для прежней Circle-проверки целого диска дополнительных стержней.

CSectionRecipeCircle описывает ввод и правила, не вызывает старые генераторы.
Добавлена одна RegisterRecipe в существующий registry. Старые Select Case
еще используются production-маршрутом до полного переноса всех семейств;
они не являются fallback нового сборщика и подлежат обязательному удалению.

## Сквозной Рецепт RectSet: Локальный Этап

Добавлен один CSectionRecipeRectSet и одна регистрация. Ввод Rectangle,
LSection/RectSet и TwoRectangles/aliases интерпретируется только рецептом
из generic snapshot. Неактивные нижние грани, дополнительные ряды и смещение
не читаются. Общий query собирает смежные неперекрывающиеся прямоугольники;
он не объявлен Boolean Union произвольных пересекающихся областей.

Общий исполнитель поддерживает FromPathMiddle независимо от геометрического
ordinal и interleaved publication. EverySecond продолжает отсчитываться по
исходному ряду. Политики RejectCoincidence/MergeIdentical/KeepPublishedOwner
задают владельца явно; один физический стержень сохраняет несколько memberships.
По последнему уточнению пользователя memberships нужны только для трассировки:
стержень включается в подпись лишь группы владельца, сумма подписей должна
равняться физическому количеству. Повторные привязки группы не дублируют подпись.
Row labels используют концы подготовленного ряда и фактические диаметры.
Preflight проверяет потенциальное число позиций до больших массивов.

CRebarLayout использует индекс ID, пространственный поиск и удвоение capacity.
Квантование не меняет координаты или допуск: совпадение проверяется прежним
условием по исходным X/Y, владелец - первый опубликованный кандидат.

## Именованные Цепочки И Согласованные Смещения

Общий CSectionGeometryQuery.OffsetRoundedPolygon смещает весь исходный
скругленный многоугольник, а не отдельные несопряженные ребра. Направление
не зависит от обхода: положительное расстояние внутрь площади, отрицательное
наружу (из отверстия в бетон). Выпуклые радиусы уменьшаются, вогнутые растут;
исходные острые углы сохраняются. Исчезновение дуги не меняет имен граней.
Исчезнувший/изменивший топологию путь отклоняется, не заменяется другой частью.
Введенный радиус исходного бетонного контура не уменьшается молча.

CGeometryPath выбирает цепочку по SegmentID и параметру 0..1 с явным
направлением. Обход замкнутого пути через начало не добавляет хорду.
Для совпавших привязок полный обход задается явно, включая эквивалентные
параметры 0/1 окружности. Части хранят SourcePathID/SourceSegmentID и исходный
интервал; Slice/Reversed/Transformed/WithID сохраняют и композиционно
преобразуют эти ссылки. Фасад предоставляет Chain и Transform.

В соответствии с новым уточнением пользователя сложные рецепты разделяются
по смыслу без отдельных классов на этап. В RectSet выделены ReadDimensions,
AddGeometry, AddRectangleRows и AddDimensions; основной метод показывает
порядок сборки. LSection/TwoRectangles не дублируют одинаковую геометрическую
операцию. Circle остается коротким линейным рецептом со смысловыми блоками.
Для RoundedRectangle/HollowRectangle применяется тот же принцип, без
искусственного ограничения строк и без переноса математики в рецепт.
