# F02 и подписи арматуры: версия для повторной проверки кода

Подготовлены исправления геометрии и подписей по последним замечаниям
пользователя. Полные on/off остановлены по его указанию. Эта редакция
предназначена для внешней проверки ALL CODE; итоговая полная приёмка и push
отложены до результатов этой проверки.

## Геометрия F02

В случае B=600, H=1200 мм, Simple/Simple, R1=50/550 мм, as=50 мм исчезают
прямые участки и две угловые дуги. Построитель CSectionGeometryQuery теперь
сохраняет их имена как положения стыков в CGeometryPath. Физические сегменты
не добавляются, радиусы не меняются, дуги остаются аналитическими.

Такие привязки сохраняются при копировании, повороте/отражении, обратном
обходе и выделении части линии, включая переход через начало замкнутого
контура. Неизвестное имя, пустой участок и поиск отсутствующего физического
сегмента остаются ошибками. В CSectionRecipeRoundedRectangle удалены все
пять проверок наличия сегментов: рецепт задаёт только нужные части контура.

937 направленных проверок проходят на восьми геометриях: точные координаты
и количество стержней, аналитические дуги, 96 равновесных состояний,
восемь схем и восемь штатных расчётов текущего НДС. 7958 записей обычных
Simple/Tapered/смешанных вариантов точно совпадают с прежней книгой,
включая представление чисел. Численные эталоны и допуски не менялись.

Прежний отдельный случай с положительной дугой радиуса 0,001 мм упирается
в существующий допуск проверки топологии. Он не относится к исчезнувшим
сегментам и этой правкой не изменён; соседний корректный случай as=49 мм
включён в проверку. Исходный неуспешный журнал сохранён.

## Отступ и состав подписи

Раньше Plot.RebarLabels.Offset откладывался от опорной линии арматуры.
Теперь общий геометрический запрос находит бетонную границу по нормали
подписи. Reader использует сохранённые контуры Results; повторный импорт
или расчёт не выполняется. Layout сначала переносит опору на эту границу,
затем откладывает Offset в сторону Outside или Inside. На прямой наружной
грани расстояние от оси ряда до линии подписи для Outside равно as + Offset.
На дугах определяется действительное расстояние до контура. TextGap по-прежнему
задаёт дополнительный зазор между линией подписи и текстом.

По последнему уточнению пользователя стандартный Offset уменьшен с 60 до
30 мм в Config, каталоге настроек, самостоятельном layout и запасном значении
плоттера. Отступ размерных линий и расстояния между рядами не менялись.
Справка и комментарии Config теперь описывают отсчёт от бетонной границы.

Сборщик CRebarGroupAnnotationBuilder уже суммирует все физические стержни
одной смысловой стороны по диаметрам. Дополнительные связи совпавшего
стержня не увеличивают количество. Изменение этого алгоритма не потребовалось.
Новые проверки задают два и три ряда отдельными независимыми правилами,
со своими as=50/100/150 мм, количеством и диаметром. Проверены подписи
7Ø20, 12Ø20, 3Ø20 + 4Ø16 и 7Ø20 + 5Ø16; повторная привязка не дублирует подпись.
Для общей подписи всех рядов указывается общая AnnotationGroup стороны.

63 новые проверки подтверждают четыре направления прямоугольника,
Outside/Inside, наружную границу и отверстие, точные дуги, внешнюю опору
импорта, отсутствие пересечения, отклонение нулевой нормали, стандартные
30 мм, чтение Results в мм/см/м после изменения OUTPUT и полные подписи
независимых рядов. При импорте без достоверного Outer сохраняется прежняя
приблизительная опора: точную бетонную границу из отсутствующих контуров
не восстанавливаем. Это ограничение относится только к оформлению схемы.

Нативные PNG с Offset=30 мм проверены для граничного F02, обычного
прямоугольника, круга, HollowOffset и независимых рядов. Сближение подписей
с размерными надписями, наблюдавшееся при прежних 60 мм после изменения
точки отсчёта, на этих снимках с новым стандартным значением устранено.
Произвольные пользовательские настройки зазоров полной UI-приёмкой не охвачены.

## Проверки и сохранение данных

В последнем выбранном наборе 2145 PASS, 0 FAIL: подписи63, F02 937,
аннотации39, снимок аннотаций24, прежние замечания742, равновесие336,
обычные снимки4. Повторные промежуточные прогоны к этому числу не добавляются.
Дополнительно сохранены схемы Circle/HollowOffset и независимых рядов.
Проверки исходного контракта операций и диагностики F02 ранее дали 512 PASS.

Ранний новый test harness ошибочно передал вложенный массив вместо
двумерного массива PolygonRegion и пытался объявить несколько аннотаций
с одним ID. Эти предположения исправлены в тесте; production для обхода
ошибок теста не менялся. Неуспешный LabelsDirected.txt сохранён.

Проверка 52003 пользовательских ячеек сохраняет данные, формулы, кэши,
оформление, списки, имена и ссылки. Единственное согласованное числовое
изменение Config — Plot.RebarLabels.Offset 60 -> 30, адрес определяется
через rngPlotAnnotationSettings. Изменения текста Справки проверяются
отдельной точной картой. Области печати сохраняются после COM-обновления.
API275 остаётся модулем комментариев без тел методов; руководство содержит
61 строку. Нормативные документы и расчётные формулы не изменялись.

Частичный полный Off завершил пять suite (33750 PASS, 0 FAIL), затем был
остановлен во время Batch. Полный Off, On, дополнения и полный UI не приняты.
Подтверждалось только известное предупреждение объединения ячеек в собственном
временном Excel; вмешательства записаны. Завершены только проверенные
собственные процессы. Чужие процессы Excel/AutoCAD не закрывались.

Фактические хеши, сверка 149 компонентов VBA и публикация пары книга/ALL CODE
фиксируются в F02_REVIEW_ACCEPTANCE_EVIDENCE.json. Журналы и исходные артефакты
сохраняются в F02ReviewEvidence.zip. Внешние файлы в пользовательской Справке
не упоминаются. Полные прогоны и push ожидают внешней проверки кода.
