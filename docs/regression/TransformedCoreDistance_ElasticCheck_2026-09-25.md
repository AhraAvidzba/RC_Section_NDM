# Проверка ядровых расстояний при малой нагрузке

Дата проверки: 2026-09-25.

Цель: проверить гипотезу, что большое расхождение между `Transformed.CoreDistance...` и фактическим НДС связано с выходом материалов на горизонтальное плато. Для этого та же геометрия RectSet / LSection с перекошенным армированием была проверена при малой сжимающей силе `N = 1 тс`.

## Ключевой вывод

Уменьшение нагрузки само по себе не устраняет расхождение для текущего `StrengthState`.

Причина: в используемой диаграмме `StrengthState` начальный сжатый участок бетона уже имеет наклон около `10333 МПа`, а справочные `Transformed.CoreDistance...` считаются через обычные модули `Eb = 32500 МПа`, `Es = 200000 МПа`.

```text
Transformed.*:        Es / Eb    = 200000 / 32500  = 6.154
StrengthState около 0: Es / Ediag = 200000 / 10333 = 19.355
```

То есть даже при очень малой нагрузке фактический НДС работает с другим отношением жесткостей арматуры и бетона. Плато здесь не является основной причиной.

## Важное замечание о точке проверки

`Transformed.CoreDistance...` относится к границе бетонного сечения.

Выводимые напряжения/деформации НДС по бетонным элементам относятся к центрам дискретных элементов. Поэтому даже в идеально линейной постановке центр крайнего элемента может оставаться сжатым, когда реальная граница элемента уже находится на нулевой деформации.

Ниже в таблицах отдельно показаны:

- `r по границе КЭ` - когда нулевая деформация достигается на реальной границе прямоугольного бетонного элемента;
- `r по центрам КЭ` - когда нулевая деформация достигается в центре крайнего дискретного элемента.

## Сравнение с N = 100 тс

Для текущей `StrengthState` границы по центрам КЭ при `N = 1 тс` и `N = 100 тс` совпали. Это ожидаемо: в проверяемом диапазоне диаграмма остается линейной с постоянным наклоном, поэтому масштаб нагрузки меняет величины деформаций и напряжений, но не меняет эксцентриситет, при котором начинается растяжение.

## Итог

Гипотеза частично верна только в таком виде: если диаграмма действительно имеет тот же начальный наклон, который использован при расчете `Transformed.*`, то ядровые расстояния сходятся хорошо.

Для текущего `StrengthState` это условие не выполняется даже при очень малой нагрузке, потому что начальный наклон бетона в диаграмме прочности отличается от `Eb`. Поэтому уменьшение нагрузки не обязано приводить к совпадению с `Transformed.CoreDistance...`.

Отдельно важно не сравнивать напрямую ядровое расстояние до границы с напряжением в центре крайнего бетонного элемента. При шаге сетки `50 мм` центр крайнего элемента находится заметно внутри сечения, поэтому он остается сжатым даже тогда, когда граница элемента уже близка к нулевой деформации.
