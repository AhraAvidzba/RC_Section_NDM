## Interpretation

While the compressed side remains on the initial `Eb` branch of the ThreeLine diagram, the difference is governed mostly by mesh discretization. Once the boundary state enters the transition branch, the nonlinear NDM boundary moves away from the linear transformed-section core distance. Therefore `Transformed.CoreDistance...` is a reference linear transformed-section property, not an exact no-tension boundary for a nonlinear material state outside the initial branch.
