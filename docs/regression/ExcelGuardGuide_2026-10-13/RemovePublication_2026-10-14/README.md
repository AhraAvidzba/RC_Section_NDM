# Доказательства изменения API настроек арматуры

Исходная версия: 6c32304beec56fd672a582a3b7632891bcf1e144.
Основные решения и ограничения описаны в
`docs/reports/PublicationOptions_2026-10-14.md`.

Acceptance.json сводит пять требований цели и последнее уточнение
пользователя о пояснениях справа. Equivalence.json и VerifyEquivalence.py
подтверждают эквивалентность всех 13 замен, прежние defaults и отсутствие
изменений остальных 145 исходных компонентов.

ExactSnapshots.zip содержит точные native-экспорты исходной и основной
книги, девять снимков геометрии до/после, 12 контрольных НДС до/после,
тексты семи адресных наборов и квитанции отдельных запусков.
Это архив доказательств: старый API присутствует только в снимке прежней
версии. В распространяемой книге, ALL CODE и текущей документации его нет.

PublishedSourceEquality.json, PublishedPreservation.json и
PublishedStandaloneHelp.json получены независимым чтением фактической
основной книги. Publication.json подтверждает равенство ALL CODE этому
экспорту и сохранение пользовательского execution_report. Нативная
приёмка текста Справки находится в GuideNativeAccepted/GuideEvidence.json.

XLSM-копии не включены в Git. Исходную книгу можно восстановить из указанного
коммита; для бинарного файла нужен бинарный вывод git show без текстового
перекодирования PowerShell. Основная итоговая книга и ALL CODE находятся
в workbook/output. Для повторных расчётов используются только частные
копии в этом каталоге через RunDirected.ps1; помощник ControlStates.bas
подключается только к тестовой копии. Полные ON/OFF этот этап не запускает.
