# Приёмка общей толщины контура

Итог — Acceptance.json, отчёт — docs/reports/ContourLineWeight_2026-10-15.md.
Default 2 pt и название «Настройки оформления схемы» приняты по уточнениям
пользователя. Старое фиксированное значение — 1,7 pt.

Directed03 — принятый прогон 994 утверждений. Directed02 содержит
ошибку порядковых номеров синтетического снимка; она исправлена в тесте.
Рабочая проверка формата контура сохранена. NativeCheck проверяет
фактическую строку и новый шаблон. Preservation/PublishedPreservation —
сохранность значений, формул, стилей, имён и рисунков.

BeforeUserSave фиксирует первоначальный исходный файл, Before — после
сохранения последних данных пользователя. Нативный VBA в обеих версиях
совпадает; изменения данных пользователя включены в baseline.
Пользовательский execution_report не изменялся задачей.

NativeSnapshots.zip содержит InitialNativeVBA, BaselineNativeVBA,
FinalNativeVBA и PublishedNativeVBA. При повторной сверке экспорты можно
распаковать из архива. Основная книга совпадает с опубликованным снимком;
ALL CODE равен реальному экспорту. Частные расходные XLSM не хранятся
в Git. Отдельный локальный Baseline сохраняет исходные данные пользователя.

RestoredApiReferences перечисляет 89 ссылочных протоколов, восстановленных
из локального архива очистки с исходными SHA256 и добавленных в Git.
Необязательный снимок Config через clipboard не получен; проверка не
выдаёт его за доказательство. Реальные толщины подтверждаются Shape.Line.Weight.
