# Независимые привязки арматуры круга

Этап начат 14.10.2026, принят 15.10.2026. Исходный коммит — d9e13456.
Acceptance.json содержит итоговые критерии. PublishedPreservation.json
и PublishedSourceEquality.json проверяют фактическую основную книгу.
Publication.json подтверждает её независимое чтение и равенство ALL CODE.

ExactSnapshots.zip содержит native-код до/после, девять полных снимков
геометрии и тексты адресных проверок. Отдельно сохранены квитанции
миграции Config и штатной сборки таблицы круга. Частные XLSM не включены.
Старую книгу для сравнения можно получить из указанного Git-коммита
бинарным выводом git show без текстового перекодирования.

VerifyAcceptance.py разрешает только два новых списка, две строки круга,
соответствующий сдвиг таблиц, четыре изменённые границы общих формул единиц
и один абзац Справки. Стили сравниваются по содержимому, а не по их
переупорядоченным Excel индексам. Цифровая модель остаётся прежней при
EachBar; при сравнении снимков исключаются только новые INPUT-ячейки.

OpenProbe.json отражает диагностику технического сохранения XML-стилей
в частных копиях. Исправленный файл и фактическая основная книга открыты
обычным Excel без восстановления, проверены независимо и получили PASS.
Рабочие VBA-алгоритмы при этой диагностике не изменялись.

RunDirected.ps1 запускает только собственные копии в этом каталоге;
FactoryTest.ps1 проверяет новую таблицу в несохраняемой отдельной книге.
Полные ON/OFF этот этап не запускает.
