Verify-Candidate.py --baseline Baseline/RC_Section_NDM.xlsm
 --candidate Release/RC_Section_NDM.xlsm --native <Release09/NativeVBA.txt>
 --baseline-native <Baseline/NativeVBA.txt> — сравнение содержимого, оформления,
списков, имён и фактически встроенного VBA. Baseline/Release XLSM хранятся локально.
Исходную книгу можно восстановить из Git 33181b12:workbook/output/RC_Section_NDM.xlsm;
SHA256 должен быть 7B4C769D3813CE0057FFA93026281CD8ED7D3DC23F60159A2655882AB37D2772.
Нормализация VBE ограничена регистром идентификаторов, формой числовых литералов,
его прежним Double-sentinel и ранее существовавшими комментариями CP1251.
Строковые литералы и новые комментарии проверяются без потерь.
