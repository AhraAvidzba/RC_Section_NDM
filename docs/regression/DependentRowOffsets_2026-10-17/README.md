# Доказательства приёмки

Итог: `FinalAudit.json`, `Publication.json`, `Acceptance.json`.
Отчёт: `../../reports/DependentRowOffsets_2026-10-17.md`.

`Evidence.zip` содержит исходные численные матрицы и большие журналы,
предварительные снимки и полную перепись прежнего Config. Пути внутри ZIP
относительны этой папке; состав и SHA256 указаны в `ArchiveManifest.json`.
Архив проверен чтением каждой записи до удаления исходных дубликатов.

Итоговые небольшие журналы, на которые ссылается каталог API, JSON-приёмка
и снимки `OffsetExamples07` оставлены доступными отдельно. Схемы созданы
реальным Excel; увеличенный фрагмент — обрезка его же PNG без изменения рисунка.

46 собственных промежуточных книг удалены. Локально сохранены только точная
исходная `Baseline.xlsm` и принятая `Accepted.xlsm`; они не добавляются в Git.
Рабочая книга распространяется из `workbook/output/RC_Section_NDM.xlsm`.
Все добавленные одноразовые миграционные PS1 удалены, включая временную
подготовку унифицированной таблицы круга.

Запуски с отказами сохранены как диагностика. Для итоговой приёмки используйте
`ProfileFinal`, `UnifiedDirected03`, `OffsetExamples07`, `DirectTemplate07`
и финальные JSON; первоначальные попытки не означают PASS.
