# Дополнение к текущей цели: региональные настройки

Пользователь 26.10.2026 прямо включил в текущий архитектурный рефакторинг аудит ВСЕГО актуального VBA на зависимости от Windows/Excel локали, особенно десятичного разделителя. Особый охват: CSystemSettingsReader.GetDouble/GetRequiredDouble, чтение Excel, AutoCAD, сохранение и восстановление снимков. Исправлять только доказанные проблемы, без механической замены CDbl; исключить случайную интерпретацию разделителей тысяч. Сохранить математические алгоритмы, единицы, результаты и совместимость файлов, максимально использовать прежние классы/модули. Проверить точку и запятую, включая сохранение/reopen/readback; рискованные изменения без достаточной уверенности не вносить.

Работа включена в этап5 границы настроек, с необходимой адресной проверкой остальных входных/сериализационных адаптеров. RawConversionInventory — исходный список вызовов для ручной классификации, НЕ доказательство дефектности каждого вызова. Числовые COM/Value2/Binary Double преобразования отделить от текстового ввода, сериализации и отображения. Пользовательскую Windows-локаль и пользовательские Excel не менять для тестов; локальные настройки допускаются только в собственном проверяемом процессе с гарантированным восстановлением. Проверку настоящего Windows LCID отделять от переключения Excel.DecimalSeparator и не выдавать одно за другое. Общую цель/полную приёмку не объявлять завершённой до этого аудита и адресных gate-ов.
