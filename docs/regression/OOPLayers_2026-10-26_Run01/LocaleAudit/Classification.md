# Классификация границ локали — итог направленного разбора

Обход src/tests и текущих VBA-шаблонов tools/build_workbook ведётся по AuditFileInventory.json, с номерами преобразований. Хеши обновлены после всех исправлений; шесть нативных document modules перечислены отдельно. Инвентаризация сама по себе не является PASS.

- CSystemSettingsReader: во время LoadFromWorkbook/Range захватывает значения и строки адресов. После загрузки Get*/InputLocation используют массивы; вызов прежнего ApplicationDecimalSeparator был чистым CStr VBA, а не COM Excel. Новый parser тоже чистый. CCalculationSettings не создаётся.
- CMaterialModelProvider/ядро/единицы/solver: подготовленные числовые параметры. Внутренние CDbl/CLng индексов, счётчиков, типизированных чисел и вариантов математических массивов оставлены; математические алгоритмы не заменяются парсером.
- CAutoCADSectionModelImporter/CAutoCADContourReader: реальные Area/Centroid/Moments/Coordinates/Elevation/Radius/Normal — числовые COM-значения, не локализованные строки. Преобразования сохранены. TestOptionalRegionDouble относится к явно тестовому fake-входу.
- CBinarySnapshotFile/CCalculationSnapshotStore: числа хранятся бинарно Double/Long с флагами типов, строки — отдельным словарём. Нет текстового десятичного формата чисел; CDbl вызывается только в соответствующей numeric-ветви. Формат файла и поддержка старых колонок не меняются.
- ReadContourArcSweep: до CDbl уже проверял весь текст и допустимые символы, нормализовал десятичный знак; не заменён.
- Results/схема/AutoCAD-export: читают матрицы сохранённого снимка. Здесь обнаружены подтверждённые текстовые границы, исправления и проверки завершены в Stage5b/5c/5d. Проверка перед последующим использованием сырого массива должна сопровождаться получением канонического Double, а не повторным locale-зависимым преобразованием старой строки.
- CStateRequest/геометрические spatial-ключи/имена индексов: Format/CStr служат индексом или непрозрачной строкой внутри одного процесса, не чтением инженерного числа. Численная эквивалентность состояния дополнительно проверяет исходные Double. Не переписывались ради формальной унификации.
- Format для UI/отчётов/подписей: представление, не источник управления. Инвариантный числовой текст помеченных протоколов явно заменяет запятую точкой.
- CCalculationProfileCatalog.IsProfileIdText: IsNumeric распознаёт текст заголовка PR*, а не преобразует инженерное число. Изменение допустимых ID не вносилось без подтверждённой ошибки; это не путь численного ввода.
- OverloadTimingProbe/PlateauSlopeBatchProbe — частные экспериментальные фрагменты, отсутствующие в178-компонентной книге. Их Val получает инвариантную спецификацию: Run-OverloadTiming.ps1 явно использует ToString(R,InvariantCulture); Run-PlateauSlopeExperiment.ps1 задаёт фиксированные ASCII alpha. Они не принимают региональный пользовательский ввод; сохранены, не импортируются в production.

Ограничение: две настройки Excel и Windows LCID собственного потока фактически не переключили CStr/Format VBA в этой установке. Это отражается в отчёте, полноценная смена системной локали не заявляется. Настройки пользователя не меняются.
