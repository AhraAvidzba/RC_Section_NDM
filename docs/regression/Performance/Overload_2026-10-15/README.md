# Перегрузки и ранняя проверка постоянной нагрузки — 15.10.2026

Итог: Acceptance.json; численные замеры и сравнения — MeasurementsAcceptance.json.
Отчёт: docs/reports/performance/Overload_2026-10-15.md.

Состав: исходный круг Ø300/8Ø20/as=40, сетки 50 и 10 мм; N=500 тс,
Mx/My=100 тс·м; контрольные 0,5×/0,9× и перегрузки 2×/3×/4× по отношению
N:M примера, калиброванные по подтверждённому λ*NMxy. Замеры включают
штатную подготовку, Results, отчёт и схему. Параллельных расчётов во время
замеров не было. Для Auto сравнивались также точные предельные плоскости.

Исходная плотная сетка: 19,297/20,156 с, 192/190 итераций UltimateStrain.
Окончательный код: три повтора на ось, 1,203–1,680 с и 4 итерации.
LoadMultiplier: семь делений λ, допуск 0,01, 1,313–1,633 с.
2016 направленных assertions прошли. Полные on/off и UI не запускались.

Порядок воспроизведения изолированной диагностики:

1. Prepare-FocusedAcceptance.ps1 с ExtraHelperFile=OverloadTimingProbe.bas.
2. Run-OverloadTiming.ps1 для нужной копии; UserCircleCase/MeshStep=10,
   затем CircleFixture/Shapes=Circle/
   Families=UserRatio и Overloads=0.5,0.9,2,3,4.
3. Prepare-OverloadCandidate.ps1 обновляет только четыре класса поиска и
   modTestCapacitySolver в отдельной копии. Повторить выбранные замеры.
4. Адресные макросы через Run-Audit03Watchdog.ps1 перечислены в
   MeasurementsAcceptance.json; Summarize-OverloadTiming.py сверяет результаты.
5. Stage-OverloadRelease.ps1 → отдельный выходной кандидат без probe →
   независимый экспорт → Package-OverloadRelease.py → OutputGuards →
   Publish-OverloadRelease.ps1 → фактический readback/source equality →
   Finalize-OverloadRelease.ps1 → Accept-OverloadRelease.py.

Измерительные вставки не входят в рабочую книгу. В Release заменён только
xl/vbaProject.bin; пользовательские данные сохранены. ALL CODE — фактический
экспорт основной книги. Baseline.xlsm оставлен локально как снимок входов;
временные тестовые книги после приёмки удаляются с отдельной описью.

OverloadEvidence.zip содержит нативные журналы, промежуточные и окончательные
замеры, параметры окружения, приёмку источников, публикацию и нативные экспорты.
Архив содержит также прежний VBA binary для восстановления исходного кода
при неизменённых остальных частях книги. Archive.json фиксирует содержимое
и хэши; TemporaryCleanup.json — только удалённые собственные временные файлы.

Промежуточные ошибки инструментов сохранены в доказательствах: неверное имя
свойства в первой подготовке probe, чтение hash открытой тестовой книги и
неподходящий линейный fixture для намеренной несходимости. Последующие
исправления относятся к диагностике; рабочие расчётные ожидания не подгонялись.
