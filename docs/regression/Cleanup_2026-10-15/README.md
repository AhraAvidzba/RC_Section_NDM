# Очистка локальных артефактов 15.10.2026

Итог — Summary.json. Основная книга, ALL CODE, исходники, нормы,
reference и пользовательский execution_report сохранены. Удалены
987 неотслеживаемых временных XLSM, 225 старых тестовых книг и локальные
библиотеки SciPy/NumPy. Четыре эталона/фикстуры сохранены по фактическим
ссылкам инструментов и назначению baseline.

Уникальные неотслеживаемые протоколы, скрипты, снимки и тестовые чертежи
сохранены в локальном LocalDiagnostics.zip с устранением повторов.
Внутренний manifest.json связывает прежний путь с содержимым и SHA256.
Если точное содержимое уже есть в отслеживаемом файле/архиве, manifest
ссылается на него. Все новые payload проверены после повторного открытия
архива; исходники удалены только после проверки их неизменности.

LocalDiagnostics.zip (около 608 МиБ) и InventoryBefore.json.gz остаются
локально и не добавляются в Git. Не следует добавлять всю эту папку
командой git add -f. В Git сохраняются только небольшие протоколы очистки,
список удалённых старых книг с исходными blob-ID и инструменты.

Для восстановления одного локального протокола из корня проекта:

```powershell
python docs/regression/Cleanup_2026-10-15/Restore-LocalEvidence.py docs/regression/ExcelGuardGuide_2026-10-13/NoMigrations_2026-10-15/PublishedNativeVBA.txt
```

Для восстановления старой отслеживаемой тестовой книги:

```powershell
git restore --source=44f3bb25 --worktree -- docs/regression/Audit03/RC_Section_NDM_clean_v42.xlsm
```

Иные пути удалённых книг перечислены в HistoricalBooks.json. Они удалены
из текущего дерева, но остаются в истории. Неотслеживаемые временные XLSM
отдельно не архивировались: это расходные копии завершённых запусков,
а данные и протоколы испытаний сохранены.

История Git уплотнена через gc --prune=never без переписывания веток
или удаления недостижимых объектов. Проверка fsck --connectivity-only
--no-dangling прошла. Дополнительно удалены 13 старых tmp_obj_* (33,94 МиБ),
которые сам Git помечал garbage и которые не являются объектами истории.

Compact-LocalDiagnostics.py — протокол выполненной одноразовой операции.
Он намеренно отказывается заменять уже созданный архив; это не рабочая
часть книги и не автоматический очиститель будущих запусков.
