# Шапка таблицы φ_l / φ_m на Config

Полная сборка от 02.11.2026: исправлен перенос шапки таблицы 7.21 СП 35. Именованный диапазон `rngSP35Table721` остаётся на `Config!X60:AE78`; заголовок со ссылкой находится в `X58:AE58`, пояснение — в `X59:AE59`.

Причина: сборщик переносил только одну строку над именованной таблицей, тогда как её заголовок расположен на две строки выше. В `WorkbookLayout.json` задано `TitleRowsAbove = 2`; перенос включает обе строки, а повторное снятие раскладки сохраняет этот параметр.

Книга полностью создана штатным `Build-Workbook.ps1` из исходников через `Workbooks.Add`, VBA скомпилирован. После сохранения книга заново открыта в Excel только для чтения с отключёнными макросами.
