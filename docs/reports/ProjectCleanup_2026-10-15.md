# Очистка проекта 15.10.2026

По просьбе пользователя удалены накопленные расходные файлы завершённых
запусков. Размер папки уменьшен примерно с **20,52 до 6,48 ГиБ**,
освобождено **14,04 ГиБ** (около 15,1 десятичных ГБ). В исходном замере
учтена отдельно проверенная папка vendor, часть которой была недоступна
в sandbox. Перед очисткой на диске оставалось около 30 МБ.

## Выполнено

* Удалены 987 игнорируемых Git временных XLSM — 5,93 ГиБ. Проверены
  точные пути внутри docs/regression, отсутствие в Git, игнорирование,
  отсутствие reparse points и неизменность размера/времени записи.
* Удалены 225 отслеживаемых старых тестовых книг — 0,81 ГиБ. Перед
  удалением их Git blob совпал с исходным: чужих изменений не было.
  Они восстанавливаются из коммита 44f3bb25. Четыре используемых
  эталона/фикстуры оставлены после поиска зависимостей в инструментах.
* 15268 локальных протоколов/вспомогательных файлов сведены с устранением
  повторов в LocalDiagnostics.zip — 607,68 МиБ. Распакованные данные
  занимали 7,56 ГиБ. Уникальное содержимое сохранено; существующие точные
  копии в отслеживаемых файлах/архивах не дублировались. Проверены SHA256
  архивных данных и неизменность источников перед удалением. Убраны
  также Python bytecode и 1095 пустых папок.
* Удалён неотслеживаемый vendor SciPy/NumPy — 181,22 МиБ. requirements.txt,
  контрольные данные и результаты независимой проверки сохранены.
* Git gc --prune=never уплотнил базу без переписывания истории и удаления
  недостижимых объектов. Удалены 13 подтверждённых старых tmp_obj_*
  объёмом 33,94 МиБ. Git fsck --connectivity-only --no-dangling прошёл.

Локальный архив диагностики не добавлен в Git, чтобы не увеличивать
историю. В нём есть manifest.json со старыми адресами и контрольными
суммами. Restore-LocalEvidence.py восстанавливает один протокол по прежнему
пути. Список удалённых исторических книг содержит исходные blob-ID.
Исторические ссылки на расходные копии означают материалы старых запусков;
при необходимости они восстанавливаются описанными способами.

## Сохранность

Основная книга и ALL CODE не пересобирались. Их SHA256 остались прежними:

* RC_Section_NDM.xlsm: `427ed4735a3c3a5f260fbe28346c10131277ad5f2cddfb2fd1be9a14f78f815f`;
* VBA_All_Code.txt: `2268a0eec321eaaad6b09cc996a33d6365aa74580a7c292ad3e9b6ae9252767a`;
* пользовательский execution_report: `821a544b460f08657c64701dff744a10141b27fd22e7f32334cb456b8f623d52`.

Исходники, нормы, reference, контрольные данные, тесты, рабочие инструменты
и принятые доказательства не изменялись. До добавления этого отчёта Git diff
содержал только ожидаемые удаления 225 книг и прежнюю пользовательскую
правку execution_report. Процессы Excel/AutoCAD не закрывались.
Расчётные проверки не запускались: рабочий код и книга не менялись.

Оставшийся объём: .git около 3,52 ГиБ, docs около 2,90 ГиБ (включая
сохранённые доказательства и локальный архив), остальной проект —
около 0,06 ГиБ. Дальнейшее значительное уменьшение .git потребовало бы
отдельного решения об удалении исторических данных.

Протоколы: `docs/regression/Cleanup_2026-10-15/` — Summary.json,
TemporaryBooks.json, HistoricalBooks.json, Diagnostics.json, Vendor.json,
GitTemporaryObjects.json и README.md. Большие архивы локальны.
