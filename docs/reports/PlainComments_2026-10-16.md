# Понятные комментарии и порядок тестовых методов

## Выполненные изменения

Продолжена правка комментариев после `7a9b53a`. Обработаны 156 компонентов
VBA: рабочие классы и модули, тесты и четыре учебных компонента. Переписаны
2507 блоков или отдельных строк комментариев. Объяснения описывают хранимые
данные, действия метода и инженерный смысл; имена методов и настроек сохранены.

- В `CRebarLayout` пояснено ускорение поиска совпавших стержней: условная
  ячейка только сокращает поиск, а совпадение проверяется по исходным координатам.
- `CConcreteRegion` описан как универсальная бетонная область. Указаны его
  применения при подготовке сетки и областей взаимодействия бетона с арматурой.
  Пары контрольных точек объяснены как концы участков бетона вдоль прямых;
  площадь вычисляется по точным контурам отдельно от этих точек.
- В `CGeometryRegion` принадлежность границе объяснена через точки: наружная
  граница относится к бетону, граница отверстия исключается. Для отдельного
  бетонного участка внутри отверстия проверяется его собственный контур.
- У всех 1941 строк деклараций полей, констант и полей внутренних `Type`
  в 104 классах есть русское пояснение справа. Добавлены 515 отсутствовавших
  пояснений; для размерных величин указаны единицы там, где они нужны для понимания.
- В 16 рабочих компонентах выделены 49 методов только для тестов.
  В восьми компонентах изменён порядок процедур. В `CFiberMeshBuilder`
  рабочие `Freeze` и `IsReadOnly` теперь предшествуют тестовому `BuildSeconds`.
- У рабочих `CMaterialDiagram.PointStrain` и `PointStress` убрана ошибочная
  пометка «ДЛЯ ТЕСТОВ»: их вызывают поставщик материалов и запись Results.
  `CSystemSettingsReader.KeyCount` используется отчётом и также описан как рабочий.
- Упрощены пояснения общих расчётных классов, сохранения результатов, импорта,
  отрисовки и тестовых модулей. В подробном справочнике API сохранены отступы
  и структура; исправлены неясные пояснения без перестройки его оформления.

### Исправление тестовой обработки ошибки перед повтором

все части пользовательской книги кроме VBA; ALL CODE читается из опубликованной книги.

Первый полный запуск остановлен на этапе несущей способности и **не считается
приёмкой**. Его исходный отказ и частичные результаты сохранены в

пользовательский пример `RunSP35SavedHollowTests`, требующий ровно 56 стержней

После коммита этого исправления оба полных режима запускаются заново на одной

### Уточнение входных тестов после полного Off

В полном Off все шесть основных расчётных наборов прошли, а интерфейсный
набор дал 14 ошибок. Двенадцать относятся к одному состоянию INPUT3 круга:
проверка единиц сравнивала деформации последнего приближения после остановки
по лимиту итераций. Во всех единицах сохранены одинаковые `NumFail`, причина
остановки и комментарий. Равновесие для этого состояния не было найдено;
его деформации нельзя считать полученным НДС и требовать от них точного
совпадения при преобразовании чисел с плавающей точкой.

Частный повтор полного порядка подготовки воспроизвёл исходные числа:
ε₀ = 0.37886256852082445 для MPa, 0.37886211141500653 для kgf/cm²,
0.37886203363242477 для tf/m². Он сохранён в
`PlainCommentsAcceptance_2026-10-16/UiPrefixProbe4/`; это воспроизведение
ошибки тестового сравнения, а не успешная приёмка.

В проверке входных единиц эксплуатационные моменты двух сочетаний PR2
уменьшены в десять раз. Теперь каждый из 120 вариантов дополнительно требует
`OK` для обоих состояний трещин. Все численные сравнения, исходные допуски,
прочностные сочетания PR1, проверки несущей способности, единиц, статусов
и комментариев сохранены. Ни одно численное поле из сравнения не исключено.

Две оставшиеся ошибки — чтение устаревшего значения формулы выпадающего
списка после изменения сочетаний тестом при ручном пересчёте Excel.
Прямой пересчёт диапазона меняет старое значение `1` на ожидаемое `LC1`.
Обе тестовые процедуры теперь пересчитывают свой диапазон перед чтением.
Настройки пересчёта пользовательского Excel не меняются.

Изменены только три процедуры `modTestWorkbookInterface`; независимый
VBA-экспорт подтвердил неизменность всех остальных 156 встроенных компонентов,
включая весь рабочий код. Исправленная книга компилируется и совпадает со
всеми 152 исходными компонентами. Все ZIP-части книги, кроме VBA, сохранены
побайтно. Доказательства: `PlainCommentsUiCorrection_2026-10-16/`.

Направленные Off и On: в каждом входные единицы 1534/0, входной интерфейс
4235/0. Отдельная проверка двух списков с намеренно устаревшим кэшем — 2/0.
