# Толщина контура и название блока оформления

15.10.2026. Приёмка: `CONTOUR_LINE_WEIGHT_ACCEPTANCE_PASS`.

На Config блок переименован в **«Настройки оформления схемы»**. В его
таблицу добавлена строка **ContourLineWeight**, общий ключ
**Plot.ContourLineWeight**. Поле находится в объединённой ячейке I84:J84,
единицы — pt. По последнему указанию пользователя значение по умолчанию
**2 pt**; прежняя жёстко заданная толщина составляла 1,7 pt.

Одна настройка задаёт толщину наружных границ и границ отверстий:
прямых, дуг и окружностей. Применяется общий CSectionPlotter, читающий
сохранённую геометрию. Ветвей по происхождению сечения и изменений рецептов
нет. Созданные программой и импортированные из AutoCAD сечения проходят
через существующий общий механизм. Настройка относится к Excel-схеме.

## Реализация

* CSystemSettingsReader разворачивает общую строку в один ключ, без
  фиктивных Plot.RebarLabels.ContourLineWeight/Plot.Dimensions.ContourLineWeight.
  Сохраняется фактический адрес ячейки при ошибке значения.
* CSectionPlotter читает положительную толщину до очистки прежнего рисунка
  и передаёт её существующим функциям линий, окружностей и дуг. При
  Plot.ContourEnabled = No поле не читается. Толщина задаётся в экранных
  пунктах, не умножается на масштаб геометрии или VisualScale.
* SettingsCatalog создаёт такую же общую ячейку, default 2 и проверку
  положительного числа при сборке нового шаблона. Действующие таблицы
  готовой книги не перестраиваются; runtime-миграция не добавлена.
* Новая строка заняла свободное место после таблицы. Соседние блоки,
  имена и формулы не сдвигались. В Справке изменены названия этого блока
  и его подразделов, добавлены два коротких пояснения новой настройки.
  «Подробнее» ведёт к своему описанию; заголовок описания — обратно к полю.

Изменение значения применяется при следующем штатном обновлении схемы.
Сохранённый рисунок намеренно не перестраивался при добавлении настройки.

отрицательное число и ошибка Excel отклоняются с фактическим адресом;
прежний рисунок сохраняется. Отключённый контур не читает ошибочное поле.
Отсутствующая строка не подменяется default. Проверен один общий ключ.
Счётчик решения равновесия не увеличился. Полные ON/OFF и расчёт НДС
не запускались: изменение касается оформления.

Отдельный нативный Excel подтвердил значение, объединение и выравнивание
ячейки, положительную validation, все четыре стороны рамки, обе ссылки
Справки и создание идентичного поля штатным сборщиком.

Промежуточный тестовый снимок сначала имел неверную общую нумерацию
