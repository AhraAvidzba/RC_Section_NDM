# Смещение дополнительных рядов и скорость экспорта — 19.10.2026

Изменения приняты направленными проверками. Сохранённое сечение PointedRect
допускает смещение дополнительного ряда Right на 40 мм; при большем смещении
позиции вне смещённого контура пропускаются с предупреждением. Расчётные
формулы, нормативные параметры и допуски решателя не менялись.

## Общая геометрия

`CSectionGeometryQuery.OffsetPath` разрешает исчезновение угловой дуги
между двумя касательными прямыми. Прямые соединяются в новой точке;
готовый замкнутый контур проверяется на пересечения и неправильное
направление участков. Полное исчезновение окружности или непригодность
всего контура по-прежнему являются ошибками ввода.

`CGeometryPath` сохраняет связь выбранной стороны с исходным замкнутым
контуром при выделении участка, развороте и преобразовании координат.
`CRebarRuleExecutor` проверяет положение дополнительного стержня после
смещения по нормали относительно полного смещённого контура. Позиции вне
него пропускаются; оставшиеся стержни не перераспределяются. Для цепочки
связанных рядов учитывается накопленное нормальное смещение. Тангенциальное
смещение контактного стержня применяется после этой проверки.

Предупреждение содержит число пропущенных стержней. Диагностика сохраняет
правило, позицию и фактические адреса исходных полей в
`Geometry.RecipeDiagnostics` на Results. Итоговое сообщение показывает
предупреждение и при выключенных некритических сообщениях.

Решение находится в общих классах; условий в рецептах не добавлено.
Связь с полным контуром действует для сторон, полученных из замкнутого
контура. Для независимо заданной LinePath такой контур не угадывается.
Проверки реального пересечения стержней и выхода их сечений из бетона
сохраняются; пропуск позиции не отменяет остальные проверки геометрии.

## CAD-экспорт

В `modAutoCADStressExport` те же четыре угловые точки элемента передаются
одной замкнутой Add3DPoly в мировых координатах, затем создаётся Region.
Порядок вершин сохраняет прежнее направление локальных осей после импорта.
Временный контур удаляется существующим механизмом очистки собственных
объектов. Четыре отдельных временных отрезка больше не создаются.

Измерялся нативный экспорт сохранённого Results через тестовый вход в тот
же рабочий код, включая чтение и создание объектов. Подключение к приложению
и итоговое сообщение в эти времена не входят. Геометрия после обратного
импорта сохранённого сечения совпала побитно. При наклонной ПСК совпали
мировые границы и нормали всех Region; границы первого элемента отдельно
проверены по ожидаемым WCS-координатам.

Пользовательская задержка 22 с не воспроизведена. Код работает с целевым
документом и не обходит остальные чертежи, но полностью изолировать экспорт
от состояния процесса AutoCAD невозможно. Перезапуск, после которого
пользователь получил 3 с, согласуется с описанным Autodesk замедлением
долгих сеансов; точная причина его сеанса не установлена. Настройки
пользовательского CAD не менялись, пользовательские чертежи не закрывались.

## Проверка влияния округления AutoCAD на расчёт

На повёрнутых прямоугольных элементах разные способы создания Region
выдают небольшие различия геометрических интегралов. Проверено сечение
600×300 мм с 48 повёрнутыми прямоугольными элементами 75×50 мм и 8 стержнями
Ø20. Выполнены настоящий экспорт и импорт обоими способами, затем один
и тот же расчётный код решил шесть сочетаний в обоих режимах расширения
диаграмм: 24 расчёта, 12 пар для сравнения.

| N, Н | Mx, Н·мм | My, Н·мм |
|---:|---:|---:|
| −500000 | 0 | 0 |
| 0 | 50000000 | 0 |
| −500000 | 50000000 | −20000000 |
| 200000 | 20000000 | 10000000 |
| −5000000 | 500000000 | 200000000 |
| −200000 | −30000000 | 40000000 |

В каждом режиме сравнены 929 полей. Все 279 полей статусов, применимости
и прочих текстовых признаков совпали точно. Максимальные различия:

- координаты — 5,69·10⁻¹⁴ мм; размеры — 2,62·10⁻¹² мм;
- площадь — 4,55·10⁻¹³ мм²; локальный момент инерции — 1,45·10⁻⁷ мм⁴
  при величине порядка 10⁶ мм⁴;
- предельный коэффициент нагрузки — 2,85·10⁻⁹;
- внутреннее N — 0,0143 Н; момент — 2,19 Н·мм, то есть 0,00219 Н·м;
- деформация — 2,24·10⁻¹¹; напряжение — 8,22·10⁻⁹ МПа;
- ширина трещины — 5,56·10⁻¹⁷ мм.

Это погрешности вычислений, несущественные для инженерного результата
на проверенной матрице. При перегрузке в пятом случае без расширения
диаграмм численный отказ сохранился в обоих вариантах; новых отказов нет.
Проверка не является доказательством всех возможных сечений и сочетаний.

Допуски введены только в сравнитель CAD-теста: относительный 10⁻⁷,
абсолютный нижний порог 10⁻¹². Нулевые компоненты усилий оцениваются по
масштабу всего вектора нагрузки и размеру сечения. Погрешность локальных
моментов инерции ограничена масштабом машинного округления и 10⁻¹⁰
характерного локального момента. Статусы сравниваются точно. Данные,
расчётные допуски, ключи кэша и нормативные коэффициенты не округлялись
и не ослаблялись.

Первоначальный побитный тест повёрнутой сетки выявил эти различия и не
засчитан успешным. В первой версии сквозного сравнителя исправлена обработка
пустых строк и оценка невязки около нуля; окончательный KernelMath_Final
запущен заново и завершён с кодом 0. Промежуточные ошибки WCS-сценария
вызваны чтением свойств Region вне плоскости активной ПСК; окончательная
проверка использует мировые границы и нормали.
