# Ссылки на методические источники

По указанию пользователя удалены семь гиперссылок на недоступный библиотечный каталог Горского. Сохранены названия источника, библиографическое описание, формулы и страницы. Эти подписи оформлены обычным чёрным текстом Arial 9 без подчёркивания. Семь ссылок на PDF ACI, включая ссылки на конкретные страницы, сохранены без изменений.

В общем каталоге у Горского отсутствует публичный URL. Сборщик поддерживает такое описание источника: выводит библиографический текст и добавляет «открыть документ» только при наличии публичной ссылки. Локальные адреса PDF не используются. `Update-HelpSourceLinks.py` применяет этот же каталог к существующей закрытой XLSM без пересериализации VBA и расчётных таблиц.

Основная рабочая книга и чистый артефакт обновлены точечно. Нативный Excel открыл обе копии: у всех семи подписей нет формулы и гиперссылки, оформление проверено; все семь формул ACI сохранены. В отдельном листе проверена генерация обычной ссылки на литературу и действующей интернет-ссылки через общий сборщик. Просмотрен фактический PDF-вывод пары подписей ACI/Горский.

В пакете книги изменены только семь ячеек справки, добавлены их стили; из цепочки пересчёта удалены соответствующие формулы. Остальные ячейки справки и существующие стили совпали, все остальные части XLSM, включая VBA, Config, «Сечения», «Расчет», Results, размеры и параметры печати, побайтно сохранены. `VBA_All_Code.txt` остаётся актуальным, его код не менялся. Пользовательский Excel не закрывался.

Доказательства: `docs/regression/HelpSourceLinks_2026-11-18_Run01/Acceptance.json` и первичные отчёты рядом. Расчётные тесты и полная пересборка не запускались: изменение относится к справке. Изменения остаются локальными, без push по действующему указанию пользователя.
