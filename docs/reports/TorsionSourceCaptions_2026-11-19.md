# Названия источников без гиперссылок

По указанию пользователя удалены внешние гиперссылки на документы ACI 445.1R-12 и EN 1992-1-1:2004. В обеих книгах заменены 28 формул `HYPERLINK`: в методике, описаниях настроек и общем перечне литературы. Названия, пункты, формулы и страницы источников сохранены обычным чёрным текстом без подчёркивания; надпись «открыть документ» удалена.

Публичные URL удалены из `NormativeHelpSources.json`. Сборщик использует этот каталог и выводит библиографические подписи без внешних гиперссылок. Внутренние переходы из настроек к справке сохранены.

Рабочая книга и чистая книга обновлены действующим `Update-HelpSourceLinks.py`. Изменились только XML листа «Справка», каталог стилей и, при наличии, техническая цепочка пересчёта удалённых формул. VBA, данные, формулы остальных листов, изображения, размеры, объединения и внутренняя навигация сохранены. `VBA_All_Code.txt` актуален, расчётный код не изменён.

Повторное открытие обеих сохранённых книг в отдельном Excel — PASS. Для всех 28 подписей в каждой книге проверены точное название, отсутствие формулы и гиперссылки, чёрный цвет и отсутствие подчёркивания. Нативный PDF изменённого блока просмотрен. Полная сборка и расчётные прогоны для этой правки справки не запускались.
