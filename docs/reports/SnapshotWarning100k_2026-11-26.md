# Порог предупреждения о крупных таблицах

Единая константа `LARGE_SNAPSHOT_WARNING_ROWS = 100000` в
`modCalculationSnapshot` задаёт порог предложения File для состояний и границ
элементов, а также предупреждения о крупных обязательных таблицах. Сравнение
строгое: при 100000 строк предупреждения нет, при 100001 оно появляется.
Проверка физической вместимости листа и расчётные алгоритмы не изменены.

Обновлены граничные тесты и описание Results.SnapshotStorage в справке и
данных сборки. Нативная компиляция прошла; 68 утверждений проверили оба типа
сетки, Excel/File, граничные значения и ограничения листов. Решатель и полные
наборы не запускались. Установленная книга и экспорт сверены; изменены только
VBA и один абзац справки, остальные данные и оформление сохранены.
