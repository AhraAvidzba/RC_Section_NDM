остальной текст четырёх исходников совпадает побайтно с версией `c14406b9`.

Excel: все 153 исходных компонента соответствуют 158 компонентам проекта.
Сравнение фактического VBA до и после подтвердило только переименование
в четырёх рецептах и автоматическое изменение регистра имён редактором VBA.
Строковые литералы, комментарии, числа и пробелы совпали. ALL CODE получен
из фактической готовой книги, а не собран из исходников.

В архиве книги изменён только `xl/vbaProject.bin`; все остальные 110 частей
сохранены побайтно, включая данные, формулы, Config, Справку и оформление.
Пользовательский execution_report сохранён и в коммит не включён.
Расчётные тесты не запускались: изменение ограничено именем переменной.

## Уточнение комментариев к нумерации стержней

В восьми комментариях Publication четырёх рецептов явно описана нумерация
R1, R2, ...: после каждого основного стержня следуют связанные с ним стержни
дополнительных рядов. Координаты этим параметром не меняются. Порядок также
учитывается при совпадении центров с политикой KeepPublishedOwner: сохраняется
ранее добавленный стержень. Поэтому действие настройки не сводится только
к тексту имени. Исполняемый код сохранён, расчётные тесты не требовались.
Книга и ALL CODE обновлены и сверены; прочие 110 частей книги сохранены.
Доказательства: `DependentRowOffsets_2026-10-17/PublicationComments`.

## Добавка для арматуры периодического профиля

В пояснениях к добавке 2,5 мм используется согласованная формулировка
«выступы арматуры периодического профиля».
Обновлены комментарии общего построителя, подробный API, его генераторы
и два абзаца Справки. В учебном примере общие настройки дополнительных рядов
теперь также названы extraOptions. Полный API-каталог сверяет 303 члена;
его манифест обновлён из-за изменения комментариев общего построителя.

Исполняемый VBA и численные параметры не менялись. В книге изменились
только VBA-проект и две текстовые строки sharedStrings; все XML листов,
включая данные, формулы, стили, ссылки, объединения и высоты строк, сохранены.
Прочие 109 частей книги совпали побайтно. ALL CODE получен повторным
чтением готовой книги. Пользовательский execution_report сохранён.
Доказательства окончательной формулировки:
`DependentRowOffsets_2026-10-17/PeriodicRebarComments`.
