# Полные проверки ON/OFF после переноса подготовки контактных рядов

Статус: первый диагностический запуск остановлен; подготовлен чистый повтор.
Исходная версия — 7e70f745.

Пользователь отдельно разрешил полный повтор. Проверяется неизменная копия
готовой книги, опубликованной после переноса CRebarContactBuilder в
AddReinforcement. Общий режим General.DiagramExtension переключается
в No и Yes. Проверки с явно заданным собственным режимом сохраняют свою
постановку; после каждого набора несохранённые изменения копии отбрасываются.

План: по восемь основных наборов, 26 геометрических и шесть СП35 в каждом
режиме — всего 80. Дополнительно по 18 наборов последних изменений
рецептов и контактных рядов в каждом режиме — ещё 36. Приёмка требует
завершения всех 116 наборов, нулевых отказов, успешного завершения watchdog,
совпадения исходной книги с зафиксированной копией и сохранности ALL CODE
и пользовательского execution_report.

Основные наборы охватывают геометрию, материалы, НДС, поиск несущей
способности, трещины, расчётные сочетания, интерфейс книги и численный эталон.
Проверяются Config, входные таблицы, профили, Results, схемы, отчёты,
единицы, знаки, статусы и комментарии. Расчёт устойчивости и трещин включает
СП35/СП63; отдельный законченный набор проверяет шесть видов сочетаний
по обоим стандартам. Дополнительная геометрия включает контуры, отверстия,
сетки, правила армирования, аннотации и импортированные размеры.

Первая попытка не запустила тесты: текущая оболочка PowerShell 7 не содержит
ожидаемого сценарием powershell.exe. Она записана отдельно как STARTUP_ERROR.
Основной прогон запущен через Windows PowerShell 5.1 без изменения книги
или исполняемых сценариев. Эта ошибка запуска не считается результатом тестов.

четыре отказа — audit03.autoPlot.noState.mode0…3.validProfile. Тест создавал
основное сочетание NO_STATE и включал устойчивость, но не создавал строку
с таким номером в rngStabilityDurationLoads. Рабочий читатель правильно
возвращал InputErr по новому правилу обязательного сопоставления.
Остальные расчётные наборы, численный эталон, 26 геометрических наборов
и шесть СП35 завершились без отказов. Начатый ON остановлен; этот запуск
не считается принятой полной проверкой. Все журналы сохранены.

В TestAudit03AutoPlotContracts добавлена строка с номером основного сочетания
и нулевыми N/Mx/My в собственной тестовой копии. Проверки не изменены.
