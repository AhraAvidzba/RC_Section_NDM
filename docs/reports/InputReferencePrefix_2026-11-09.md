# Подтверждённая часть цепочки ссылок

Если прямая ссылка ведёт к ячейке с формулой, которая использует несколько адресов, сообщение показывает путь до этой ячейки включительно. Для прямых ссылок до ячейки ввода выводится полный путь. Обход выполняется при подготовке сообщения об ошибке.

Во всех трёх книгах проверены остановка на второй и третьей ячейках, формула в первой ячейке, полный прямой путь, цикл, битая формула в подтверждённой ячейке и сообщение ошибки настройки. Из нативного окна каждой книги прочитан текст со стрелкой U+27F6.

VBA скомпилирован из исходника сборки и побайтно совпадает во всех трёх книгах. Остальные части каждой книги побайтно совпали с её резервом. Сохранены формулы, данные, рисунки и оформление. Нативный экспорт подтвердил совпадение изменённого модуля с исходником и сохранение остальных 186 модулей.
