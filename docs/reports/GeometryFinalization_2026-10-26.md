Чистая книга FreshBuild07 и соответствующий AllCode **опубликованы в workbook/output**; прежние файлы сохранены отдельно. **Полного PASS нет: 178/CoverageVersion6 + весь Focused ещё не запускались. Цель 30 сочетаний быстрее 5 с в Excel и File не достигнута.** FinalCurrentBenchmark01 завершил шесть native-вызовов и два настоящих reopen; независимое полное численное сравнение всех шести результатов получило PASS_EXACT_PHYSICS_ONLY. **Результат изменений**

- Точная область бетона, площадь, центр и Ix/Iy/Ixy добавляются в CSectionModel атомарно, до публикации ID, ревизии и кэшей. Генерация, импорт и восстановление используют общий путь; Contour без границы запрещён. Компактные прямоугольники сохранены. Изменяемые границы защищены независимыми копиями; отверстия и отдельные части распределяются через ConnectedRegions. Принятая Adaptive-семантика, включая уровень 1, сохранена. [Архитектура](../regression/GeometryFinalization_2026-10-26_Run01/IntegrationReview.json), [CAD/арматура](../regression/GeometryFinalization_2026-10-26_Run01/CAD_RebarReview.json).
- Mesh.MinElementArea расположен в «Сетке геометрии» и применяется к каждой окончательной бетонной части и физическому стержню. Площадь переводится в мм²: строго меньше порога исключается, равенство остаётся, 0 отключает фильтр. Снимки повторно не фильтруются. Default новой сборки — Contour; ненужные параметры другого режима не читаются. Блоки геометрии/сетки/нагрузок/диаграмм разделены. [Настройки](../regression/GeometryFinalization_2026-10-26_Run01/FinalKeyRename.json).
- Excel хранит полную 18-колоночную геометрию элементов на листе; File — в проверенном .ndm, оставляя шапку без старого тела/рамок. Файл успешно сохраняется до очистки листовой копии. Явный Snapshot.Kind=GeometryPreview хранит настоящую геометрию без фиктивных НДС/LC/профилей. Повреждённый полный снимок не становится preview, потерянный файл не заменяет точные границы прямоугольниками. [Контракты](../regression/GeometryFinalization_2026-10-26_Run01/FileGeometryStorageDocumentationReview.json).
- Сформированное сечение экспортируется без solver и повторного импорта с обязательным предупреждением «только сечение, без рассчитанного состояния», включая NonCriticalMessages=No. ContourEnabled сохраняет выбор пользователя. Несформированная геометрия и испорченные расчётные Results дают адресные ошибки. [CAD gate](../regression/GeometryFinalization_2026-10-26_Run01/NativeCAD02/Acceptance.json).
- Справка, русские шапки, комментарии, API-guide и сборка синхронизированы. Для comment-only изменений сохранено равенство исполняемых токенов/AST; литерал TODO как ошибочный ввод не удалялся. Предложение File и невозможность вместить обязательные листовые данные проверены отдельно. [Ревизия](../regression/GeometryFinalization_2026-10-26_Run01/Review.json), [Excel](../regression/GeometryFinalization_2026-10-26_Run01/ExcelCommentsExecutableProof.json), [сборка](../regression/GeometryFinalization_2026-10-26_Run01/BuildCommentReview/Review.json), [guide](../regression/GeometryFinalization_2026-10-26_Run01/GuideGeneratorSync.json).

Формулы, порядок суммирования, единицы, допуски и статусы сохранены. ImportRotation не перенесён: достаточной полной native-пары нет. **Надёжность и оставшаяся работа**

Ложное absent Excel14300 явно отозвано: StartTime был недоступен в обычном контексте. Root отдельно подтвердил уже закрывший книгу/Quit остаток и убрал только его; Ready/VBA mode не выдавались за прочитанные. [Коррекция](../regression/GeometryFinalization_2026-10-26_Run01/NativeReleaseClosureCorrection01/Correction.json). Применены шесть PS-защит: Unknown не равен NotFound, worker фиксирует Close/Quit, watcher принимает только post-child exactAbsent. Дополнительно применена NativeMemoryGuard Revision02: фактические RAM/commit, пороги 4/8 ГиБ, ожидание до 300 с и общий logical deadline; CAD inventory/права владения перепроверяются после ожидания. VBA/книга этим не менялись. [Шесть PS](../regression/GeometryFinalization_2026-10-26_Run01/FullLaunchGuardHardening01/Applied01/ApplyReceipt.json), [Revision02](../regression/GeometryFinalization_2026-10-26_Run01/FocusedNativeMemoryGuard01/Revision02/Applied01/ApplyReceipt.json).

Полный **178 + весь Focused — NOT_STARTED**: 122 одиночных случая, batch15 No/Yes, устойчивость, асимметричная сталь, настоящий CAD, reopen и независимый контроль обязательны. Прежние 162/178 результаты не переносятся на новую SHA. Source-only проверка 175+6 после обычного сохранения завершена: буквальное равенство 181 компонента основной и тестовой книг подтверждено; различие сырого vbaProject.bin само по себе не означает изменение кода. Далее — root commit/freeze, авторизованный полный запуск, чтение всех первичных отчётов и официальный finalizer на той же книге. Затем — окончательный итог полного набора, обновление PROGRESS/Processed, commit/push с проверкой remote и согласованное слияние в main. Опубликованная чистая книга сама по себе этих стадий не заменяет.


Пакетный импорт AutoLISP отдельно по скорости не проверен. Возможное сокращение COM-чтений не отменяет общую геометрию, WCS, MinArea и запись результатов; результат экспортного прототипа на импорт не переносится. Рабочий COM-импорт сохранён.
