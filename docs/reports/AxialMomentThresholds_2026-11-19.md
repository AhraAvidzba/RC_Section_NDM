# Независимые пороги N и M — 19.11.2026

Перед `Calculation.ZeroMomentPerDepth` добавлена настройка
`Calculation.ZeroAxialForcePerDepth`. Начальные значения ядра и сборки:
1 tf/m для N и 1 tf*m/m для M; при INPUT tf, tf*m, mm обе ячейки равны 0.001.
Подписи единиц вычисляются формулами через `rngUnitSettings`.

Общий класс `CLoadZeroFilter` принимает независимые коэффициенты.
Исходная N обнуляется при `abs(N) <= qN*min(hx,hy)`, только если одновременно
`abs(N*OffsetY) <= qM*hy` и `abs(N*OffsetX) <= qM*hx`. Смещения относятся
к бетонному центру; координаты чертежа в условие не входят. Сохраняемая малая
эксцентричная сила участвует в точном переносе. Значение 0 независимо отключает
соответствующий фильтр. При qM=0 ненулевой эксцентриситет сохраняет ненулевую N.

N фильтруется только при подготовке исходного полного сочетания и постоянной
части, до переноса и построения траектории. Пробы lambda и Nult повторно не
фильтруются. Исходные нагрузки сохраняются. Физические моменты после
устойчивости продолжают обрабатываться существующим порогом моментов;
смена начала координат не обнуляет служебные моменты переноса.

Настройка читается и диагностируется общим `CSystemSettingsReader`.
Проверены отрицательное, текстовое и пустое значения с фактическим местом
ввода. Порог, переполняющий Double при умножении на габарит, отклоняется до
загрузки сочетаний с адресом соответствующего параметра.

Синхронизированы каталог, справка, формулы единиц, раскладка и автономный
шаблон оформления. На Config перемещены только A:E от строки фильтра моментов;
другие таблицы, размеры столбцов и строки входных листов сохранены.
Справка перестроена из источников с разделом руководства по рецептам.
Ссылки «Подробнее» проверены в сохранённой и повторно открытой чистой книге.
