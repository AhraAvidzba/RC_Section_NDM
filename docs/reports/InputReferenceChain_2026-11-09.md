# Цепочка ссылок в сообщениях об ошибке ввода

Для прямых ссылок на одну ячейку внутри книги сообщение показывает весь путь от проверяемой ячейки до поля ввода. Проверенный пример из нативного диалога Excel выглядит так.

```text
Config!J19 ⟶ Расчет!AA41 ⟶ 'Ввод О''Б'!A1
```

Обход выполняется при подготовке сообщения об ошибке и ограничен 32 ячейками. При неоднозначной формуле, цикле, битой ссылке или превышении предела выводится адрес проверяемой ячейки.

Штатный сборщик скомпилировал проект. В итоговую книгу перенесён этот VBA-проект с побайтным сохранением остальных частей файла. Нативный экспорт совпал с изменённым исходником. Остальные 186 компонентов совпали с предыдущим экспортом.

Пройдены восемь сценариев, включая реальную ошибку формирования сечения, и 49 проверок оформления сообщений. Из текста окна Windows прочитан исходный символ U+27F6. Книга и экспорт VBA сохранены с резервом.

Windows записала три сбоя в combase.dll при закрытии экземпляров с добавленным тестовым модулем. На том же файле полный адресный тест и два независимых чтения окна без изменения проекта VBA завершились штатно. Все тестовые экземпляры закрыты.
