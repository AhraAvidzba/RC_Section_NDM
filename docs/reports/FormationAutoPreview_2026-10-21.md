# Автоматическая схема после формирования сечения

После сохранения геометрии FormSectionForWorkbook вызывает существующую
UpdateSectionGeometryPreviewForWorkbook. Схема строится по Results без
генерации, повторного импорта и решения НДС.

Plot.Enabled = No отключает отрисовку. Plot.AutoUpdateAfterCalculation
применяется только после расчёта и не блокирует предварительную схему.
При ошибке оформления формирование остаётся успешным: снимок сохраняется,
пользователь получает предупреждение с причиной и действием «Обновить схему».

Проверены в отдельном Excel:

- 11/0: автоматическая схема и аннотации; нулевое число вызовов НДС;
  Plot.Enabled = No; автообновление после расчёта отключено; неверное
  оформление вызывает предупреждение и сохраняет пригодную модель.
- 90/0: формирование, автоматическая схема, расчёт только по снимку,
  повторный расчёт, смена OUTPUT и отказ формирования.
- Фактический VBA совпадает с исходниками; книга и ALL CODE обновлены.

В XLSM меняются только VBA и один абзац Справки. Все остальные части,
включая данные и формулы Config, листа «Сечения» и Results, оформление,
размеры строк и столбцов, сохранены побайтно. Та же логика добавлена в
сборщик, чтобы пояснение сохранялось при сборке с нуля. Полные прогоны
после этой небольшой правки не запускались.
