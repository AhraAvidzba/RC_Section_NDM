# Источник снимка File/Excel, таблицы и сообщения — 27.10.2026

Все пользовательские действия выбирают снимок по текущему Results.SnapshotStorage. Excel читает только Results текущей книги. File сразу читает файл текущего Results.SnapshotName рядом с книгой; предварительное «Обновить схему и результаты» и прежняя служебная привязка не требуются. Нет скрытой подмены отсутствующего/повреждённого файла данными листа или ранее показанного файла.

«Выполнить расчёт» использует сохранённую геометрию из этого источника и текущие нагрузки, материалы и расчётные настройки Config. В File после завершения выбранный снимок целиком заменяется новым расчётом. «Сформировать сечение» получает новую геометрию из Config/«Сечения» либо AutoCAD и в File сохраняет GeometryPreview без прежнего НДС. Чтение старых .ndms сохранено, новые записи остаются .ndm.

File един для геометрии, ID, единиц, контуров, фактических границ, аннотаций, сохранённых состояний, сводок и выполненных проверок. Определяющее сочетание Worst относится к файлу. Выбор LC/состояния/величины, точности и оформления остаётся на Config. Изменённые или удалённые значения Results не подмешиваются. Полный снимок загружается в память на время действия и освобождается после него; постоянного межоперационного кэша нет.

Нижние таблицы Results переставлены слева направо:

1. Сетка бетона и арматуры — A156.
2. Характеристики сечения — S156.
3. Диаграммы материалов — AA156.
4. Достоверные контуры — AN156.
5. Результаты элементов по сочетаниям — BG156.
6. Фактические границы бетонных элементов — BR156.
7. Аннотации — CL156.

В File обновляются верхние результаты и данные первых четырёх нижних таблиц. Последние три сохраняют только шапки без прежних подробных строк. Excel выводит все семь. Сборщик, WorkbookLayout.json, Справка и AGENTS синхронизированы.

После итога действия добавляется его источник: геометрия для расчёта; геометрия и НДС для экспорта; данные схемы и таблиц для обновления. Экспорт без расчёта называет только геометрию. Формирование сообщает место сохранения. Последняя строка расчётного сообщения повторяет «Данные сохранены в файле „имя.ndm“» либо «Данные сохранены на листе Results текущей книги». Эти строки появляются после успешного сохранения, а не до него.

Отсутствующий файл даёт имя, ожидаемый путь и фактический адрес Results.SnapshotName. Подсказка предлагает проверить имя/папку либо нажать «Сформировать сечение», если снимка ещё нет. SaveAs не сверяет и не копирует старую привязку другого выбранного имени.

## Проверка и сохранность

Чистая FreshBuild11 собрана из источников и скомпилирована реальной командой VBE 578. Шесть адресных Snapshot/Workflow No/Yes дали 1898/0, включая сохранение и повторное открытие значений и статусов. Проверены Adaptive/Contour, прямой расчёт из GeometryPreview и полного файла, отсутствие предварительной загрузки, удаление всего содержимого Results, строгие сравнения девяти матриц повторного расчёта, контуры/границы, Worst, текущие переключатели просмотра, ошибочный файл и реальные сообщения расчёта/формирования. Тест экспорта читает тот же готовый набор для AutoCAD без запуска CAD; геометрический алгоритм экспорта не менялся.

Две подготовленные книги проверены нативно readonly без импорта, компиляции, расчёта или сохранения: 175 исходных + 6 document-компонентов, точные одинаковые native-тела Main/Ready, актуальный AllCode, адреса таблиц и читаемость изменённой Справки. Дополнительно проверены точные IEEE64-константы 12 изменённых компонентов; остальные 169 native-компонентов неизменны, кроме регистра идентификаторов VBE.

В каждом пакете изменены пять ZIP-частей: VBA, sharedStrings, целевые ячейки Справки, адреса четырёх имён и перестановка нижних Results. Остальные 102/107 частей Main и 106/111 частей Ready сохранены побайтно. Обратная перестановка нижних ячеек возвращает исходный Results XML буквально: числа, строки, стили, верхние результаты и данные книги с 1232 бетонными элементами, 8 стержнями и 30 сочетаниями не менялись. Все собственные процессы закрыты; чужие отчёты и outputs не включены.

Неуспешные промежуточные журналы сохранены. В ходе разработки исправлена потеря шапки состояний при сокращённом File-выводе; устаревшие тестовые предпосылки автоматического File→Excel и прежних адресов заменены проверками прямо заданного пользователем контракта. Математические алгоритмы, единицы и файловый кодек не менялись.
