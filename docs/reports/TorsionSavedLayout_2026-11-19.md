# Оформление и ссылки блока T/NMT

Сохранённое оформление листа «Расчет» включено в автономный шаблон сборки полностью: 4249 оформленных ячеек, 167 объединений, формулы, подписи, примечание о сложении напряжений, границы, ширины, высоты и объекты. Расположение ячеек сохранено. `WorkbookLayout.json` снят повторно с утверждённого файла.

Все пять листов сравнены с предыдущим сохранённым образцом. В Config добавлены 19 пользовательских привязок: `I109`, `I110`, `I111`, `I113` и `V71:V85`. Они вошли в шаблон; всего в нём 257 входных ячеек Config и 198 ячеек «Сечений». В «Сечениях» и «Справке» новых изменений содержимого не обнаружено. Изменения цветов статусов Results относятся к сохранённому результату расчёта и воспроизводятся штатными writers.

## Исправленные ссылки

Проверены все 41 формула оформленного блока `AR1:BD45` и вспомогательная формула `CF27`. Изменена 41 формула: 40 в блоке и одна во вспомогательной таблице; ссылка `AV12=CF27` проверена и сохранена.

| Группа | Исправление |
| --- | --- |
| Продольная арматура NMT | Определяющее сочетание берётся из `Results!Q12`; подробные значения ищутся по ID в самой подробной таблице T/NMT. |
| Хомут | Все поля используют своё определяющее сочетание `Results!R12` через `AU35`, включая напряжение, сопротивление, запас и статус. |
| Бетон | Все поля используют своё определяющее сочетание `Results!P12` через `AU42`. |
| Подробные значения | `MATCH` использует ID таблицы `A158:A187`, соответствующей диапазонам `INDEX`, вместо ID общей сводки `A13:A42`. Порядок строк и пропущенные строки T больше не смешиваются. |
| Отсутствующие результаты | Выводится прочерк, включая пустые числовые поля при InputErr. Фактический ноль остаётся числом ноль. |
| Исходные ID | 15 ссылок на исходные сочетания сохраняют пустые строки пустыми. |
| Вспомогательная таблица стали | `CF27` использует точное совпадение класса и группу фактического диаметра хомута из существующей таблицы, сохраняя выбор назначения моста. Неизвестный класс не подменяется ближайшим. |

Формула `CF27` продолжает брать сопротивления из существующей таблицы книги; значения нормативной таблицы не менялись. Решатель НДМ и физические формулы постпроверки T не изменены.

## Диагностика

После успешного чтения ID и числового T обработчик перестаёт считать ячейку момента источником последующих ошибок. Ошибка настройки сохраняет её ключ, ошибочное значение и цепочку фактических адресов, сформированные `CSystemSettingsReader` и общим слоем сообщений. К этой готовой причине добавляется только контекст сочетания. Адрес корректного T и его значение повторно не приписываются.

Ошибки самого ID или T по-прежнему указывают на соответствующую ячейку строки. Нулевой T не читает неприменимые настройки. Добавлена регрессия `RunTorsionPostDiagnosticTests`, включая две строки с общей ошибкой подготовки и значение `29+`.

## Шапка Results

В шаблон добавлен отдельный слой только для постоянного заголовка `AL8:AN9`: текст с одним переносом перед «(если применимо)», стили шести ячеек и объединение. Данные расчёта и метаданные запуска в этот слой не включаются. `CBatchResultWriter` уже выдаёт тот же текст и включает перенос в верхних шапках при штатном оформлении.

- Рабочая копия и чистая сборка повторно открыты в Excel. Проверены все формулы блока, цепочки Config, перенос AL8 и область печати. На синтетических данных заданы три разных определяющих ID и другой порядок подробных строк; проверены выбор значений, InputErr, отсутствие результатов, пустые ID и точный поиск класса стали.
- 7 направленных наборов T — 488 успешных проверок, 0 отказов: расчёт, применимость проверок, единицы, writers, длины и смысловые грани стержней, защита границ вывода и новая адресная диагностика.

- Все значения, формулы, стили и объединения всех пяти листов рабочей книги сохранены, кроме явно перечисленных 41 исправления формул. Проверки данных сохранены с точными формулами и разделителями.

- Пользовательские значения и формулы отсутствуют в слоях оформления входных листов. В справке не восстановлены внешние гиперссылки документов. `VBA_All_Code.txt` экспортирован из итогового проекта.
