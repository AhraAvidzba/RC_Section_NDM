# Цвета полей ввода Config — 18.10.2026

По фактическому коду `CSectionRecipeHollowRectangle.ReadRebarInputs` поле `n`
читается только у четырёх наружных сторон. Стержни у отверстия создаются
проекцией наружной арматуры; введённое для них количество не используется.

## Изменения

- Только в `rngRebarInput` добавлены три правила условного форматирования.
  Четыре количества `n` у отверстия HollowRectangle и поля строк без
  соответствующего участка контура выделяются серым RGB(230,230,230).
- Правила используют ключи, которые уже вычисляются обычными формулами.
  Цвет меняется при выборе типа и формы RectSet без запуска VBA.
  Значения сохраняются; защита от редактирования не добавляется.
- Остальные поля ввода сохраняют бледную оранжевую заливку RGB(255,242,230),
  включая настройки дополнительных рядов с пока пустым диаметром.
  Внутренние `as` остаются оранжевыми: они ограничивают линии у отверстия
  даже при выключенной арматуре на соседней стороне.
- По уточнению пользователя оранжевая заливка добавлена во все 30 ячеек
  `Comment` таблицы сочетаний нагрузок, включая пустые. Заливка обозначает
  возможность ввода, а не обязательность заполнения. Выравнивание слева сохранено.
- Справка и сборщик книги обновлены. При новой сборке применяются те же
  правила; в рабочий VBA никакой обработчик или миграция не добавлены.
