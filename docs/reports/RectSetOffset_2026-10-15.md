# Положительная величина размера Δ в RectSet

В `CSectionRecipeRectSet` концы горизонтального размера смещения задаются
слева направо: `min(0, Offset)` → `max(0, Offset)`. Общий метод получает
разность `Abs(Offset)`, а выноски остаются у действительных граней.
Значение Offset, контуры, армирование и расчётные алгоритмы не менялись.
Контракт общего HorizontalDistance с возможностью знакового значения сохранён.

Нативный Excel подтвердил три случая:

| Смещение, мм | До | После |
| ---: | ---: | ---: |
| −50 | Δ = −50 | Δ = 50 |
| 0 | Размер отсутствует | Размер отсутствует |
| +50 | Δ = 50 | Δ = 50 |

Прошли 15 адресных проверок на каждой версии. Сравнены 5913 строк снимка
каждой версии: входы, контуры, сетка, арматура, геометрические характеристики
и прочие аннотации совпали побитно. Изменилась только запись Δ для −50 мм:
порядок концов и знак значения. Решение НДС не запускалось.
