# Поэлементные усилия кручения на Results при хранении File

Таблица `rngTorsionBarForces` выводится полностью при Excel и File: по одной
строке на участвующий продольный стержень для каждого сочетания с T. Колонки:
ID сочетания, Rebar, смысловая грань, усилие от T и распределённая длина.
Полные состояния элементов НДМ в режиме File по-прежнему остаются в `.ndm`.

После расчёта и при нажатии «Обновить схему и результаты» используется один
метод `CTorsionSummaryWriter.RestoreSummary`, без флага подавления строк
стержней. Ручное обновление читает выбранный файл, восстанавливает таблицу
и очищает лишние строки предыдущего вывода без решения НДМ. Вместимость
проверяется до очистки результатов; если таблица стержней не помещается,
сообщение содержит её имя, число строк и предел листа. File не предлагается
как решение нехватки места для таблицы, обязательной на обоих носителях.

Обновлены существующие исходники VBA и описание Results.SnapshotStorage в
данных сборки. Компиляция проверила 209 компонентов; нативный экспорт
совпадает с исходниками. Изменены четыре существующих компонента, включая
два тестовых. При установке сохранены все части книги, кроме VBA и одного
абзаца справки в sharedStrings.xml. Новое пояснение короче прежнего; размеры,
формулы, списки, пользовательские данные и оформление не изменены.

Приёмка: 10 связанных исполнений, 1156 утверждений, отказов нет. Проверены
две комбинации в таблице длин, все пять колонок, единицы, совместимость
трёх- и четырёхколоночных снимков, запись после расчёта, восстановление
повреждённого справочного вывода из File, удаление хвоста, диагностика
переполнения до очистки и сохранение пустой подробной таблицы НДМ в File.
Табличные наборы выполнены в No/Yes; существующая интеграционная проба
Excel/File явно задаёт Yes независимо от внешнего режима, что сохранено
в первичных журналах и явно отмечено в Acceptance.json. Полные наборы не
запускались; математические алгоритмы расчёта не менялись.

Первичная остановка анализатора журнала была ложной: шаблон RUNTIME совпал
с успешной строкой `PASS Runtime preserves width`. Исправлена только привязка
шаблона к началу строки ошибки. Успешный журнал сохранён и принят без
повторного запуска; численные проверки и ожидания не ослаблялись.
