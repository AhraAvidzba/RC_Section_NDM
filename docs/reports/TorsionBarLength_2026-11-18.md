# Длина участка оси хомута в поэлементных результатах

Последний столбец rngTorsionBarForces — `l_i` в единицах OUTPUT Length. Значение соответствует доле периметра оси наружного хомута, назначенной физическому стержню: `F_T,i = q l_i cot θ`. Для общей станции или нескольких равных проекций выводится суммарная доля данного стержня. Состав участвующих стержней и расчёт усилий/напряжений не изменены.

Длины подготавливаются один раз вместе с геометрией. Writer переводит их через CUnitSystem, сохраняет без округления в четырёхколоночной матрице снимка и выводит с тремя десятичными знаками. Чтение трёхколоночных матриц поддерживается: длина восстанавливается из сохранённых F_T, q и cot θ без повторного решения или чтения геометрии. В режиме File на листе остаётся только шапка согласно общему контракту.

Сборщик, ширина добавленного столбца в WorkbookLayout.json, верхняя полоса и справка синхронизированы. Runtime не меняет ширины столбцов. Якорь остаётся одной ячейкой, данные выводятся без рамок; сохранённые три колонки и остальные результаты не изменены. Основная книга обновляется с сохранением ввода и оформления «Расчет», включая печать. Тестовая книга пользователя не обновляется.

## Направленная проверка

1007 проверок: проекции 257, математика 48, независимость доступности 105, единицы 57, вывод 107, защитные условия 16, угловые длины 325, добавленный столбец и его сохранение 92. Последний набор проверяет OUTPUT mm/m, угол 30°, восстановление трёхколоночной матрицы, точный двоичный roundtrip v6, вывод сохранённого файла, скрытие деталей в File и очистку длины. Файловая проверка использует направленную заготовку контейнера с шапкой элементов, не полный расчёт НДМ.

Первые попытки выявили неполную тестовую заготовку файлового контейнера, затем восстановление пустого значения через COM в проверочном скрипте. Исправлены тестовые данные и сценарий проверки; ожидания не ослаблены. Итоговый направленный набор прошёл полностью. В обеих сохранённых и повторно открытых книгах сверены все 192 исходных компонента. Общий полный ON/OFF-набор и полная пересборка для этой локальной правки не запускались. Изменения остаются локальными.
