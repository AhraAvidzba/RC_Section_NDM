# Уточнение текстового отчета расчета

Отчет разделяет поиск несущей способности, текущее НДС по прочности, образование трещины, текущее НДС для трещин, продольные трещины и ширину раскрытия. Общая статистика пакета, кручение и запись результатов имеют самостоятельные разделы. Таблицы Excel не перемещаются.

Каждый расчетный вектор усилий сопровождается точкой отсчета моментов. Координаты подписаны как координаты внутренней расчетной системы элементов. Отдельно показаны исходный ввод, нагрузки после фильтрации, рабочий вектор относительно O и найденные предельные усилия. Для сочетания 16 сохраненного примера исходные N/Mx/My равны −50/40/30 tf, tf*m, tf*m; рабочие моменты относительно O равны 14.605263157895 и 12.105263157895 tf*m вследствие переноса точки.

Диагностика поиска содержит внутренние единицы и знаки. Номер пробы отделен от множителя нагрузки. Статусы StrengthState и CrackedState различаются; название CrackedState само по себе не означает образования трещины. Нерассчитанные параметры ширины и Ncr/D табличной ветви СП 35 не выводятся как численные нули. Для сжатого стержня без ограничения по растяжению запас суммы NM+T подписан соответствующим образом.

Сообщение о фильтрации поясняет, что исключены только первоначально заданные ненулевые N/Mx/My, полностью обнуленные фильтром при отсутствии T. Пустые и первоначально нулевые строки не учитываются. Сочетание с T сохраняется; при нулевом НДМ профиль PR не нужен. Проверка подтвердила существующую корректность этого отбора: изменены подписи и проверки, а не правила фильтрации.
