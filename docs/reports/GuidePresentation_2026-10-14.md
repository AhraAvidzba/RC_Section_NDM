# Справка: удаление служебной строки и уменьшение высоты строк

Из раздела «Добавление нового типа сечения» удалена техническая строка с
версией и контрольными суммами. Она применялась скриптами обновления для
проверки прежнего текста. Теперь проверка выполняется по внешнему описанию;
в книгу, её скрытые данные и VBA контрольные метки не записываются.
Для изменения текста предусмотрен параметр PreviousLayoutPath. Ручные
правки, не совпадающие с выбранным прежним описанием, блокируют замену.

Причина избыточной высоты — грубая оценка количества символов в строке и
сохранение максимума прежней и новой высоты. Общий установщик и направленный
обновитель теперь измеряют текст с фактическим шрифтом по ширине ячейки.
Два абзаца, отмеченные пользователем, уменьшены с 57 до 30,95 пункта;
пустые разделители — с 21 до 9. Текст, шрифты, рамки и свёрнутые группы сохранены.
Изображение Candidate.png получено непосредственно из Excel после сохранения.

Первая проверочная копия отклонена: присвоение высоты в Excel одновременно
раскрыло скрытые строки. Исправленный обновитель восстанавливает их состояние.
Основная книга заменяется только прошедшей приёмку копией.

Проверки:

- Независимое сравнение XML: 107461 ячейка, 27 имён, рисунки, формулы,
  сохранённые значения и оформление. Единственное изменение содержимого —
  очистка A612 в Справке; высоты изменены только в её блоке A552:F612.
- Во всех XML-частях книги, включая скрытые ячейки, имена и свойства,
  а также в полном реальном экспорте VBA нет контрольных меток и строк SHA256.
- Все 157 VBA-компонентов идентичны исходной книге; 152 компонента совпадают
  с исходниками. Модуль API содержит прежние 137 методов в девяти разделах.
- Пять проверок внешней защиты: новая и прежняя справка принимаются,
  ручная правка блокирует замену, старая метка не позволяет обойти защиту.
- Общий установщик проверен на отдельной книге: обновление без метки,
  повторный вызов и отказ от перезаписи ручной правки.
- Повторное чтение основной книги завершено: её XML и реальный VBA прошли
  те же проверки. ALL CODE побайтно равен этому экспорту.
  Пользовательский execution_report не изменён и не включён в коммит.

Расчётные макросы, полные ON/OFF и полные UI-прогоны не запускались:
изменения касаются Справки и инструментов её оформления.
