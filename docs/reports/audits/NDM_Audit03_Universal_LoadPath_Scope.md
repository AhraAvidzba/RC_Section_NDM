## Контракт

- Единственная пользовательская настройка пути находится в строке сочетания:
  `LoadPath`. Она применяется к Capacity и CrackFormation.
- Допустимы `Auto`, `λ*Mx`, `λ*My`, `λ*Mxy`, `λ*N`, `λ*NMxy`.
  Значение новой строки по умолчанию `Auto`; пустая строка, включая результат
  формулы `""`, равнозначна `Auto`, а не ошибке ввода. Неизвестное значение и
  ошибка формулы остаются InputErr с указанием строки/ячейки.
- `SLS.Crack.InitiationLoadPath` удаляется из действующих настроек,
  комментариев, validation, справки и runtime consumers.
- Mx/My являются только вариантами масштабирования нагрузок, а не отдельными
  постановками solver-а: равновесие всегда решается для N + Mx + My.
- Момент от эксцентриситета N остается связан с N при любом пути.

## Общий Auto

Выбор и перебор выполняет Search, независимо от инженерного критерия и
material spec. Классификация использует нормализованные компоненты нагрузки
в точке приложения после общего фильтра малых моментов.

1. Только N: сразу λ*N.
2. Только Mx: сразу λ*Mx; только My: сразу λ*My;
   два ненулевых момента без N: сразу λ*Mxy.
3. N + M: сначала путь момента (Mx, My либо Mxy по заданному вектору),
   затем λ*N, затем λ*NMxy, если предыдущий путь не дал принятую точку.
4. При явно выбранном пути скрытая смена траектории запрещена.

## Машинные Исходы

Успешно найденный предел с λ < 1 не является неудачей Search и не запускает
перебор другого пути только ради получения OK. Это честный физический FAIL.
Численная несходимость не превращается в физическое разрушение.

Непрохождение постоянной части при λ = 0 и доказанная недостижимость критерия
на выбранном пути сохраняют разные ResultCode и точные русские пояснения.
Для фиксированного пути внешний BaseFail допускается также в Formation,
согласно новому требованию пользователя. Само отсутствие достижения критерия
в начальной точке не доказывает недостижимость на всей траектории. Исчерпание
MaxLambda/численного лимита не подменяется доказанным физическим исходом.
Внешний статус назначает только CResultStatusPolicy по typed результату.

Последующее уточнение пользователя: отсутствие пригодной точки Formation
или состояния PostCrackState не блокирует Width/Longitudinal. Если текущее
НДС сочетания получено и физически допустимо, Width рассчитывается с psi_s = 1
в любом PsiMode с предупреждением в собственном ResultComment. Фактический
typed исход поиска сохраняется отдельно и участвует в общем статусе; он
не превращается в NumFail формулы. Продольные трещины от Formation не зависят.
Отказ обязательного текущего НДС блокирует обе проверки. Некорректные входные
данные не подменяются defaults.

## Границы Изменений

Объединить существующий механизм путей, не добавляя новых классов, новых
расчетных постановок или нормативных допущений. Численные strategies/options,
критерии Capacity/Formation и material spec сохраняют свои ответственности.
Все ResultComment формируют ответственные результаты, writers выводят готовые
комментарии своего subtree; summary содержит все относящиеся к нему причины.

## Приемка

- Каждый фиксированный путь отдельно для Capacity и CrackFormation.
- Auto для N, Mx, My, Mxy и N+M, порядок fallback и остановка на принятом пределе.
- Пустое значение, formula-empty, неизвестное значение, CVErr, восстановление.
- Offset/Base при λ = 0/1/2, эксцентриситет N, пользовательские единицы/знаки.
- Физические пределы, все равновесия, typed статусы и ResultComment во всех
  подробных блоках, batch summary и txt-отчете; save/reopen.
- Off/On расширения диаграмм, несколько сечений/профилей, все suites,
  пересборка и фактическая проверка Config/справки/validation.
