# Audit03: Динамические Адреса Ошибок Ввода

Дата: 2026-10-03. Проверенный направленный срез: v176.
Общая приемка Audit03 этим документом не объявляется.

## Контракт

Адрес ошибочного пользовательского значения определяется по фактическому
именованному диапазону при чтении входа конкретного запуска. Перенос таблицы
с корректным обновлением ссылки имени Excel меняет адрес в новом сообщении
и в новом ResultComment. В расчетном ядре нет Excel-адресов, writer выводит
готовый комментарий результата и не подставляет адрес из раскладки шаблона.

Старый сохраненный результат не меняется задним числом после переноса Config:
его комментарии относятся к исходным данным того запуска. Следующий расчет
снова читает именованные таблицы. При поврежденной ссылке имени требуется
восстановить ее в диспетчере имен; несуществующий адрес не выдумывается.

## Ответственные Места

| Владелец | Формирование Адреса |
| --- | --- |
| CSystemSettingsReader.AppendSettingsRange / InputCellLocation | Читает Worksheet.Name, Range.Row/Column текущей таблицы и относительную позицию поля. Буквы столбца вычисляются, строка шаблона не зашита. |
| CCalculationProfileCatalog.BuildProfile | Использует source.Worksheet.Name и source.Cells(row, profileColumn).Address(False, False) для конкретного ключа PR. |
| CLoadCombinationReader.CellLocation | Использует фактический source.Cells(row, column).Address; это место включается в готовую row-level причину до Batch. |
| Result owners / writers | Сохраняют и выводят причину своего subtree. Поиск или вычисление адреса на основе текста writer не выполняет. |

Поиск литеральных Config-адресов в src не выявил фиксированных адресов ошибок
ввода. `Range("AP1")` в CSectionPlotter задает начальную позицию графика,
а не место исправления настройки.

## Исправления

- 47 ранее безадресных geometry reads переведены на существующий
  AppendGeometryValue; значения и инженерная активность не изменены.
- Параметры подписей арматуры и размеров сохраняют координаты своего ввода.
- Profile selector/precision/formula errors включают технический PR, key
  и фактическую ячейку; машинные номера ошибок сохранены.
- Конфликт общих RectSet-параметров называет обе спорные ячейки. Ошибка
  формулы в служебной второй строке не проходит через необработанный CStr.
- В справку добавлен контракт нового запуска и исторического snapshot.
