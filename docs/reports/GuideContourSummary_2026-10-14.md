# Справка: способы создания контуров

Из порядка добавления сечения удалены требования к русской шапке назначения
и русским пояснениям каждого метода. В первом шаге осталось создание класса
с Implements ISectionRecipe. Язык и оформление комментариев пользователь
выбирает сам; ограничения интерфейса и геометрии описаны по фактическому API.

Вместо прежнего общего абзаца добавлены три короткие строки:

- Готовые контуры: RectanglePath, CirclePath, AdjacentRectangles.
- Многоугольник через CPolygonSpec.AddVertex / Seal / RoundedPolygon;
  последовательность отрезков и дуг через CGeometryPath.AddLine / AddArc,
  Seal True и AddPath.
- Назначение наружной границы через Outer или отверстия через Opening;
  подробные вызовы и примеры находятся в modSectionRecipeApiGuide этой книги.

Порядок вызовов сверен с CSectionDefinitionBuilder, CPolygonSpec и
CGeometryPath. Обзор занял существующие строки: в блоке осталось 61 строка.
Изменены тексты A558, A559, A560 и A571, высоты только первых трёх.
Изображение Candidate.png получено из сохранённой копии Excel и просмотрено:
текст виден полностью, высокие пустые строки не появились.

Независимая проверка XML охватывает 107461 ячейку и 27 имён; остальные
данные, формулы, сохранённые результаты, списки и оформление сохранены.
Все 157 реальных VBA-компонентов идентичны исходной книге, 152 компонента
совпадают с исходниками. В Справке и модуле API нет требований к языку
авторских комментариев, в книге нет служебных меток.

Основная книга заменена под проверкой исходных контрольных сумм. После
независимого чтения её VBA обновлён ALL CODE, побайтно равный экспорту.
Пользовательский
execution_report исключён из изменений. Расчётные тесты и пересборка не
нужны: рабочий код не менялся.
