# Диагностика геометрии без переноса текста

В общем форматтере `CNDMResultsWriter.FormatResultsBlock` добавлено явное
`WrapText=False` для строк данных после записи значений. Это применяется
как после расчёта, так и при выводе геометрии без НДС. Заголовки сохраняют
своё оформление. Полный текст Geometry.RecipeDiagnostics не сокращается.

В готовой книге отключён перенос сохранённой ячейки Results!AY164.
Значения, формулы, имена, остальные исходные стили и высоты строк сохранены.
В XLSM изменены VBA, ссылка этой ячейки на стиль и добавлен стиль без
переноса; декларации пространств имён XML сохранены.

Проверено в отдельном Excel: при открытии и после повторного штатного
вывода WrapText=False, высота строки 15. Прежний текст из 1675 символов
сохранён полностью. Направленный набор сохранения аннотаций пройден:
24 проверки, ошибок нет, включая единицы mm/cm/m. Решение НДС не запускалось.

Все 161 компонента нативного VBA сверены с предыдущей принятой книгой:
изменился только CNDMResultsWriter и только одна исполняемая строка.
Различия регистра идентификаторов, внесённые VBE, проверены штатным
каноническим сравнителем. Незавершённые правки ожиданий будущего полного
прогона в эту книгу и коммит не включены.

Рабочая книга и ALL CODE обновлены. Данные пользователя и его
execution_report сохранены. Полные прогоны не запускались и остаются
отложенными по указанию пользователя.
