# Таблицы геометрии Config и общий ридер — приёмка 18.10.2026

Четыре штатные таблицы заменены согласованными блочными таблицами. По последнему
указанию пользователя рабочая книга собрана с нуля, со значениями по умолчанию.
Старые пользовательские настройки в новый файл не переносились. Предыдущая книга
сохранена отдельно; пользовательский execution_report не изменён и не коммитится.

## Реализация

- Один именованный диапазон на форму; блоки Geom, необязательный Detail, Main и Extra.
- Над диапазоном — название сечения и синяя ссылка «Подробнее» на свой раздел.
- Весь диапазон, включая пустые ячейки и разделители, обведён тонким пунктиром.
- Поля ввода белые, центрированы; комментарии справа в последнем столбце своего
  блока, без переноса текста. Высота строк стандартная. Условного форматирования нет.
- I–U Config имеют ширину 17. Её назначает только общий сборщик; повторное
  назначение ширин из Build-Workbook удалено. Расчёт ширину не меняет.
- Размерные единицы задаются формулами через INPUT Length в rngUnitSettings.
  Количество остаётся в штуках, безразмерные поля отмечены прочерком.
- a2/a3 подписаны «Смещение 2/3»; у граней отверстия вместо ручного количества
  стоят прочерки. Каждый выпадающий список имеет независимый именованный источник.

CSectionInputReader разбирает неизменяемый снимок CSectionInputTable: диапазон →
блок → строка → столбец. Русские подписи не участвуют в поиске; порядок блоков,
строк и столбцов можно менять. Числовые проверки остаются в CSectionInputTable,
перевод единиц — в CUnitSystem, ограничения формы — в рецепте. Excel-объектов
в ридере нет. ValueAt(row, column) читает исходное значение по позиции с 1,
в том числе из произвольной таблицы без ключей; единицы при этом не преобразует.

Все четыре рецепта используют context.Reader. Их геометрия, правила армирования
и аннотаций сохранены. Удалены старый AdditionalRowsHeader и четыре отдельных
сборщика геометрических таблиц; общая схема находится в GeometryTables.json.
Рабочий VBA не содержит мигратора таблиц. Для распространения достаточно книги:
она не читает каталог сборщика или другие внешние файлы во время работы.

Справка и modSectionRecipeApiGuide описывают рекомендуемую структуру, прямое чтение
по позиции и возможность своей структуры таблицы с тем же декларативным API.
Каталог 321 члена API и его реальные примеры синхронизированы; модуль справочника
автора сечения сохраняет ограниченный авторский состав.

количества у отверстия; 294 поля ввода; 87 независимых списков; 1300 необъединённых
ячеек с полной рамкой и заголовки объединённых блоков. Все 51 формула единиц
сохраняется после открытия и меняет значение при INPUT Length = mm, cm, m.

конфигурация форм, определения и сумма аннотаций: 101/284/216/15/92, отказов нет.

Полные ON/OFF, часовой план и UI-марафон в этом этапе не выполнялись. Расчётные
сравнения направленные, с General.DiagramExtension = No; это не общий ON/OFF PASS.

## Исправления при проверке

Первый пакет рецептов выявил старые координаты полей в тестах ошибок ввода
Rounded/Hollow; они переведены на поиск по ключам. Первый Config-пакет также
использовал прежние координаты круга и ожидания до уже принятой добавки 2,5 мм
на выступы арматуры периодического профиля и обхода круга от 12 часов по часовой
стрелке. Эти ожидания исправлены с явным геометрическим обоснованием:
контактное межосевое расстояние равно сумме радиусов плюс 2,5 мм. В четырёх
проверках смещения крайние стержни разных граней совпадали при отступе 80 мм,
поэтому общее правило сохранения владельца корректно объединяло их. Вход
этого теста заменён на 100 мм, чтобы проверять смещение без совпадения углов.
Рабочая геометрия ради прохождения тестов не менялась.

Сборка с нуля выявила два старых сбоя COM-привязки PowerShell 5.1: запись Double
после текстовых Value2 и дробной RowHeight после целых высот. Отдельные числовые
setter-ы устранили ошибки сборщика. В дополнительном тесте ридера использование
переменных до объявления остановило первый запуск в редакторе VBA и дало timeout;
объявления перенесены в начало процедуры, проект скомпилирован, повторный запуск
прошёл. Эти неудачные журналы сохранены; они не засчитывались как PASS.
