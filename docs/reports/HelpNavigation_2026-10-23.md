# Проверка переходов к справке

Сообщённый сбой прокрутки не воспроизведён. На сохранённой книге проверены
все 152 внутренние ссылки на справку: 144 с Config, четыре с листа «Сечения»
и четыре из самой справки. Рабочий обработчик и опубликованная книга
в этой задаче не менялись; пользовательские данные и результаты сохранены.

## Проверка в Excel

Для каждой ссылки выполнены три сценария: справка свёрнута, целевая строка
уже видна, внутри раздела вручную скрыта строка. Проверка открывает read-only
копию в собственном экземпляре настоящего Excel и вызывает штатную команду
«Открыть гиперссылку» из выбранной исходной ячейки. Она проверяет активный
лист, положение верхней строки окна, первый столбец и отсутствие скрытых
строк во всём целевом разделе. Физическое нажатие мышью этим не проверяется.

Итоговое покрытие — 456 из 456 пар «ссылка/сценарий». Во всех случаях
целевой заголовок находится сверху окна, первый столбец равен 1,
раздел раскрыт полностью. Отдельно подтверждены все девять переходов
для трёх настроек сетки:

| Настройка | Ссылка Config | Назначение | Сценариев успешно |
|---|---|---|---|
| Mesh.StepMode | E16 | Справка!A800 | 3/3 |
| Mesh.StepX | E17 | Справка!A809 | 3/3 |
| Mesh.StepY | E18 | Справка!A819 | 3/3 |

Дополнительная проверка Mesh.StepMode после выполнения команды и через
400 мс сохранила строку 800 сверху. Код событий ThisWorkbook из проверяемой
книги совпадает с WorkbookHelpEvents.vba с учётом нормализации регистра
идентификаторов редактором VBA и завершающих пустых строк.

Первый запуск сохранил исходный FAIL: 448 успешных проверок и восемь ошибок
подготовки теста. Для четырёх ссылок внутри справки тест пытался повторно
установить ShowDetail у уже открытой группы; Excel отклонял это действие
до открытия гиперссылки. Исправлена только подготовка теста: исходная группа
раскрывается при скрытой исходной ссылке. Все восемь тех же случаев повторно
прошли без изменения ожиданий. Исходный FAIL и повторный PASS сохранены;
итог объединяет только совпадающие пары, без пропусков и дублирования.

## Вывод и сохранность

Основания объяснять наблюдение пользователя дефектом обработчика не найдены.
Воспроизводимого различия между ссылками Mesh и остальными ссылками нет.
Это не устанавливает причину разового сбоя в пользовательском сеансе Excel.
С учётом уточнения пользователя о возможном временном сбое изменения
прокрутки не вносились. Добавлен повторяемый тест Test-AllHelpNavigation.ps1.
Полные расчётные ON/OFF и пересборка для этой проверки не выполнялись.
