# Автоматический выбор шага бетонной сетки

Добавлена настройка `Mesh.StepMode` непосредственно над `Mesh.StepX` и
`Mesh.StepY` на Config. Список: `Auto 0.05`, `Auto 0.1`, `Auto 0.2`, `User`.
По умолчанию выбран `Auto 0.1`; `Mesh.BoundarySubdivisions = 2`.

В Auto одинаковый основной шаг по X/Y равен выбранной доле меньшего
точного габарита бетонной области в WCS. Например, 300×500 мм и Auto 0.1
дают 30×30 мм. В User используются два ручных положительных шага в INPUT
Length без подмены. Auto сохраняет ручные поля и не использует их, включая
пустой ввод и ошибку формулы. В User такая ошибка указывает фактическую ячейку.

Алгоритм дробления граничных ячеек общий для обоих режимов; при основном
шаге 30 мм и дроблении 2 проверены граничные элементы 15×15 мм. Параметрические
рецепты и создание сетки по контурам AutoCAD используют один построитель.
Готовые Region бетона AutoCAD сохраняются без нового разбиения. Расчёт
по-прежнему читает сохранённое сечение: изменение сетки требует формирования.

Справка новой настройки имеет оформление соседних блоков, ссылку «Подробнее»,
формулу, пример и пояснение обоих режимов. Проверены настоящее раскрытие
всего раздела, прокрутка к заголовку и полное сворачивание. Все 76 рисунков
справки сохранены; 75 исходных PNG-частей не изменились. Обновлён макет для
последующей сборки и справочник API `TSectionMeshOptions.AutoStepFactor`.

При вставке строки обнаружено смещение служебных формул выбора сочетаний,
использовавших `ROW(A…)`. Счётчик заменён на собственную строку `ROW()`;
в настоящем Excel проверены последовательно все 30 разных ID.
