# Круг: начало сверху, обход по часовой стрелке

Исходная версия: `ec73ee9a`, ветка `codex/linked-rebar-row-offsets`.

В CSectionRecipeCircle заменены три исполняемые строки: две команды создания
линии центров используют существующую ArcPath с началом π/2 и обходом −2π;
знаки контактного построителя изменены на −1 по нормали и +1 по касательной.
Начало — над центром, на «12 часах», дальнейшие стержни идут по часовой стрелке.
При нулевых концевых отступах ряд остаётся полным и равномерным, без повторного
конца. При ненулевых отступах используется прежняя общая Slice.

Число строк рабочего рецепта не выросло: 143 до и после. Процедур по-прежнему
шесть, структура условий прежняя. Нет новых классов, общих методов или
специального расчёта координат. Бетонный контур, общий CirclePath и остальные
рецепты не менялись. Источник доказательства — `CircleClockwise/SourceScope.json`.

Дополнительные ряды по-прежнему направлены внутрь бетона; SideBySide идёт
по часовой касательной. Привязка EverySecondBar теперь выбирает нечётные
позиции от верхнего стержня. Концевые отступы измеряются вдоль основного ряда:
StartSetback вперёд по часовой стрелке, EndSetback назад от конца полного оборота.
Изменены только соответствующие пояснения в Config и Справке; форматирование
комментария осталось слева, без переноса, 15 pt.

## Приёмка

Доказательства: `docs/regression/DependentRowOffsets_2026-10-17/`.

- CircleClockwiseTests: 146 проверок начала, направления, полного круга,
  двусторонних и односторонних отступов, возврата 0/0, mm/cm/m, двух/трёх
  рядов, знаков смещения, добавки профиля и EverySecond — без отказов.
- 4774 проверки привязок круга, 146 ввода четырёх рецептов, 524 ошибок и
  отключённых полей круга — без отказов.
- CircleClockwiseExamples: семь схем Excel и 48 решений НДС; все сошлись.
  Восемь batch-сочетаний завершились без NumFail, общие статусы сохранены.
- Четыре примера других форм совпали с предыдущими по всем 104 069 строкам
  контрольных данных, включая геометрию и выполняемые для них расчёты.
- 12 110 сравнений значений/формул сохранённой книги, кроме двух намеренно
  изменённых пояснений, прошли. Именованные диапазоны не менялись.
- Фактический встроенный VBA сверяется со всеми 153 исходными компонентами;
  общий состав книги — 158 компонентов.

У открытой дуги разрыв армирования переместился с правой стороны наверх
относительно неизменных моментов. В перегруженном BEND-примере ширина трещины
поэтому изменилась с 0,251739 до 0,338518 мм при сохранённом пределе 0,3 мм:
NormalCrackStatus перешёл из OK в FAIL. Внутренние статусы поиска остались
rsSuccess; общий статус этого перегруженного сочетания и раньше был FAIL.
Это изменение физической расстановки, не численная несходимость. Старый
эталон не заменялся; обе численные записи сохранены.

Книга и ALL CODE выпускаются вместе, пользовательский execution_report
сохраняется. Полные ON/OFF не требовались и не запускались.

Актуальные схемы: `CircleClockwiseExamples/Circle_TwoRows_100.png` и
`CircleClockwiseExamples/Circle_Arc_ThreeRows_100_200.png` в папке доказательств.
