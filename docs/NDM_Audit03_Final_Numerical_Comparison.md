## Намеренные Изменения Контрактов

Классы не подгоняют expected под текущий ответ. Сохранены физические узлы,
пределы материалов, знаки и обычные численные формулы. Отличающиеся ошибочные
ветви документированы вместе с negative/positive reproducer-ами:

- Generic Search возвращает проверенный root/retained bracket и точную typed
  причину, не объявляет несошедшуюся пробу физическим пределом.
- Единый пользовательский LoadPath заменяет независимую Formation-настройку;
  фиксированный путь без масштабируемой компоненты получает InputErr.
- При недоступной Formation-точке Width по пригодному текущему НДС использует
  согласованный psi=1/warning. Подтвержденный NotCracked формулу не вызывает,
  сохраняет заданный User PsiS и не пишет неиспользованное предупреждение.
- Четыре старые assertions принудительной runtime-ширины заменены проверкой
  сохранения существующей ширины; размеры новой книги принадлежат сборке.
- Новые invalid-input проверки не меняют правильные numerical expected или
  tolerance обычных сценариев. Переполнение/обнуление технической арифметики
  не является новым нормативным физическим критерием.

Статическая сверка прежних AssertClose и инженерное объяснение двух записей
psi приведены в `NDM_Audit03_ResultComment_Review.md`, раздел «Сверка численных
эталонов с Baseline». Исторические отрицательные comparison/log artifacts
сохранены, не перекрашены в PASS и не удалены.

## Финальный Повтор v328

`expected_preservation_release_v328_2026-10-05.txt` дает 536 неизменных
expected/tolerance из 542 исходных AssertClose, reviewedApiOnly=0,
changedOrMissing=6, все 277 исходных Test-процедур сохранены. Четыре
ColumnWidth exceptions требуют точного сохранения прежней ширины вместо
навязывания 10; допуск этой presentation-проверки стал 0, не был ослаблен.
Две условные записи Psi теперь объединены в одну: при недоступной Formation
все три режима используют 1 с предупреждением. Это тот же согласованный
контракт, а не подгонка обычной формулы или component tolerance. Для fixed
моментного пути без моментной Base Formation сохраняет `rcInvalidInput`,
не выдумывает трещину от постоянной части. Raw script exit=1 сохранен;
приемка шести исключений выполняется этим содержательным разбором.

Latest Off v322 -> v328 сравнил 20893 общих numeric IDs: missing=0,
differences=0. Baseline -> v328 Off сохраняет все 3273 ID и тот же набор
111 отличий с теми же значениями, что приведены выше для v322. Итоговый On
v322 -> v328 сравнил 20898 общих ID: missing=0, differences=0; baseline ->
v328 On сохраняет все 3273 ID и ровно тот же набор 111 отличий. Последняя
проверка не изменила технические причины отличий или прежние допуски.
