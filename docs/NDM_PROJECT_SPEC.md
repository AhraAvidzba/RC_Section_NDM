# NDM_PROJECT_SPEC

Дата актуализации: 2026-08-05.

## Назначение

Проект реализует Excel VBA-программу для расчета железобетонных поперечных сечений по нелинейной деформационной модели.

Основная постановка:

```text
N + Mx + My
```

Отдельных расчетных режимов `Mx`, `My`, `Mxy` нет. Одноосный изгиб является частным случаем общей постановки.

## Поддерживаемая функциональность

- расчет НДС по заданным `N`, `Mx`, `My`;
- расчет несущей способности с сохранением направления вектора моментов;
- расчет ширины раскрытия уже образовавшихся нормальных трещин;
- batch до 20 сочетаний;
- круглая геометрия;
- прямоугольник со скруглениями;
- автоматическая арматура круглого сечения;
- параметрические TwoLine/ThreeLine диаграммы материалов по параметрам бетона, арматуры и расчетного режима;
- экспорт расчетной сетки и напряжений в AutoCAD;
- импорт расчетной сетки из AutoCAD `Region` на заданных слоях.

## Неподдерживаемая функциональность

- напрягаемая арматура;
- отдельные расчеты `SolveMx`, `SolveMy`, `SolveMxy`;
- ручной ввод координат арматуры на листе `Расчет`;
- новые геометрии без отдельного задания;
- расчет образования трещин и `Mcrc`;
- окончательная нормативная сертификация без закрытия трассировки.

## Нормативные требования

- Значения по СП не подставлять по памяти.
- Все нормативно зависимые параметры должны быть видимы и редактируемы на `Config`.
- Неоднозначные формулы фиксировать в `docs/OpenNormativeQuestions.md`.
- До завершения трассировки расчеты считать предварительно верифицированным прототипом.

## Архитектурные требования

- Расчетное ядро не обращается к `Range`, `Cells`, `Worksheets`, `ActiveSheet`.
- Ввод и вывод из Excel изолированы в `src/Excel`.
- Все настройки читаются пакетно через `CSystemSettingsReader`.
- Геометрия реализуется через `ISectionGeometry`.
- Сетка и арматура передаются в решатель подготовленными массивами.
- Writer-ы пишут результаты блочно, а не построчно.

## Расчетная модель

Поле деформаций:

```text
epsilon(x, y) = epsilon0 + kappaX * y + kappaY * x
```

Равновесие:

```text
Nint  = Next
Mxint = Mxext
Myint = Myext
```

Подробности: `docs/MathematicalModel.md`.

## Материалы

Материалы задаются параметрами:

- `rngConcreteMaterialParameters`;
- `rngSteelMaterialParameters`;
- `rngCalculationDiagramSettings`.

Пользователь выбирает TwoLine/ThreeLine для расчетных режимов. Произвольные точки диаграмм больше не являются входными данными: контрольные таблицы точек на `Config` используются только для проверки формул.

## Несущая способность

Поддерживаются:

- `Capacity.SolutionStrategy = Auto`;
- `Capacity.SolutionStrategy = UltimateStrain`;
- `Capacity.SolutionStrategy = LoadMultiplier`.

Для `LoadMultiplier` и fallback-ветки `Auto`:

- `Capacity.SearchMethod = Bisection`;
- `Capacity.SearchMethod = Brent`;
- `Capacity.SearchMethod = Secant`.

`NumericalFailure` не считается физическим разрушением.

## Трещины

Расчет выполняется для продолжительного раскрытия нормальных трещин по II группе. Настройки `SLS.Crack.*` управляют включением расчета, допустимой шириной, способом определения `psi_s` и способом выбора растянутой зоны `Abt`.
