# NDM_PROJECT_SPEC

Дата актуализации: 2026-09-21.

## Назначение

Проект реализует Excel VBA-программу для расчета железобетонных поперечных сечений по нелинейной деформационной модели.

Основная постановка:

```text
N + Mx + My
```

Отдельные режимы `Mx`, `My`, `Mxy` не развиваются. Одноосный изгиб считается частным случаем общей постановки.

## Поддерживаемая Функциональность

- расчет НДС по заданным `N`, `Mx`, `My`;
- расчет несущей способности по выбранной λ-траектории;
- расчет образования нормальной трещины внутри ветки `Calculation.Crack.Width`;
- расчет ширины раскрытия нормальных трещин и проверка продольных трещин;
- расчет продольного изгиба и устойчивости по СП 63 и СП 35;
- batch по фактическим строкам `rngLoadCombinations`; шаблон содержит 30 строк, число строк можно менять;
- параметрические геометрии `Circle`, `RectSet`, `RoundedRectangle`, `HollowRectangle`;
- AutoCAD import расчетной сетки из `Region`;
- AutoCAD export геометрии, контура, арматуры, осей, нейтральной линии и результатов;
- Excel-схема по сохраненному снимку `Results`;
- человекочитаемый отчет расчета.

## Неподдерживаемая Функциональность

- напрягаемая арматура;
- ручной ввод координат арматуры на листе `Расчет`;
- отдельные пользовательские режимы `SolveMx`, `SolveMy`, `SolveMxy`;
- самостоятельный расчет `Mcrc`/`Ncrc` вне расчета трещин;
- автоматическое восстановление точного контура произвольного импортированного `Region`, если контур не задан параметрически;
- окончательная нормативная сертификация без ручной проверки источников.

## Нормативные Требования

- Значения по СП нельзя подставлять по памяти.
- Основные источники находятся в `norms/`.
- Все нормативно зависимые параметры должны быть видимы на `Config` или в контрольных таблицах.
- Неоднозначные формулы фиксируются в `docs/OpenNormativeQuestions.md`.
- До закрытия трассировки расчеты считаются инженерно проверяемой реализацией, а не заменой независимой нормативной экспертизы.

## Архитектурные Требования

- Расчетное ядро не обращается к `Range`, `Cells`, `Worksheets`, `ActiveSheet`.
- Excel-ввод и вывод изолированы в `src/Excel`.
- Все настройки читаются через `CSystemSettingsReader`.
- Пользовательские единицы и знаки проходят через `CUnitSystem`.
- Нагрузки переносятся и нормализуются централизованно.
- Геометрия встроенных генераторов реализуется через `ISectionGeometry`.
- Расчетное ядро работает с готовым `CSectionModel`.
- Реальные `Area/Ix/Iy/Ixy` элементов используются в механике; геометрическая оболочка `Width/Height/Rotation` используется только для границ, схемы и AutoCAD.
- Writer-ы пишут результаты блочно через массивы.

## Расчетная Модель

Поле деформаций:

```text
epsilon(x, y) = epsilon0 + kappaX * y + kappaY * x
```

Равновесие:

```text
Nint  = Next
Mxint = Mxext
Myint = Myext
```

Подробности: `docs/MathematicalModel.md`.

## Материалы

Материалы задаются параметрами:

- `rngConcreteMaterialParameters`;
- `rngSteelMaterialParameters`;
- `rngCalculationDiagramSettings`.

TwoLine/ThreeLine-диаграммы строятся по параметрам материала и выбранному расчетному режиму. Контрольные таблицы точек на `Config` используются для проверки и трассировки, но не являются ручным вводом произвольной диаграммы.

## Несущая Способность

Поддерживаются стратегии:

- `Capacity.SolutionStrategy = Auto`;
- `Capacity.SolutionStrategy = UltimateStrain`;
- `Capacity.SolutionStrategy = LoadMultiplier`.

Поддерживаются пути:

- `λ*Mx`;
- `λ*My`;
- `λ*Mxy`;
- `λ*N`;
- `λ*NMxy`.

Для `LoadMultiplier` и fallback-ветки `Auto` доступны `Bisection`, `Brent`, `Secant`. Численная несходимость не считается физическим разрушением.

## Трещины

Расчет выполняется для сочетаний, где в профиле включен `Calculation.Crack.Width`. Сначала проверяется образование нормальной трещины по выбранному `SLS.Crack.InitiationLoadPath`, затем считается ширина раскрытия и отдельно проверяются продольные трещины. `CrackedState` нужен не только для нормальных, но и для продольных трещин, поэтому рассчитывается для всех сочетаний с включенной веткой трещин.
