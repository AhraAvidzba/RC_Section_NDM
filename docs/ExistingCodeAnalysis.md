## Доступность VBA-кода

Обе `.xlsm`-книги содержат `xl/vbaProject.bin`, а рядом есть экспортированный код в текстовых файлах. Этого достаточно для анализа без открытия Excel и без изменения бинарных книг.

## Справочная программа круглого сечения

Книга содержит листы:

- `системный`
- `сочетания`
- `расчет`

Основные модули:

- `NDM.bas` - расчет прочности круглого сечения по высоте сжатой зоны.
- `II_gruppa.bas` - расчет приведенного сечения, нейтральной линии и напряжений для второй группы.
- `Module3.bas` - вспомогательные функции, интерполяция и поиск минимального запаса.
- `Class1.bas` - небольшой класс/заготовка для сегментов.

Расчетная схема:

- геометрия жестко задана как круг;
- бетон разбивается на горизонтальные сегменты по высоте;
- арматура задается рядами на окружности;
- для прочности ищется высота сжатой зоны `x`;
- внутренние силы суммируются по бетонным сегментам и стержням;
- удерживающий момент считается относительно центра круга;
- вторая группа использует приведенное сечение и аналитические зависимости для кругового сегмента.

Инженерно полезные решения:

- аналитические формулы площади и центра кругового сегмента;
- понятное разделение бетонных сегментов и арматурных рядов;
- контроль равновесия по продольной силе при подборе высоты сжатой зоны;
- отдельная логика для приведенного сечения второй группы.

Риски:

- расчет одномерный и применим только к круглому сечению;
- используются глобальные массивы `bet`, `arm1`, `arm2`, `arm3`;
- единицы в коде местами указаны как м, т, т/м2, что не соответствует целевым внутренним единицам новой программы;
- растянутый бетон в прочностном расчете обнуляется по напряжению, но касательная жесткость в старой схеме явно не контролируется;
- поиск высоты сжатой зоны выполняется пошаговым перебором с уменьшением шага, а не общим трехпараметрическим решателем;
- часть кода закомментирована, содержит экспериментальные функции и не должна переноситься автоматически;
- нормативные коэффициенты и диаграммы не имеют полной трассировки до пунктов СП.

## Справочная программа произвольного сечения

Книга содержит листы:

- `Batch`
- `Data`
- `Log`
- `Calculation`
- `Справка`

Основные модули:

- `Functions.cls` - диаграммы материалов, итерационные процедуры, пакетный расчет, вспомогательная интерполяция и матричное решение через Excel.
- `CAD.cls` - обмен с AutoCAD, чтение областей/точек, запись результатов визуализации в DWG.
- `Interpolate.cls` - интерполяция по диапазонам Excel.
- `ExportAllClasses.cls` - экспорт модулей.
- классы листов и книги - в основном контейнеры событий/метаданных.

Расчетная схема:

- геометрия поступает из AutoCAD как `REGION` и `POINT`;
- элементы имеют типы `c`, `r`, `p`, `u` и варианты точек `cp`, `rp`, `pp`, `up`;
- из AutoCAD читаются площадь, центроид, моменты инерции и bounding box;
- в расчетной книге хранятся деформации, напряжения, матрицы и результаты;
- используется поле деформаций с тремя параметрами: `eps0`, кривизны по двум направлениям;
- решение выполняется итерациями с пересчетом листа Excel;
- есть пакетный режим через лист `Batch`.

Инженерно полезные решения:

- сама идея представлять произвольное сечение набором элементарных площадок и стержней;
- поддержка нескольких типов материалов в справочном расчете: бетон, обычная арматура, напрягаемая арматура, пользовательский материал; для новой программы это не является требованием, так как проект ограничен обычной ненапрягаемой арматурой;
- учет косого изгиба через трехпараметрическое поле деформаций;
- пакетная обработка сочетаний;
- визуализация сжатых/предельных зон и напряжений в AutoCAD;
- использование массивной записи данных в диапазоны вместо поэлементной записи в некоторых местах импорта.

Риски:

- расчетное ядро напрямую читает и пишет `Range`, `Cells`, `ActiveSheet`, `ActiveWorkbook`;
- AutoCAD является обязательным источником геометрии для произвольного сечения;
- в `Functions.cls` используется `WorksheetFunction.MInverse`, что запрещено для нового решателя;
- сходимость в `MainIteration` контролируется по изменению параметров деформаций, а не по нормированным невязкам `N`, `Mx`, `My`;
- при нулевом моменте код принудительно обнуляет соответствующую кривизну, что противоречит требованию для несимметричных сечений;
- несходимость местами трактуется как недостаточная несущая способность;
- в горячем контуре вызывается `Calculate`, а данные хранятся на листе;
- обработка ошибок частично подавляет детали через `On Error Resume Next` или общий выход из обработчика.

## Вывод

Существующие программы пригодны как инженерные источники идей и контрольных ориентиров. Их архитектуру переносить нельзя: новая программа должна отделять ядро от Excel/AutoCAD, работать во внутренних единицах, иметь трехпараметрический решатель и нормативную трассировку.
