# UserGuideRectSet

Дата актуализации: 2026-09-19.

## Назначение

Сечение из прямоугольников задается на листе `Config` в диапазоне `rngRectSetGeometry` и рассчитывается тем же универсальным ядром `N + Mx + My`, что круг и скругленный прямоугольник. Один и тот же блок используется для прямоугольника, Г-сечения и двух прямоугольников со смещением верхней части.

## Выбор Геометрии

В `rngSystemSettings` установите:

```text
Geometry.Type = RectSet
```

Все размеры сечения и параметры автоматической расстановки арматуры задаются только на листе `Config`.

## Общие Настройки Геометрии

`RectSet.SectionType` - тип формы:

```text
Rectangle     только верхний прямоугольник H1/B1
LSection      два прямоугольника с общей левой гранью, то есть обычное Г-сечение
TwoRectangles два прямоугольника; верхний можно смещать по X
```

`RectSet.UpperOffsetX` - горизонтальное смещение верхнего прямоугольника относительно базового положения. При `Offset = 0` левая грань верхнего прямоугольника совпадает с левой гранью нижнего. Плюс смещает верхний прямоугольник вправо по оси X. В режиме `LSection` этот параметр не используется, чтобы поведение Г-сечения оставалось неизменным.

## Размеры Сечения

Таблица `rngRectSetGeometry` имеет колонки:

```text
Параметр | H1 | B1 | H2 | B2 | Ед. | Комментарий
```

Смысл размеров:

| Параметр | Ед. | Смысл |
|---|---:|---|
| `H1` | мм | высота верхнего прямоугольника |
| `B1` | мм | ширина верхнего прямоугольника |
| `H2` | мм | высота нижнего прямоугольника |
| `B2` | мм | ширина нижнего прямоугольника |

В режимах `LSection` и `TwoRectangles` полная высота сечения равна `H1 + H2`: верхний прямоугольник расположен непосредственно над нижним. В режиме `Rectangle` нижний прямоугольник `H2/B2` полностью отключается и не участвует в бетоне, арматуре, контурах и размерных линиях.

Допустимые размеры:

```text
B1 > 0
H1 > 0
B2 > 0 и H2 > 0 для LSection и TwoRectangles
```

Для `LSection` сохраняется поведение обычного Г-сечения с общей левой гранью. Для `TwoRectangles` верхний прямоугольник может смещаться по X, но должен иметь горизонтальное пересечение с нижним прямоугольником, иначе бетонная область распадается на две несвязанные части.

## Основной Ряд Арматуры

Для каждой стороны каждой грани задаются параметры первого ряда. На листе они собраны в строках вида `H2 - левая`, `H2 - правая`, `B1 - верхняя`, `B1 - нижняя`.

| Параметр | Ед. | Что задает |
|---|---:|---|
| `as` | мм | расстояние от соответствующей бетонной грани до оси первого ряда стержней, измеренное по нормали внутрь сечения. Для `H`-граней это расстояние по X от левой/правой грани, для `B`-граней - по Y от верхней/нижней грани. |
| `d` | мм | диаметр стержней первого ряда на этой стороне грани. Пустая ячейка или `0` отключает ряд, даже если задано `n`. |
| `n` | шт | количество стержней первого ряда на этой стороне грани. Если `n = 0`, ряд не создается. |
| `t нач.` | мм | отступ от начала линии раскладки до первого стержня. Начало линии определяется направлением обхода грани по часовой стрелке. |
| `t кон.` | мм | отступ от конца линии раскладки до последнего стержня. Конец линии также берется по направлению обхода по часовой стрелке. |

Линия раскладки - это линия осей первого ряда стержней, параллельная выбранной бетонной грани; она уже смещена внутрь сечения на расстояние `as`, идет от края до края соответствующего прямоугольника и не обрезается на `as` сверху, снизу или по бокам. Например, для `H2 - левая` линия раскладки проходит внутри нижнего прямоугольника параллельно левой грани H2, на расстоянии `as` от нее, на всю высоту `H2`.

Доступную длину, на которой реально раскладываются стержни, уменьшают только `t нач.` и `t кон.`. Поэтому `as` не входит в формулу доступной длины вдоль грани.

В именах ключей `t нач.` для стороны `_1` хранится как `StartOffset1`, а `t кон.` - как `EndOffset1`. Для стороны `_2` используются `StartOffset2` и `EndOffset2`.

Доступная длина для раскладки на одной линии:

```text
Lдоступная = Lграни - t нач. - t кон.
```

Шаг между стержнями при `n > 1`:

```text
step = Lдоступная / (n - 1)
```

Если `t нач. + t кон.` больше длины грани, программа останавливает расчет ошибкой, потому что невозможно разместить первый и последний стержень на отрицательной доступной длине. Если на грани задан один стержень, он ставится в середину доступного участка.

## Дополнительные Ряды

Дополнительные ряды задаются строками:

| Строка | Смысл |
|---|---|
| `d_2row_1` | диаметр второго ряда у грани `_1` |
| `d_2row_2` | диаметр второго ряда у грани `_2` |
| `d_3row_1` | диаметр третьего ряда у грани `_1` |
| `d_3row_2` | диаметр третьего ряда у грани `_2` |
| `loc_2row` | расположение второго ряда, общее для `_1` и `_2` |
| `loc_3row` | расположение третьего ряда, общее для `_1` и `_2` |
| `bind_2row` | привязка второго ряда к стержням первого ряда |
| `bind_3row` | привязка третьего ряда к стержням первого ряда |

Пустой или нулевой диаметр означает, что соответствующий дополнительный ряд не создается.

Если первого ряда на конкретной грани нет, второй и третий ряды этой грани не создаются, даже если их диаметры указаны.

Третий ряд всегда строится относительно первого ряда. Если второй ряд есть и `loc_3row` совпадает с `loc_2row`, третий ряд перескакивает второй. Если направления разные, третий ряд ставится от первого ряда в своем направлении.

Допустимые значения `loc_2row` и `loc_3row`:

| Значение | Смысл |
|---|---|
| `Stacked` | дополнительный стержень ставится внутрь сечения |
| `SideBySide` | для вертикальных граней `H1/H2` стержень ставится вниз, для горизонтальных `B1/B2` вправо |

Допустимые значения `bind_2row` и `bind_3row`:

| Значение | Смысл |
|---|---|
| `EachBar` | дополнительный ряд создается у каждого стержня первого ряда |
| `EverySecondBar` | дополнительный ряд создается через один стержень первого ряда |

## Служебные Имена В Настройках

На экране пользователь видит понятные строки граней: `H1 - левая`, `H1 - правая`, `B1 - верхняя`, `B1 - нижняя`, `H2 - левая`, `H2 - правая`, `B2 - верхняя`, `B2 - нижняя`. Внутри книги эти же строки разворачиваются в ключи настроек с суффиксами `_1` и `_2`.

`H1` - вертикальные грани верхнего прямоугольника.

`B1` - горизонтальные грани верхнего прямоугольника.

`H2` - вертикальные грани нижнего прямоугольника.

`B2` - горизонтальные грани нижнего прямоугольника.

`_1` - первая сторона грани: левая для `H1/H2`, верхняя для `B1/B2`.

`_2` - вторая сторона грани: правая для `H1/H2`, нижняя для `B1/B2`.

Примеры соответствия:

| Строка на Config | Внутренние ключи |
|---|---|
| `H2 - левая` | `RectSet.H2.as_1`, `RectSet.H2.d_1`, `RectSet.H2.n_1`, `RectSet.H2.StartOffset1`, `RectSet.H2.EndOffset1` |
| `H2 - правая` | `RectSet.H2.as_2`, `RectSet.H2.d_2`, `RectSet.H2.n_2`, `RectSet.H2.StartOffset2`, `RectSet.H2.EndOffset2` |
| `B1 - верхняя` | `RectSet.B1.as_1`, `RectSet.B1.d_1`, `RectSet.B1.n_1`, `RectSet.B1.StartOffset1`, `RectSet.B1.EndOffset1` |
| `B1 - нижняя` | `RectSet.B1.as_2`, `RectSet.B1.d_2`, `RectSet.B1.n_2`, `RectSet.B1.StartOffset2`, `RectSet.B1.EndOffset2` |

## Дубли В Углах

Если разные грани или ряды дают одну и ту же координату стержня, повторный стержень не добавляется. Это защищает от двойного учета арматуры в углах.

## Результаты

После расчета контрольные координаты автоматически созданных стержней больше не выводятся на лист `Config`; расчетный снимок хранится на `Results`.

Расчетные результаты сохраняются на лист `Results`: сводка по сочетаниям - в
`rngBatchSummary`, а полный расчетный snapshot - в таблицах NDM ниже. Лист
`Расчет` используется для кнопок и визуальной схемы, без отдельного численного
вывода результата.
