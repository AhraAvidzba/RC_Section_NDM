## Как собирается книга

Сборка выполняется через Excel COM:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Build-Workbook.ps1
```

Результат сохраняется в:

```text
workbook/output/RC_Section_NDM.xlsm
```

Книга сохраняется как macro-enabled workbook (`.xlsm`), но на этапе 1 в нее не добавляются VBA-модули с расчетной логикой.

## Структура книги

Созданы листы:

- `Расчет`
- `System`

Лист `Расчет` содержит четыре горизонтальных блока:

- `Исходные данные`;
- `Расчёт Mx`;
- `Расчёт My`;
- `Расчёт Mxy`.

Лист `System` содержит смысловые блоки:

- геометрия и дискретизация;
- материалы;
- нормативные параметры;
- настройки решателя;
- настройки поиска несущей способности;
- настройки расчета ширины раскрытия трещин;
- диагностика.

## Именованные диапазоны

Созданы крупные именованные диапазоны:

- `rngMainInput`;
- `rngRebarInput`;
- `rngLoadCombinations`;
- `rngResultMx`;
- `rngResultMy`;
- `rngResultMxy`;
- `rngSystemSettings`;
- `rngSystemDiagnostics`.

Отдельные имена для каждой ячейки не создавались.

Таблица `rngSystemSettings` организована как:

```text
Ключ | Значение | Единица | Комментарий | Нормативная ссылка
```

Таблица `rngRebarInput` организована как:

```text
ID | X | Y | Diameter | Area | SteelClass | Comment
```

Уточнение после этапа 2: проект поддерживает только обычную ненапрягаемую арматуру; поля `InitialStrain` и `IsPrestressed` исключены из целевой схемы.

Таблица `rngLoadCombinations` организована как:

```text
CombinationID | N | Mx | My | CalculationType | DurationType | Comment
```

## Настройка печати

Для листа `Расчет` настроены:

- формат А4;
- книжная ориентация;
- печатная область `Расчет!$A$1:$BT$50`;
- ручные вертикальные разрывы перед колонками `S`, `AK`, `BC`;
- четыре блока слева направо;
- масштаб печати 80%;
- отсутствие горизонтальных разрывов.

Лист `System` не включен в пользовательскую печатную форму.

## Выполненные проверки

Проверка выполняется командой:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_workbook/Validate-Workbook.ps1
```

Проверено:

- наличие листов `Расчет` и `System`;
- наличие всех обязательных именованных диапазонов;
- отсутствие дублирующихся имен;
- корректность области печати;
- формат А4 и книжная ориентация;
- отсутствие горизонтальных разрывов при масштабе 80%;
- наличие ручных вертикальных разрывов перед колонками `S`, `AK`, `BC`;
- расположение блоков слева направо;
- заголовки таблицы системных настроек;
- заголовки таблицы арматуры;
- заголовки таблицы сочетаний нагрузок;
- отсутствие формул и расчетной логики НДМ.

Итог проверки: все проверки пройдены.

## Невыполненные проверки

- Физическая печать на принтер или экспорт в PDF не выполнялись.
- Компиляция VBA не выполнялась, потому что на этапе 1 расчетные VBA-модули не добавлялись.
- Инженерные расчетные проверки не выполнялись, потому что расчетная логика не реализована.

## Известные ограничения

- В книге пока нет расчетного ядра.
- В книге пока нет моделей материалов.
- В книге пока нет геометрии и построения сетки.
- В книге пока нет нормативных значений, не подтвержденных трассировкой.
- Значения в служебных таблицах предназначены для будущего чтения управляющим слоем и не используются для расчета на этапе 1.
