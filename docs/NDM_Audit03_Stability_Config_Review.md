# Audit03: Настройки Устойчивости

Дата: 2026-10-04. Исходный checkpoint: `23e167a8`.

## Объем

Поадресная проверка всех 17 editable полей Stability в действующей таблице
Config. Настоящий reader -> units/materials/profiles -> batch -> Calculator
выполняется заново в каждом сценарии. Модель - армированный круг 300 мм,
12 стержней диаметром 16 мм на радиусе 120 мм. Это направленная проверка
Config, а не повтор полной матрицы всех форм и не нормативная верификация.

Таблица испытывается на исходном месте и после переноса именованного диапазона
в CH800. Все исходные формулы таблиц и ссылки имен восстанавливаются тестом.
Основная output-книга и пользовательский Excel не используются как test fixture.

## Подтвержденные Дефекты

- Неизвестный SystemType молча выбирает определимую схему.
- Числа, отличные от 1/-1, принимаются как направление случайного эксцентриситета.
- Отрицательный модуль User скрытно преобразуется через Abs.
- Ошибки диапазонов и selectors Calculator не указывают текущую ячейку Config.
- Автономный Calculator тоже принимал неизвестную расчетную схему и завершал
  вычисления вместо раннего InputErr; отдельный тест требует Calculated=False.

Начальный v252 завершился 1033/2: один подтвержденный address failure и ошибка
нового helper-а при CVErr до инициализации profile catalog. Ошибка helper-а
исправлена отдельно, не подменяется production-дефектом. Уточненный frozen v253
завершился 7354/130: 64 address assertions, по 22 status/key/action assertions.
При корректных значениях новые численные проверки этого прогона прошли.
Окончательный frozen v254 добавляет дополнительные SP35/NoCompression/lifecycle
проверки: 7680/138, все отказы воспроизведены при неизменном production.
Шесть дополнительных отказов относятся к маскировке неизвестных selectors
ранним NoCompression, два - к автономному принятию неизвестной схемы.

## Владение И Изменения

`CStabilityCalculator.ValidateSettings` владеет допустимыми диапазонами и
selectors. Batch передает нормализованные числа и reader только для адреса,
не повторяет формулы и не назначает статусы по тексту. Автономный Calculate
использует тот же validation до раннего NoCompression. Формулы СП 63/СП 35,
материалы, оси, продольные нагрузки и критерии физической проверки не изменены.

Unknown SystemType не превращается в Determinate; signs строго 1/-1.
User означает положительный модуль; в Auto допускается неиспользуемое число 0,
но не отрицательный модуль. Delta=0 сохраняет существующее отключение своей
программной границы. Активные положительные delta-границы упорядочены.
Ks/PhiP/NOverNcrLimit положительны; произвольный положительный коэффициент
не объявляется нормативно подтвержденным. Все 17 ключей Config обязательны,
потерянная строка/blank/TODO/CVErr не заменяются defaults новой книги.

Контролируемая ошибка остается rsInvalidInput/rcInvalidInput. При ранней
автономной ошибке Calculated=False; CalcErr относится к программной причине.
В устойчивости нет поиска НДС и NumFail не формируется. Отдельные consumers
могут выполнять DirectState; отключенный фильтр не меняет его плоскость/solve count.

## Поведенческие Проверки

- L/mu1/mu2 изменяют фактические расчетные длины и Ncr по обратному квадрату
  при фиксированной жесткости; другой плоскости mu не подменяется.
- Определимая/неопределимая схема дают соответственно сумму/максимум
  статического и случайного эксцентриситетов в управляемом fixture.
- Оба zero-sign действуют только при нулевом моменте; при ненулевом знак
  следует моменту, а не настройке для нулевого случая.
- User1/User2, OnlyMomentPlane/BothPlanes и все AutoWithL/MuL варианты
  проверены по фактическим эксцентриситетам; Greek mu alias проверяется отдельно.
- PhiL2/Auto и длительная часть изменяют SP63/eta результаты. Табличная SP35
  сохраняет свою phi при изменении допустимых eta/SP63 настроек.
- Ks и delta-границы управляют D/delta; SP35 PhiP изменяет D только eta-ветви,
  NOverNcrLimit масштабирует Reserve без изменения Ncr/eta. Есть OK/FAIL
  по этому запасу и оба SP35/table/eta исхода.
- Все 17 допустимых настроек при выключенной устойчивости сохраняют реальную
  плоскость DirectState и число solve. Сам фильтр ни одного state-solve не вызывает.
- Эквивалентный INPUT Length мм -> м с пересчетом L и User1/2 сохраняет
  внутренние длины, Ncr и статус. Геометрия остается во внутренних мм.
- Для каждого поля проверены ошибки, потерянный ключ, recovery; ResultComment
  каждого subtree, detailed writers и batch summary проверяются штатным helper-ом.
