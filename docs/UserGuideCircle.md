# UserGuideCircle

Дата актуализации: 2026-09-21.

## Назначение

Инструкция описывает ручной запуск расчета круглого сечения через Excel.

Все исходные данные геометрии, материалов, сетки, арматуры, сочетаний нагрузок и алгоритмов задаются на листе `Config`. Лист `Расчет` используется для кнопок и схемы сечения.

## Открыть Книгу

Открой:

```text
workbook/output/RC_Section_NDM.xlsm
```

Разреши макросы.

## Геометрия И Сетка

В `rngSystemSettings` задай:

| Параметр | Ед. | Пример |
|---|---|---:|
| `Geometry.Type` | | `Circle` |
| `Mesh.StepX` | мм | 50 |
| `Mesh.StepY` | мм | 50 |
| `Mesh.BoundarySubdivisions` | шт | 1 |
| `Load.ReferenceOffsetX` | мм | 0 |
| `Load.ReferenceOffsetY` | мм | 0 |

При `Load.ReferenceOffsetX = 0` и `Load.ReferenceOffsetY = 0` моменты из `rngLoadCombinations` считаются заданными относительно центра тяжести бетонного сечения.

## Круглое Сечение

В `rngCircleGeometry` задай:

| Параметр | Ед. | Пример | Назначение |
|---|---|---:|---|
| `Circle.Diameter` | мм | 1000 | диаметр круга |
| `Rebar.AxisDistance` | мм | 60 | расстояние от грани круга до оси стержней первого ряда |
| `Rebar.Count` | шт | 35 | количество стержней первого ряда по окружности; `0` отключает арматуру |
| `Rebar.Diameter` | мм | 20 | диаметр стержней первого ряда; пусто или `0` отключает арматуру |
| `Rebar.Diameter2` | мм | | диаметр стержней второго ряда, пусто или 0 - ряда нет |
| `Rebar.Diameter3` | мм | | диаметр стержней третьего ряда, пусто или 0 - ряда нет |
| `Rebar.Loc2row` | | `Stacked` | расположение второго ряда |
| `Rebar.Loc3row` | | `Stacked` | расположение третьего ряда |

Допустимые значения `Rebar.Loc2row` и `Rebar.Loc3row`:

- `Stacked` - дополнительный стержень ставится внутрь сечения по радиусу к центру;
- `SideBySide` - дополнительный стержень ставится справа по часовой касательной относительно стержня первого ряда.

Третий ряд строится относительно первого ряда. Если второй ряд есть и `Rebar.Loc3row` совпадает с `Rebar.Loc2row`, третий ряд перескакивает второй. Если направления разные, третий ряд ставится от первого ряда в своем направлении.

Координаты стержней вручную вводить не нужно. Они создаются внутри `CSectionModel` и передаются в расчетное ядро напрямую. Контрольная таблица координат на `Config` больше не выводится.

## Материалы

В `rngConcreteMaterialParameters`, `rngSteelMaterialParameters` и `rngCalculationDiagramSettings` проверь:

| Параметр | Пример |
|---|---:|
| `Concrete.Eb` | 32500 |
| `Concrete.Ebt` | 32500 |
| `Steel.Es` | 200000 |
| `Strength / Растянутый бетон` | `Ignore` |

Пользователь больше не задает произвольные точки диаграмм. Программа строит расчетные TwoLine/ThreeLine-диаграммы по параметрам материала и выбранному расчетному режиму; служебные таблицы точек на `Config` нужны только для контроля формул.

## Сочетание Нагрузок

На листе `Config` в `rngLoadCombinations` заполни строку:

```text
CombinationID | N | Mx | My | ProfileId | CapacityLoadPath | Comment
```

Единицы:

- `N` - выбранная пользователем `INPUT`-единица силы из `rngUnitSettings`;
- `Mx`, `My` - выбранная пользователем `INPUT`-единица момента из `rngUnitSettings`.

Пример:

```text
LC1 | 100 | 50 | 0 | PR1 | λ*Mxy | Контрольный пример
```

Полностью пустые строки ниже игнорируются.

## Запуск И Результаты

На листе `Расчет` нажми кнопку `Выполнить расчет`.

Результаты сохраняются на лист `Results`: сводка по сочетаниям появится в
`rngBatchSummary`, а полный snapshot для схемы и AutoCAD - в таблицах NDM ниже.
Лист `Расчет` остается для кнопок и визуальной схемы.

Кнопка `Очистить чертеж AutoCAD` удаляет из активного чертежа AutoCAD автоматически созданные подписи, нейтральную линию, главные оси и точку приложения нагрузки, оставляя расчетную геометрию.

Кнопка `Экспорт в AutoCAD` выгружает текущую расчетную сетку, арматуру, главные центральные оси, точку приложения нагрузки и напряжения в активное окно AutoCAD.
