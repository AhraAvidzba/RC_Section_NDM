# Пользовательский сценарий расчета круглого сечения

Статус: сценарий предназначен для ручного запуска пользователем в книге `workbook/output/RC_Section_NDM.xlsm`.

Контрольный расчет из этой инструкции не запускается автоматически, исходные данные примера в книгу не подставляются. Пользователь вводит их самостоятельно и получает результаты после нажатия кнопки `Выполнить расчет`.

## 1. Открытие книги

Откройте файл:

```text
workbook/output/RC_Section_NDM.xlsm
```

Если Excel спросит разрешение на макросы, разрешите выполнение макросов для этой книги.

## 2. Основные исходные данные

Все основные поля вводятся на листе `Расчет` в блоке `Исходные данные`.

| Параметр | Лист | Ячейка | Именованный диапазон | Единица | Пример |
|---|---|---:|---|---|---:|
| Объект / элемент | Расчет | E6 | rngMainInput | - | Опора 1 |
| Тип сечения | Расчет | E7 | rngMainInput | - | Circle |
| Ширина прямоугольника | Расчет | E8 | rngMainInput | мм | не заполнять для Circle |
| Высота прямоугольника | Расчет | E9 | rngMainInput | мм | не заполнять для Circle |
| Радиусы скруглений | Расчет | E10:E13 | rngMainInput | мм | не влияют при Circle |
| Диаметр круга | Расчет | E14 | rngMainInput | мм | 300 |
| Центр круга X | Расчет | E15 | rngMainInput | мм | 0 |
| Центр круга Y | Расчет | E16 | rngMainInput | мм | 0 |
| Класс бетона | Расчет | E17 | rngMainInput | - | B30 |
| Класс арматуры | Расчет | E18 | rngMainInput | - | A400 |
| Допустимая ширина трещины | Расчет | E19 | rngMainInput | мм | 0.3 |
| Защитный слой, справочно | Расчет | E20 | rngMainInput | мм | 35 |

В ячейке `Расчет!E7` выберите `Circle`. При этом расчет использует только `Circle.Diameter`, `Circle.CenterX` и `Circle.CenterY`. Поля прямоугольника и радиусов скругления не участвуют в расчете круглого сечения.

## 3. Арматура

Таблица арматуры находится на листе `Расчет` в диапазоне `rngRebarInput` (`Расчет!A25:G34`).

Заголовки расположены в строке `Расчет!A25:G25`. Данные вставляйте начиная с `Расчет!A26`.

| Столбец | Поле | Единица | Пример |
|---:|---|---|---:|
| A | ID | - | B1 |
| B | X | мм | 105.00 |
| C | Y | мм | 0.00 |
| D | Diameter | мм | 20 |
| E | Area | мм2 | 314.16 |
| F | SteelClass | - | A400 |
| G | Comment | - | ring bar |

Координаты задаются в общей системе координат сечения. Для круглого сечения с центром `0; 0` стержни удобно задавать относительно центра круга.

## 4. Одно сочетание нагрузок

Таблица сочетаний находится на листе `Расчет` в диапазоне `rngLoadCombinations`.

Заголовки расположены в строке `Расчет!A40:G40`. Единственное сочетание вводите в строку `Расчет!A41:G41`.

| Столбец | Поле | Единица | Пример |
|---:|---|---|---:|
| A | CombinationID | - | LC1 |
| B | N | Н | -300000 |
| C | Mx | Н*мм | 25000000 |
| D | My | Н*мм | 15000000 |
| E | CalculationType | - | StrengthAndCrack |
| F | DurationType | - | LongTerm |
| G | Comment | - | Контрольный пример |

Оставьте остальные 19 строк сочетаний полностью пустыми. Полностью пустые строки игнорируются: для них не запускаются решатели, они не получают статус `InvalidInput` и практически не увеличивают время расчета.

Частично заполненная строка считается ошибкой исходных данных. Если строка начата, заполните как минимум `CombinationID`, `N`, `Mx` и `My`.

## 5. Настройки System

Материалы, параметры решателя, сетка и параметры трещин считываются с листа `System` из таблицы `rngSystemSettings`.

Для контрольного ручного примера проверьте следующие ключи:

| Ключ | Единица | Пример |
|---|---|---:|
| Calculation.Mode | - | DirectState |
| Capacity.CalculateMx | Да/Нет | Да |
| Capacity.CalculateMy | Да/Нет | Да |
| Capacity.CalculateMxy | Да/Нет | Да |
| Concrete.TensionMode | - | Ignore |
| Mesh.StepX | мм | 10 |
| Mesh.StepY | мм | 10 |
| Solver.LoadSteps | шт | 1 |
| Solver.DiagnosticsEnabled | Да/Нет | Нет |
| Capacity.MaxRetries | шт | 0 |
| Capacity.BaseLoadSteps | шт | 1 |
| Concrete.Eb | МПа | 32500 |
| Concrete.Bilinear.Stress1 | МПа | -15.5 |
| Concrete.Bilinear.Eps1 | - | -0.0015 |
| Concrete.Bilinear.EpsU | - | -0.0035 |
| Steel.Bilinear.StressY | МПа | 350 |
| Steel.Bilinear.EpsY | - | 0.00175 |
| Steel.Bilinear.EpsU | - | 0.025 |
| CrackWidth.Allowable | мм | 0.3 |
| Materials.SourceStatus | - | PROVISIONAL_FOR_SOLVER_TESTING |

Для расчета ширины раскрытия уже образовавшихся трещин значение по умолчанию для `Concrete.TensionMode` - `Ignore`.

По умолчанию книга работает в быстром режиме `DirectState`: выполняется прямой расчет НДС при заданных `N`, `Mx`, `My`, без поиска `lambdaUltimate` и без определения несущего момента. В этом режиме в строках `LambdaUltimate`, `SafetyFactor` и `MomentUltimate` выводится `NotCalculated`.

Для полного поиска несущей способности установите на листе `System`:

```text
Calculation.Mode = FullCapacity
```

После этого расчет будет существенно медленнее, потому что для каждого направления `Mx`, `My`, `Mxy` запускается поиск предельного множителя.

Для максимально быстрого оценочного матричного расчета можно установить:

```text
Calculation.Mode = LinearMatrix
```

Этот режим решает одну линейно-упругую матрицу `3 x 3`. Он быстрее, но не является НДМ, не использует нелинейные диаграммы материалов и не рассчитывает ширину раскрытия трещин.

## 6. Запуск расчета

На листе `Расчет` нажмите кнопку `Выполнить расчет`.

Кнопка запускает публичный макрос:

```text
RunSectionCalculation
```

Макрос читает исходные данные, проверяет заполненные строки сочетаний, выполняет расчет только для заполненных сочетаний и выводит результаты на лист `Расчет`.

Если входные данные некорректны, макрос показывает сообщение с описанием ошибки.

## 7. Где смотреть результаты

Результаты появляются на листе `Расчет`:

| Направление | Диапазон | Область |
|---|---|---|
| Mx | rngResultMx | Расчет!S17:AH35 |
| My | rngResultMy | Расчет!AK17:AZ35 |
| Mxy | rngResultMxy | Расчет!BC17:BR35 |

Для одного введенного сочетания в этих блоках выводятся:

- `LambdaUltimate`;
- удерживающие моменты `MxUltimate`, `MyUltimate` и результирующий момент;
- `SafetyFactor`;
- `Utilization`;
- критерий предельного состояния;
- параметры деформационной плоскости `Epsilon0`, `KappaX`, `KappaY`;
- предельные деформации;
- ширина раскрытия трещин;
- допустимая ширина раскрытия;
- статус расчета;
- предупреждение `PROVISIONAL_FOR_SOLVER_TESTING`, если применяются предварительные параметры материалов.

В быстром режиме `DirectState` результаты несущей способности (`LambdaUltimate`, `SafetyFactor`, удерживающий момент) не рассчитываются и показываются как `NotCalculated`. При этом деформации, невязки равновесия, статус прямого решения и ширина раскрытия трещин выводятся.

Подробная пакетная диагностика записывается на лист `System` ниже основной таблицы настроек, начиная с области диагностики.

## 8. Очистка результатов

На листе `Расчет` нажмите кнопку `Очистить результаты`.

Кнопка запускает макрос:

```text
ClearSectionResults
```

Очищаются только результаты и диагностика. Введенные пользователем исходные данные, арматура, сочетания нагрузок и настройки `System` не удаляются.

## 9. Контрольный пример для ручного ввода

Этот пример предназначен для ручного сравнения с другой программой НДМ. Ожидаемые результаты здесь не приводятся.

Исходные данные:

- диаметр сечения: `300 мм`;
- центр круга: `X = 0 мм`, `Y = 0 мм`;
- бетон: `B30`;
- арматура: `A400`;
- защитный слой до поверхности арматуры: `35 мм`;
- арматура: `8 стержней диаметром 20 мм`;
- радиус окружности центров стержней: `105 мм`;
- `N = -300000 Н`;
- `Mx = 25000000 Н*мм`;
- `My = 15000000 Н*мм`;
- `Concrete.TensionMode = Ignore`;
- шаг волоконной сетки: `Mesh.StepX = 10 мм`, `Mesh.StepY = 10 мм`;
- допустимая ширина раскрытия трещины: `0.3 мм`;
- статус материалов: `PROVISIONAL_FOR_SOLVER_TESTING`.

Таблица для копирования в `rngRebarInput` с вставкой начиная с `Расчет!A26`:

```text
ID	X	Y	Diameter	Area	SteelClass	Comment
B1	105.00	0.00	20	314.16	A400	manual circle example
B2	74.25	74.25	20	314.16	A400	manual circle example
B3	0.00	105.00	20	314.16	A400	manual circle example
B4	-74.25	74.25	20	314.16	A400	manual circle example
B5	-105.00	0.00	20	314.16	A400	manual circle example
B6	-74.25	-74.25	20	314.16	A400	manual circle example
B7	0.00	-105.00	20	314.16	A400	manual circle example
B8	74.25	-74.25	20	314.16	A400	manual circle example
```

Площадь одного стержня рассчитана как:

```text
Area = pi * Diameter^2 / 4 = 314.16 мм2
```
