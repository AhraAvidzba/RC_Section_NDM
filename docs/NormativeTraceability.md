# Нормативная трассировка

Статус: начальный документ этапа 0. Нормативные значения не внесены, потому что каждое значение должно быть подтверждено пунктом, таблицей, формулой или приложением СП.

## Источники в репозитории

- СП 35: `norms/SP_35/СП 35.13330.2011 Мосты и трубы. Актуализированная редакция СНиП 2.05.03-84 (с Изменениями № 1-5)_Текст.pdf`
- СП 63: `norms/SP_63/СП 63.13330.2018 Бетонные и железобетонные конструкции. Основные положения. СНиП 52-01-2003 (с..._Текст.pdf`
- Дубликат СП 63 также найден в `norms/SP_35/`.

## Ограничения этапа 0

Автоматическое извлечение текста PDF не выполнено: в локальной среде не найден `pdftotext`, а обычный `python` недоступен. Поэтому этот файл содержит структуру трассировки и перечень требуемых нормативных позиций, но не подставляет нормативные значения.

## Открытые нормативные вопросы

- Подтвердить приоритет СП 35 и СП 63 для каждого расчетного случая.
- Подтвердить редакции и действующие изменения PDF из `norms`.
- Заполнить трассировку диаграмм материалов.
- Заполнить трассировку предельных деформаций.
- Заполнить трассировку расчета ширины раскрытия трещин.
- Не переносить коэффициенты из справочного VBA без проверки по нормативному источнику.

## Нормативные параметры листа System

Все нормативные коэффициенты и параметры материалов должны быть отражены на листе `System` в структуре:

```text
Ключ | Значение | Значение по умолчанию | Единица | Назначение | Нормативный источник | Изменено пользователем
```

Требования:

- `Значение по умолчанию` заполняется только подтвержденным значением из СП 35 или СП 63;
- `Нормативный источник` должен содержать СП, пункт, таблицу или формулу;
- `Значение` может быть изменено пользователем;
- отличие `Значение` от `Значение по умолчанию` должно диагностироваться;
- пользовательское значение не заменяет нормативное значение по умолчанию;
- неподтвержденные параметры остаются `TODO`.
