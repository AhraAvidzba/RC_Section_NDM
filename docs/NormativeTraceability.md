# NormativeTraceability

Дата актуализации: 2026-08-05.

## Статус

Нормативная трассировка не завершена. Текущие значения материалов и трещин доступны пользователю на листе `System`, но результаты программы пока не должны объявляться окончательно верифицированным расчетом по СП 35/СП 63.

## Источники

Основные источники должны браться из каталога:

```text
norms/
```

Приоритет для мостовых конструкций:

- методика НДМ - СП 63, если не противоречит специальным требованиям мостов;
- расчетные сопротивления, предельные деформации и специальные требования мостов - СП 35 при наличии подтвержденного пункта.

## Реализованная программная модель

| Область | Реализация | Нормативный статус |
|---|---|---|
| Диаграмма бетона | `CConcreteDiagramMaterial`, точки `rngConcreteDiagramPoints` | параметризовано; формулы участков требуют ручной проверки |
| Диаграмма стали | `CSteelDiagramMaterial`, точки `rngSteelDiagramPoints` | параметризовано; формулы участков требуют ручной проверки |
| Предельные деформации | `Capacity.ConcreteCompressionLimit`, `Capacity.ConcreteTensionLimit`, `Capacity.SteelStrainLimit` | вынесено на `System`; требуется подтверждение применимости |
| Растянутый бетон | `Concrete.TensionMode = Ignore / UseDiagram` | постановка выбирается пользователем |
| НДС | `CSectionSolver` | расчетная механика реализована |
| Несущая способность | `CCapacitySolver` | алгоритмы реализованы; нормативная приемка не завершена |
| Трещины | `CCrackWidthCalculator`; прозрачная методика будет вынесена отдельно после уточнения СП | временные коэффициенты требуют нормативной трассировки |

## Требования к дальнейшей трассировке

Для каждого нормативного параметра нужно зафиксировать:

- документ;
- редакцию;
- пункт, таблицу, формулу или приложение;
- единицы;
- область применимости;
- программный ключ или метод;
- контрольный пример.

Неоднозначные места фиксируются в `docs/OpenNormativeQuestions.md`.
