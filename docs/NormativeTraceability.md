# NormativeTraceability

Дата актуализации: 2026-09-21.

## Статус

Нормативная трассировка не закрыта полностью. Формулы и коэффициенты, которые влияют на расчет, должны быть доступны пользователю на `Config`, в контрольных таблицах или в подробной справке. Результаты программы не следует объявлять окончательно верифицированным расчетом по СП 35/СП 63 без ручной проверки источников.

## Источники

Основные нормативные источники хранятся в каталоге:

```text
norms/
```

Рабочее правило проекта:

- методика НДМ принимается по СП 63;
- специальные требования мостовых конструкций принимаются по СП 35 там, где пункт СП 35 подтвержден;
- неоднозначные места фиксируются в `docs/OpenNormativeQuestions.md`.

## Реализованная Программная Модель

| Область | Реализация | Нормативный статус |
|---|---|---|
| Диаграмма бетона | `CMaterialModelProvider` строит `CMaterialDiagram` по `rngConcreteMaterialParameters` и `rngCalculationDiagramSettings` | TwoLine/ThreeLine реализованы; применимость параметров требует нормативной проверки |
| Диаграмма стали | `CMaterialModelProvider` строит `CMaterialDiagram` по `rngSteelMaterialParameters` и `rngCalculationDiagramSettings` | TwoLine/ThreeLine реализованы; применимость параметров требует нормативной проверки |
| Предельные деформации | берутся из построенной диаграммы выбранного расчетного режима | дублирующие настройки предельных деформаций удалены |
| Растянутый бетон | задается в `rngCalculationDiagramSettings`: `Strength`, `CrackInitiation`, `CrackedNDS` | источник логики учета растянутого бетона централизован |
| НДС | `CSectionSolver`, постановка `N + Mx + My` | расчетная механика реализована |
| Несущая способность | `CCapacitySolver`, λ-траектории и стратегии `Auto`/`UltimateStrain`/`LoadMultiplier` | алгоритмы реализованы; нормативная приемка не завершена |
| Нормальные трещины | `CCrackWidthCalculator`, проверка образования трещины и расчет ширины раскрытия | реализовано по принятой проектной интерпретации СП 63; допущения описаны в `docs/CrackWidthMethodology_SP63.md` и справке книги |
| Продольные трещины | проверка выполняется для всех LC с включенным расчетом трещин по найденному `CrackedState` | требуется независимая нормативная проверка коэффициентов и пределов |
| Устойчивость СП 63 | случайный эксцентриситет, `phi_l`, `Ncr`, `eta`, условие `l0/i > 14` | реализовано по зафиксированной проектной интерпретации; см. `SP63_SP35_SECOND_ORDER_STABILITY_DISCRETE_AUDITED.md` |
| Устойчивость СП 35 | табл. 7.21, ветвь `ec/r > 1`, `Ncr`, `eta`, ограничение `N/Ncr` через пользовательский коэффициент | реализовано по зафиксированной проектной интерпретации; таблица 7.21 читается из `Config` |

## Требования К Дальнейшей Трассировке

Для каждого нормативного параметра нужно зафиксировать:

- документ;
- редакцию;
- пункт, таблицу, формулу или приложение;
- единицы;
- область применимости;
- программный ключ или метод;
- контрольный пример.

Неоднозначные места фиксируются в `docs/OpenNormativeQuestions.md`.
