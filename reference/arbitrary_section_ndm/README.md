# Справочный расчёт произвольного сечения

В каталоге находится Excel-программа расчёта произвольного
железобетонного сечения по НДМ. Геометрия загружается из AutoCAD.

## Назначение

Программа предоставлена для инженерного изучения:

- дискретизации произвольного сечения;
- расчёта косого изгиба;
- поиска нейтральной оси;
- вычисления внутренних усилий;
- организации нелинейного расчёта;
- контрольных численных результатов.

Результаты программы можно использовать как доверенный контрольный
ориентир.

## Ограничения

Программа не является эталоном архитектуры кода.

Не следует автоматически копировать:

- структуру VBA-проекта;
- деление на модули;
- взаимодействие с Excel и AutoCAD;
- способ хранения данных;
- обработку ошибок;
- численный алгоритм без предварительной проверки.

Программа приложена с инженерной, а не с программно-архитектурной
точки зрения.
