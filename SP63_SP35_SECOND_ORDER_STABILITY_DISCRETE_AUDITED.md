# Устойчивость И Продольный Изгиб По СП 63 И СП 35

Дата актуализации: 2026-09-21.

Документ описывает текущую реализацию расчета устойчивости в проекте. Это не самостоятельное нормативное заключение: спорные места должны проверяться по локальным документам `norms/` и фиксироваться в `docs/OpenNormativeQuestions.md`.

## Место В Расчетной Цепочке

`CStabilityCalculator` работает как фильтр нагрузки перед обычными расчетами НДС, несущей способности и трещин.

```text
исходное LC
  -> перенос к центру приведенного сечения
  -> переход к главным осям приведенного сечения
  -> расчет устойчивости по выбранному СП
  -> возврат скорректированных моментов в глобальные оси
  -> дальнейшая цепочка НДМ
```

Если в профиле `Calculation.Stability.Enabled = No`, нагрузка проходит дальше без изменения, а статус устойчивости равен `N/A`.

Если расчет устойчивости получает `FAIL`, последующие NDS / Capacity / Strength / Crack для этого LC не запускаются. Общий итог сочетания остается `FAIL` по устойчивости, а пропущенные расчеты получают централизованный статус через `CBatchStatusPolicy`.

## Исходные Данные

Основные настройки:

| Ключ | Смысл |
|---|---|
| `Stability.Code` | `SP63` или `SP35`; по умолчанию `SP35` |
| `Stability.ElementLength` | геометрическая длина элемента `L` |
| `Stability.Mu1`, `Stability.Mu2` | коэффициенты расчетной длины для главных плоскостей 1 и 2; должны быть больше нуля |
| `Stability.SystemType` | статически определимая или неопределимая система для ветви СП 63 |
| `Stability.AccidentalEccentricityMode` | `AutoWithL`, `AutoWithMuL`, `User` |
| `Stability.AccidentalEccentricityUser1/2` | пользовательский модуль случайного эксцентриситета по главным плоскостям |
| `Stability.AccidentalEccentricityPlanes` | `OnlyMomentPlane` или `BothPlanes` |
| `Stability.ZeroMomentEccentricitySign1/2` | направление случайного эксцентриситета при нулевом моменте в плоскости |
| `Stability.PhiLMode` | `Auto` или `PhiL2` |
| `MaterialModel.Stability.ValueSet` | набор характеристик материалов для расчета устойчивости |

Пользователь задает `Mu1/Mu2` по главным осям приведенного сечения. Если главные оси совпадают с центральными `X/Y`, плоскость 1 связана с моментом `Mx` и эксцентриситетом по `Y`, а плоскость 2 связана с моментом `My` и эксцентриситетом по `X`.

## Нагрузки И Моменты

Полные нагрузки LC и нагрузки длительной/постоянной части читаются из `Config` один раз, переводятся в расчетные единицы и переносятся тем же общим механизмом, что используется в остальных ветках программы.

Перед выбором ветвей моменты проходят фильтр практически нулевого момента:

```text
Mtol = Calculation.ZeroMomentPerDepth * h
Abs(M) <= Mtol => M = 0
```

Для расчета в главных плоскостях используются бетонные габариты `h1/h2`, определенные по оболочкам бетонных элементов. Арматура влияет на приведенное сечение, главные оси, радиусы инерции и ядровые расстояния, но не задает внешний бетонный габарит `h`.

## Случайный Эксцентриситет

`Stability.AccidentalEccentricityMode = AutoWithL` использует геометрическую длину `L`.

Для СП 63:

```text
ea = max(L / 600, h / 30, 10 mm)
```

Для СП 35:

```text
ec,sl = L / 400
```

`AutoWithMuL` является отдельной пользовательской проверочной настройкой и вместо `L` использует расчетную длину `l0 = μ * L`. `User` берет модуль из `Stability.AccidentalEccentricityUser1/2`, а знак определяется общей логикой: по направлению существующего момента, либо по `Stability.ZeroMomentEccentricitySign1/2`, если момент в плоскости равен нулю.

`OnlyMomentPlane` сохраняет расчетный эксцентриситет только в плоскости существующего момента; при двух нулевых моментах используются пользовательские направления. `BothPlanes` учитывает случайный эксцентриситет в обеих главных плоскостях.

## Геометрические Характеристики

Для механики используются реальные свойства элементов:

- бетонные `Area/LocalIx/LocalIy/LocalIxy`;
- площадь и координаты арматуры;
- приведенное сечение с учетом арматуры.

Для габаритов, проекций и расстояний до границ используется геометрическая оболочка бетонных элементов. Если размеры элемента известны, используются они. Если известны только площадь и инерции, `CSectionModel` строит area-preserving эквивалентный прямоугольник. Если инерции отсутствуют, последний fallback - эквивалентный квадрат той же площади.

## СП 63

Для каждой главной плоскости определяются:

```text
l0 = μ * L
e0 = M / N + ea
phi_l = 1 + Ml1 / M1
1 <= phi_l <= 2
```

`M1` и `Ml1` определяются относительно наиболее растянутого или наименее сжатого стержня арматуры с учетом `N` и координаты выбранного стержня. Режим `PhiL2` принудительно задает `phi_l = 2` и остается отдельной пользовательской опцией.

Критическая сила считается по принятой формуле СП 63:

```text
Ncr = pi^2 * D / l0^2
```

Коэффициент `eta` применяется только при:

```text
l0 / i > 14
```

Если `l0 / i <= 14`, принимается `eta = 1`, а `Ncr` может выводиться справочно.

## СП 35

В СП 35 выбор ветви выполняется по отношению:

```text
q = |ec| / r
```

`r` - ядровое расстояние приведенного сечения в направлении эксцентриситета, а не радиус инерции `i`. Для несимметричного сечения выбирается `r+` или `r-` по направлению `ec`.

### Ветвь `ec/r <= 1`

Используется табличная проверка по таблице 7.21 СП 35:

```text
N <= Nult,stab
```

`phi_m` и `phi_l` интерполируются только по пользовательской таблице `rngSP35Table721` на `Config`. В этой ветви режим `PhiL2` не подменяет табличный `phi_l`.

Коэффициент запаса:

```text
Kstab = Nult,stab / N
```

Условие считается выполненным при `Kstab >= 1` с численным tolerance.

### Ветвь `ec/r > 1`

Используется структура формулы (7.10) СП 35 без добавления `pi^2`:

```text
Ncr = D / l0^2
eta = 1 / (1 - N / Ncr)
```

Где требуется проверка ограничения отношения продольной силы к критической, используется пользовательская настройка:

```text
k = Stability.SP35.NOverNcrLimit
Kcr = k * Ncr / N
```

Если `Kcr >= 1`, условие `N / Ncr <= k` выполнено.

Для `phi_l` в режиме `Auto` используется нормативная структура:

```text
phi_l = 1 + Ml / M
1 <= phi_l <= 2
```

`M` и `Ml` определяются относительно требуемой наиболее растянутой или наименее сжатой грани. Для противоположных знаков `M` и `Ml` используется отдельная ветвь СП 35. `PhiL2` принудительно задает `phi_l = 2` только там, где коэффициент участвует в формулах `Ncr/eta`, и не заменяет табличный коэффициент в ветви `ec/r <= 1`.

## Вывод

Подробный блок `rngStabilitySummaryAnchor` выводит по каждой плоскости:

- `l0/i`;
- эксцентриситеты и случайный эксцентриситет;
- `phi_l`;
- `Ncr`, `eta`, `D`, `delta`;
- ветвь СП 35: `SP35-table`, `SP35-eta` или общий `SP35-mixed`, если плоскости попали в разные ветви;
- коэффициенты запаса по применимым условиям.

`rngBatchSummary` берет минимальный применимый коэффициент запаса устойчивости по двум главным плоскостям. Для СП 35 в ветви `ec/r > 1` в этот минимум входит именно запас `k * Ncr / N`, а не отношение `N / Ncr`.

## Что Требует Ручной Проверки

- окончательная нормативная трассировка пунктов СП 63 и СП 35;
- контрольные примеры для несимметричных сечений;
- проверка знаков `M`, `Ml` и выбора `r+ / r-`;
- контроль таблицы 7.21, потому что ее значения задает пользователь на `Config`.
