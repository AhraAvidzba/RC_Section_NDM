# Правила проекта

## Расчет и нормы

- Единственная постановка - `N + Mx + My`; одноосный изгиб задается нулем второго момента. Поддерживается ненапрягаемая арматура.
- Приоритеты: физическая корректность, равновесие, проверяемость, воспроизводимость, затем скорость. Численная несходимость не означает физическое разрушение.
- Формулы и коэффициенты брать из `norms/`, не по памяти. Неоднозначные трактовки фиксировать в `docs/OpenNormativeQuestions.md`; инженерное допущение не выдавать за требование СП.
- Нормативные параметры должны быть доступны на Config или в контрольных таблицах. Автотесты не означают окончательную нормативную верификацию.

## Данные и геометрия

- Ядро не обращается к Excel. Настройки читаются через `CSystemSettingsReader`, единицы и знаки преобразуются только через `CUnitSystem`.
- Внутри: мм, мм2, Н, Н*мм, МПа; положительное N - растяжение. Ввод по умолчанию: tf, tf*m, положительное N - сжатие.
- Поле деформаций: `epsilon = epsilon0 + kappaX*y + kappaY*x`. Пользовательская точка приложения отсчитывается от центра бетонной сетки без арматуры; перенос нагрузки описан в `docs/CoordinateSystem.md`.
- Генераторы и импорт заполняют один `CSectionModel`. Контуры и несколько отверстий классифицируются как Outer/Opening на уровне геометрии, передаются централизованно и обрабатываются одинаково.
- Для нового типа обязательны геометрия с `ISectionGeometry.BuildContours` и раскладка арматуры; аннотации необязательны. Подключение - в реестре, без ветвей по типам в потребителях. При отсутствии отверстий возвращается пустой набор.
- Область трещин: только Opening - наружные границы сетки минус только заданные отверстия; только Outer - сплошной бетон внутри него; Outer и Opening - только заданные границы; ничего не задано - сетка со всеми ее пустотами. Это не меняет сетку НДС.
- Контуры сохраняются в `rngNDMSectionContours`, элементы - в `rngNDMSectionGeometry`, область трещин - в аннотациях. Контуры не дублировать. Расчетные имена элементов создавать только в `CSectionModel`.
- Экспорт и схема читают сохраненный Results с его единицами, без нового импорта или решения НДС. Габариты по наружному контуру точные, по сетке - приблизительные.
- AutoCAD: 1 единица чертежа = 1 мм; импорт мм/мм2/мм4, экспорт геометрии всегда в мм независимо от INPUT/OUTPUT. Работать в WCS; импорт при неизвестной или локальной ПСК отклоняется.
- Отсутствие контурных слоев не блокирует импорт. Проверять фактическую замкнутость полилиний; временные объекты убирать, исходники не менять.
- `AutoCAD.Export.ContourFormat`: Region или Polyline. Экспорт добавляет объекты без поиска совпадений и очистки. Ручная очистка сохраняет бетон, арматуру, наружные контуры и отверстия, включая экспортированные копии.

## Поиск и трещины

- `LoadPath` сочетания - единая настройка несущей способности и трещинообразования: Auto, λ*Mx, λ*My, λ*Mxy, λ*N, λ*NMxy. Пустое значение равно Auto.
- Auto: единственная составляющая масштабируется сразу; при N + M пробуются M, затем N, затем NMxy. Найденный предел с λ < 1 не запускает следующий путь. Явный путь не менять; ошибки ввода не маскировать fallback.
- Момент от эксцентриситета N масштабируется вместе с N. Осевая траектория использует LoadMultiplier из-за вырожденности UltimateStrain на плато.
- Проверять предельные деформации сжатия и растяжения бетона и стали; растяжение бетона активно только при включенной растянутой ветви.
- Неудача трещинообразования не блокирует ширину и продольные трещины при пригодном текущем НДС. В СП 63 недоступное уточнение дает psi_s = 1 с предупреждением только при фактическом использовании коэффициента.
- NotCracked исключает только ширину нормальных трещин; продольные проверяются независимо. Пользовательский psi_s при этом не менять, предупреждение о psi_s = 1 не выводить. В СП 35 такого коэффициента нет.
- Группы СП 35 неделимы: включение в конечную область определяется по центру группы. Ряды нумеруются от бетонной границы к НЛ.
- Боковые границы СП 35: ближайшая арматурная группа отдельно слева/справа, t/L; t - расстояние проекций на НЛ, L - полное расстояние. Ниже порога сохраняется r, иначе min(r; t/2). RowTolerance разделяет ряды, но не меняет границы.
- Область трещин не должна менять прежние A/I и конвейер устойчивости.

## Производительность и оформление

- Сетку, арматуру и материалы готовить один раз на запуск. Горячие циклы - массивы, Excel-вывод - блочные присваивания.
- Кэш - только при точном совпадении всех значимых входов и ревизий; не округлять ключи, не переиспользовать изменяемые состояния. Результаты, диагностика и надежность неизменны.
- Ширина столбцов Results задается только при сборке. В данных и пояснениях перенос отключен; в верхних шапках сохраняется.
- Списки Config строить через независимые именованные диапазоны; настройки противоположных граней не объединять. Таблицы обводить полностью, включая правую грань Справки.
- Пользовательские ячейки Config центрировать; комментарии слева при наличии столбцов справа, иначе справа. Формулы оформлять с дробями и индексами, объяснять обозначения.
- Справка описывает действия пользователя и расчетный смысл. Ссылка ведет к своей настройке, без повторения всего соседнего раздела.
- Ошибки и ResultComment: понятная причина и фактический адрес через именованный диапазон, без жестко заданных ячеек. Сохранять корректный Unicode.
- Новым модулям - короткая шапка назначения; нетривиальным методам - русский комментарий с инженерным смыслом. Тестовые entrypoint-ы отделять пометкой ДЛЯ ТЕСТОВ.

## Проверки и защита данных

- Объем тестов выбирать по риску. После мелких правок не запускать полный набор; документация не требует расчетных тестов и пересборки.
- Самые долгие полные on/off и Excel UI прогоны - только с отдельного явного согласия пользователя в чате, с указанием состава и длительности.
- Проверять затронутые пути, статусы, ResultComment, единицы и знаки. Baseline менять только с инженерным объяснением.
- После изменений, попадающих в книгу, проверить output-файл: код, настройки, списки, рамки, заголовки и актуальность `VBA_All_Code.txt`. Сохранять пользовательские данные.
- Не изменять `norms/`, `reference/`, `control_examples/` и не откатывать чужие правки.
- Не завершать все процессы Excel/AutoCAD; закрывать только собственный проверенный PID.
- Команды: `docs/ValidationPlan.md`. Отчеты: `docs/reports/`. Доказательства: `docs/regression/`.
