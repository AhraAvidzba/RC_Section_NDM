# Иллюстрации сечений

Четыре PNG с именами `Circle`, `Rectangles`, `PointedSection` и `HollowRectangle` — исходники иллюстраций книги. Сборщик встраивает их на лист «Сечения» и в группу `CurrentSection` листа «Расчет». Все изображения вписываются в рамки с сохранением пропорций.

Выбор в `Расчет!K2` вызывает `modSectionIllustrations.SwitchSectionPicture`. Процедура вписывает выбранную встроенную картинку и меняет видимость четырёх готовых объектов. Буфер обмена, выделение, переключение листов и расчётные таблицы для этого не нужны.

Пользователь может перемещать и изменять размеры всей группы `CurrentSection`. Внутри неё находятся прозрачная рамка `CurrentSection_Frame` и четыре рисунка с префиксом `CurrentSection_`. Исходные ширина и высота PNG записаны в `AlternativeText` каждого рисунка как `ширина|высота`; они нужны для сохранения пропорций при растяжении группы.

Для обновления изображений замените соответствующие PNG в этой папке и пересоберите книгу. Копии рисунков на листе «Сечения» и в группе обновляются сборщиком одновременно. Имена группы и её дочерних объектов должны сохраняться. Выбор иллюстрации независим от расчётной настройки `Geometry.Type`.

Исходный чертёж иллюстраций — [Типы_сечения.dwg](../../../Типы_сечения.dwg) в корне проекта. В нём редактируются сечения для подготовки картинок. Экспортируйте выбранные изображения в соответствующие PNG этой папки; сборщик встраивает эти PNG в книгу.
