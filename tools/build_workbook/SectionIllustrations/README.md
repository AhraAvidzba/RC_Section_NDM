# Ручное обновление иллюстраций

На листе «Сечения» можно удалить рисунок, вставить другой и присвоить ему нужное имя через поле имени слева от строки формул. Имена выбираемых рисунков перечислены непосредственно в проверке данных ячейки Расчет!K2. Общие поясняющие иллюстрации могут иметь любые другие имена и в этот список автоматически не добавляются.

Чтобы добавить вариант, вставьте именованный рисунок и допишите его имя в «Данные → Проверка данных → Источник» для K2. Это обычное перечисление, без служебных ячеек, скрытых копий и правок VBA. Вернитесь на «Расчет» и выберите нужное имя. Пересборка или сохранение книги для переключения не нужны.

CurrentSection задаёт положение и полные габариты рамки. Можно перемещать и растягивать всю группу. Если вместо группы вручную вставлен обычный рисунок с именем CurrentSection, процедура сама подготовит рамку в его границах. Выбранная иллюстрация вписывается с сохранением пропорций. Не переименовывайте два внутренних объекта группы.

Связанное изображение показывает видимую область рисунка на листе «Сечения»; размещайте исходные иллюстрации без наложения друг на друга. Буфер обмена, пересчёт книги и файлы изображений при переключении не используются. Выбор иллюстрации независим от Geometry.Type.

Для полной сборки PNG хранятся в этой папке. Явный перечень имён и начальный выбор задаются в Illustrations.json, положение и габариты — в ../WorkbookLayout.json. Новый вариант без собственной записи раскладки размещается под остальными исходными рисунками. Имя PNG совпадает с именем рисунка в книге. Общие PNG, не перечисленные в Illustrations.json, сборщик не добавляет в список.

Исходный чертёж иллюстраций — [Типы_сечения.dwg](../../../Типы_сечения.dwg) в корне проекта. После редактирования чертежа экспортируйте PNG в эту папку, если изменения должны воспроизводиться полной пересборкой.
