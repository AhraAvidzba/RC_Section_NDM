# Ручное обновление иллюстраций

На листе «Сечения» можно удалить исходный рисунок, вставить другой и присвоить нужное имя. В Расчет!K2 выберите это имя: процедура копирует обычный рисунок в CurrentSection, сохраняя его положение, внешние габариты и пропорции изображения. Новая картинка заменяет текущую только после успешной вставки. Исходный лист не активируется; режим обновления экрана не переключается. События временно отключаются, затем восстанавливаются вместе с выбранным листом и ячейкой; расчёт не запускается.

K2 содержит обычное перечисление непосредственно в проверке данных. Для нового варианта вставьте именованный рисунок и допишите его имя в «Данные → Проверка данных → Источник» ячейки K2. Служебные ячейки и правки VBA не нужны. После ручной замены уже выбранного источника выберите его в K2 повторно. Выбор иллюстрации независим от Geometry.Type.

PNG для полной сборки находятся в этой папке. Names и Default в Illustrations.json задают выбираемые варианты и начальное изображение. Additional содержит общие иллюстрации, которые вставляются только на «Сечения» и не попадают в список K2. Name — имя объекта в книге, File — имя PNG. Положение и габариты объектов задаются в ../WorkbookLayout.json.

Исходный чертёж — [Типы_сечения.dwg](../../../Типы_сечения.dwg) в корне проекта. Для воспроизводимой пересборки экспортируйте изменения в соответствующие PNG этой папки.
