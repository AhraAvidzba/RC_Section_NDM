# Формулы справки

PNG и SVG строятся из математической записи в `../NormativeFormulaImages.json`.
Каталог хранит ссылку на пункт/формулу, сведения о локальном PDF и контрольные
суммы математической записи и готового PNG. Исходные PDF в `norms/` не меняются.

Обычная сборка Excel использует готовые PNG и не запускает Python-рендерер.
Для изменения формулы сначала сверьте её вид и ссылку с локальным нормативом,
затем выполните в Python с Matplotlib и Pillow:

```powershell
python tools/build_workbook/Render-NormativeFormulas.py --update-catalog
```

Рендерер создаёт новые изображения при четырёх пикселях на пункт и векторные
SVG. Увеличение малого растра PDF не используется. После изменения проверьте
в сохранённой книге дроби, индексы, ссылку и полное размещение формулы в строке.
